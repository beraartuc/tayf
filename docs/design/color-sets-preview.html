Neon as default — the light question

Neon is the dark default. Electric colors can't stay bright on white, so the light terminal gets a dark, high-contrast recast of the same hues — colorizing to raise legibility on white, not lower it. ipv4 = azure, ipv6 = indigo, url = one blue underlined link (incl. https://), duration = amber, log_level the only bold.

Backgrounds are neutral defaults (dark #141414 / light #fbfbfa) — stand-ins for your terminal. Below 24-bit, downgrade() maps each color to the nearest 256/16 entry. The "default text" line shows the bg's own fg; every rule differs from it.
