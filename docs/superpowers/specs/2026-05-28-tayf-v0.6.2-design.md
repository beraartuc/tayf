### 3.5 Item 5 — AST-level 3-way merge

#### 3.5.1 Yeni module: `src/config_tui/merge.rs`

```rust
//! Three-way structural merge of TOML config documents.
//!
//! `merge_three_way` takes the disk content as it existed when the TUI
//! opened (`base`), the TUI's pending-edit projection (`ours`), and the
//! current on-disk content (`theirs`). It walks all keys recursively and
//! returns an auto-merged document plus the set of conflicting keys.
//!
//! Conflicts arise when the same key was modified in both `ours` and
//! `theirs` to different values. Disjoint modifications auto-merge.
//!
//! This module owns NO IO; it operates purely on `toml_edit::DocumentMut`.
```

**Public API:**

```rust
pub(crate) struct MergeResult {
    pub auto_merged: DocumentMut,
    pub conflicts: Vec<KeyConflict>,
}

pub(crate) struct KeyConflict {
    pub path: KeyPath, // Vec<String>, e.g. ["general", "theme"]
    pub base_value: String, // toml_edit fmt
    pub ours_value: String,
    pub theirs_value: String,
}

pub(crate) fn merge_three_way(
    base: &DocumentMut,
    ours: &DocumentMut,
    theirs: &DocumentMut,
) -> MergeResult;
```

#### 3.5.2 Algoritma

Recursive walk root tables:

```text
union_keys = base_keys ∪ ours_keys ∪ theirs_keys
for k in union_keys:
    bv, ov, tv = base[k], ours[k], theirs[k]  // each Option<&Item>
    if bv == ov && bv == tv:
        // no-op, keep
    elif bv == ov:
        // theirs changed, ours unchanged → take theirs
        set auto_merged[k] = tv (or remove if tv absent)
    elif bv == tv:
        // ours changed, theirs unchanged → take ours
        set auto_merged[k] = ov (or remove if ov absent)
    elif ov == tv:
        // both changed identically → take ours (convergent)
    elif bv is Table && ov is Table && tv is Table:
        // recurse into table
        recurse(bv, ov, tv) — conflicts pushed with path prefix
    else:
        // genuine conflict
        push KeyConflict { path, base_value, ours_value, theirs_value }
        // auto_merged stays at base value until item 6 resolves
        set auto_merged[k] = bv
```

**Edge cases:**

- **Table type mismatch** (e.g., `general` `Table` in base/ours, `InlineTable` in theirs): treat as leaf conflict.
- **Array of tables** (`[[patterns]]`): walk by index — index drift edge case (theirs deleted patterns[0], ours edited patterns[1]). v0.6.2 simplification: arrays of tables treated as leaf — full array replace conflict if any element differs across all three. Doc note in module: "Array-of-tables fine-grained merge is v0.7+ — `[[patterns]]` conflicts fall back to whole-array conflict for v0.6.2."
- **Comments / whitespace**: `toml_edit` preserves these; algorithm compares `Item` values structurally, not raw bytes. Comment-only changes don't trigger conflicts.
- **Nested tables**: `[general.subsection]` recursive walk supports arbitrary depth (TOML spec depth in practice ≤ 3).

#### 3.5.3 `SaveDiffState` integration

```rust
// src/config_tui/widgets/save_diff.rs
pub(crate) enum SaveDiffState {
    Closed,
    Confirm { /* shipped */ },
    Reject { /* shipped */ },
    MergePending {
        base: DocumentMut,
        ours: DocumentMut,
        theirs: DocumentMut,
        auto_merged: DocumentMut,
        conflicts: Vec<KeyConflict>,
        selection: Vec<ConflictChoice>, // per-conflict O/T/S, default O
        focused_row: usize,
    },
}

pub(crate) enum ConflictChoice { Ours, Theirs, Skip }
```

Save flow:

1. User Ctrl+S → snapshot disk content as `theirs`.
2. `base = snapshot.original_disk_doc` (TUI startup capture, mevcut `app.original_config_bytes` kullanılır).
3. `ours = base.clone() + apply_pending_edits(base.clone(), &state.edits)`.
4. `merge = merge_three_way(&base, &ours, &theirs)`.

#### 3.6.3 `apply_conflict_selections`

```rust
fn apply_conflict_selections(state: &mut MergePendingState) -> Result<(), Error> {
    let mut final_doc = state.auto_merged.clone();
    for (conflict, choice) in state.conflicts.iter().zip(state.selection.iter()) {
        match choice {
            ConflictChoice::Ours => write_to_path(&mut final_doc, &conflict.path, &state.ours),
            ConflictChoice::Theirs => write_to_path(&mut final_doc, &conflict.path, &state.theirs),
            ConflictChoice::Skip => write_to_path(&mut final_doc, &conflict.path, &state.base),
        }
    }
    write_atomic_to(config_path(), final_doc.to_string().as_bytes())?;
    state.should_quit = state.pending_save_and_quit; // item 8
    Ok(())
}
```

`write_to_path` helper `merge.rs` içinde, recursive path resolver.
