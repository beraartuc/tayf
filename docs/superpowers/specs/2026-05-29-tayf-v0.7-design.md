## 3. Item 4 — Per-element `[[rules]]` AoT merge

### 3.1 Mevcut davranış (v0.6.2-v0.6.3)

`src/config_tui/merge.rs:204-213` her üç tarafta `Item::ArrayOfTables(_)` olan key için whole-array `KeyConflict` üretir (is_array_block: true). Sonuç: `[[rules]]` array'inin tek bir element'inde değişiklik bile tüm array'i conflict yapıyor. Test pin: `merge_array_of_tables_yields_whole_array_block_conflict_v0_6_2_limitation` ([merge.rs:534](src/config_tui/merge.rs#L534)).

### 3.2 v0.7 davranışı: name-keyed per-element merge

**Element identity key (Q1 kararı):** Element'in `name = "..."` field'ı. UserRule struct (config.rs:93-94) `name: String` REQUIRED — well-formed config'de identity her zaman mevcuttur.

**Identity validation (fallback guard):**
- ANY side'da bir element `name` field'ı taşımıyorsa **veya** `name` `Item::Value(String)` değilse (örn. `Item::Value(Integer)` veya inline-table) → **whole-array fallback** (v0.6.2 davranışı korunur, `is_array_block: true`).
- Empty-string `name = ""` allowed (toml_edit + apply_user_rules late-validate) — identity'de meşru anahtar; pin test §3.4 #13.

**Algoritma (`merge_table` içinde yeni branch):**

```text
all three Item::ArrayOfTables(aob, aoa, aot):
  1. Identity validate (her element name field zorunluluğu, String tipi).
     Fail → whole-array fallback (is_array_block: true).

  2. Identity collect:
       base_names   = aob.iter().map(|e| e.get("name").as_str().unwrap().to_owned()).collect()
       ours_names   = aoa.iter() ...
       theirs_names = aot.iter() ...
     Same-side duplicate name (ours/theirs):
       - ours-side duplicate: debug_assert!(false) — apply_user_rules INVARIANT violation
         (memory feedback A-I-1); release builds → whole-array fallback (defensive).
       - theirs-side duplicate: malformed disk file; whole-array fallback
         + push warning via app.toast_warning("disk file [[rules]] has duplicate name=\"{n}\"")
         in apply-layer (events.rs).

  3. Distinct ordered name list:
       order = []
       for n in base_names: if n not in order: order.push(n)
       for n in ours_names: if n not in order: order.push(n)
       for n in theirs_names: if n not in order: order.push(n)

  3a. **Order-divergence guard (A-C-2 fold):** when no inserts or deletes
      occur (`base_names ∪ ours_names ∪ theirs_names` all equal as sets)
      BUT `ours_names != theirs_names` as ORDERED lists → **whole-array
      conflict** (is_array_block: true). Sebep: tayf RegexSet first-match-wins
      iteration order = [[rules]] declaration order (audit doc §0.1); silent
      reorder semantik anlam taşır.

  4. Yeni ArrayOfTables alloc; her name n için:
       be = aob.find_by_name(n)
       oe = aoa.find_by_name(n)
       te = aot.find_by_name(n)

     Per-element merge_table kuralı (Table-on-Table specialised):
       be == oe == te                              → push be
       be == oe, be != te                          → push te
       be == te, be != oe                          → push oe
       oe == te (convergent)                       → push oe
       be present, oe absent, te absent            → DROP (convergent deletion)
       be present, oe absent, te present, te == be → DROP (ours deleted, theirs untouched)
       be present, oe present, te absent, oe == be → DROP (theirs deleted, ours untouched)
       be present, oe absent, te present, te != be → element-level Block conflict (delete-modify)
                                                     path = [...key, name], shape = Block
       be present, oe present, te absent, oe != be → element-level Block conflict (delete-modify)
                                                     path = [...key, name], shape = Block
       be absent, oe present, te absent            → push oe (ours insertion)
       be absent, oe absent, te present            → push te (theirs insertion)
       be absent, oe present, te present, oe == te → push oe (convergent insertion)
       be absent, oe present, te present, oe != te → element-level Block conflict (insert collision)
                                                     path = [...key, name], shape = Block
       all present, all different, all Table       → recurse merge_table on element fields
                                                     (sub-conflict path = [...key, name, field])
       shape mismatch                              → element-level Block conflict

     **Absent-side render contract (A-C-1 fold):** her conflict üretildiğinde
     `base_value` / `ours_value` / `theirs_value` rendering MEVCUT
     `render_item(it: Option<&Item>) -> String` (merge.rs:303-308) ile yapılır:
     None → `"(absent)"` literal. Per-element conflict'lerde de aynı sözleşme.
     Conflict-list UI bu literal'i row'da gösterir; "(absent)" empty-string'den
     net ayırt edilir.
```

**`KeyConflict::is_array_block` semantiği** (sözleşme daralır):
- v0.6.2: AoT olan her tablo karşılaştırması `is_array_block: true`.
- v0.7: SADECE iki durumda `true`:
  1. Identity validation fail (name eksik veya non-String) → whole-array fallback.
  2. Step 3a order-divergence guard fire → whole-array conflict.
- Per-element conflict'lerde **always `false`** (path daha derin).

**`ConflictValueShape` sözleşmesi:** Per-element conflict element-level alındığında `Block` (path = `[..., name]`, full element replacement); field-level alındığında `Leaf` veya `Block` (path = `[..., name, field]`, field'ın gerçek şekline göre). Mevcut `classify_shape` helper değişmiyor.

### 3.3 `write_to_path` extension + apply-layer semantic

**Path shape extension:** Per-element merge yeni path shape'leri üretir:
- `["rules", "log_level", "pattern"]` — `rules` AoT, `log_level` name'li element, `pattern` field.
- `["rules", "log_level"]` — element-level conflict (Block shape, full element replacement).

**Descend rule:** mevcut `write_to_path` (merge.rs:335) sadece `Item::as_table()` descend kullanıyor. AoT segment için yeni lookup:

```text
cur is Item::ArrayOfTables(aot):
    find_index = aot.iter().position(|e| e.get("name").and_then(Item::as_str) == Some(seg))
    if find_index is None:
        return AotElementMissing { path, element_name: seg }
    cur = aot.get(find_index).expect("position-validated").as_item() (element's Table)
```

**Yeni error variant** (R-I-2 fold — exact format pin):

```rust
#[derive(Debug, thiserror::Error)]
pub enum WriteToPathError {
    // ...existing variants...

    /// Path descended into an array-of-tables but no element with the
    /// requested `name` field was found on the source side. Distinct from
    /// MissingIntermediate (which fires on plain-table descent failure).
    #[error("array-of-tables element not found at {path}: no element with name=\"{element_name}\"")]
    AotElementMissing {
        /// Dotted path where the AoT descent ran out.
        path: String,
        /// The `name` field value that did not match any AoT element.
        element_name: String,
    },
}
```

**SemVer impact (A-I-2 fold):** `merge::WriteToPathError` is declared `pub` at `merge.rs:101` BUT the module is `pub(crate) mod merge` (per v0.6.3 demote, memory `project_v0_6_3_shipped`). Visibility composes: `pub` in `pub(crate)` module → effective `pub(crate)`. Crate-external SemVer impact: zero.

**Apply-layer semantic for delete-modify (A-C-4 fold):** `events.rs::apply_conflict_selections` (the harness for user's per-row Ours/Theirs picks) handles AoT element-level conflicts where the source side does not contain the element:

```text
on user choice for path = [..., element_name]:
  source = match choice {
      Ours => &ours,
      Theirs => &theirs,
      Skip => return Ok(()),  // base value retained
  };
  match write_to_path(&mut auto_merged, path, source) {
      Ok(()) => continue,
      Err(AotElementMissing { .. }) if conflict.is_delete_modify() => {
          // The chosen side deleted this element — apply-as-remove.
          remove_aot_element_by_name(&mut auto_merged, &path[..path.len()-1], &path.last())?;
      }
      Err(e) => return Err(e),  // any other error surfaces to UI
  }
```

Yeni helper: `KeyConflict::is_delete_modify(&self) -> bool` — returns true when one of (base_value, ours_value, theirs_value) equals `"(absent)"`. Bu, conflict producer'ın delete-modify classification için ek state taşımasından kaçınır (render strings'lerin bilgi taşıması yeterli).

Yeni helper: `merge::remove_aot_element_by_name(doc, &[String], name) -> Result<(), WriteToPathError>` — descend to the AoT, remove element matching `name`. If absent: no-op (idempotent — safer than error for apply-layer).

## 4. Item 5 — LCS-DP line diff

### 4.1 Mevcut davranış (v0.5.4 inline impl)

`HashSet<&str>` based. Bug (documented limitation, save_diff.rs:236-238): duplicate-line collapse. `"a\na\nb\n" → "a\nb\n"` "(no changes)" gösterir.

### 4.2 v0.7 davranışı: LCS-DP with explicit boundary handling (A-C-3 fold)

**Algoritma:**

```text
Input: old: &[u8], new: &[u8]
1. old_lines = std::str::from_utf8(old).unwrap_or("").lines().collect::<Vec<_>>()
   new_lines = std::str::from_utf8(new).unwrap_or("").lines().collect::<Vec<_>>()
   n = old_lines.len(); m = new_lines.len()

2. Cap fallback: if n * m > MAX_DP_CELLS (= 100_000)
   → return cap_fallback(old_lines, new_lines)

3. DP table (flat Vec<u16>):
   cells = vec![0u16; (n+1) * (m+1)]
   for i in 1..=n:
     for j in 1..=m:
       if old_lines[i-1] == new_lines[j-1]:
         cells[i*(m+1) + j] = cells[(i-1)*(m+1) + (j-1)] + 1
       else:
         cells[i*(m+1) + j] = max(cells[(i-1)*(m+1) + j], cells[i*(m+1) + (j-1)])
   debug_assert!(cells.last().unwrap() < u16::MAX)

4. Trace-back (boundary-safe; rev2 correction of arch C-3 tie direction):
   ops = vec![]; i = n; j = m;
   while i > 0 || j > 0:
     if i == 0:                                          // ran out of old
       ops.push(Add(new_lines[j-1])); j -= 1;
     elif j == 0:                                        // ran out of new
       ops.push(Remove(old_lines[i-1])); i -= 1;
     elif cells[(i-1)*(m+1) + j] > cells[i*(m+1) + (j-1)]:
       ops.push(Remove(old_lines[i-1])); i -= 1;          // strictly-greater dp ↑
     elif cells[i*(m+1) + (j-1)] > cells[(i-1)*(m+1) + j]:
       ops.push(Add(new_lines[j-1])); j -= 1;             // strictly-greater dp ←
     elif old_lines[i-1] == new_lines[j-1]:
       ops.push(Same(old_lines[i-1])); i -= 1; j -= 1;    // tie + match → Same
     else:
       ops.push(Add(new_lines[j-1])); j -= 1;             // tie + no match → Add (pinned)
   ops.reverse()

5. Render:
   if ops.iter().all(|op| matches!(op, Same(_))):
     return "(no changes)\n".to_owned()  // contract preserved
   format each op with prefix: "  ", "- ", "+ "
   join with "\n", trailing "\n"
```

**Tie convention** (pinned A-C-3, rev2 corrected): strictly-greater dp neighbour wins first (`>` not `>=`). When both dp neighbours are equal AND the cells don't match → **Add** in backward walk; after reverse this yields **Remove-before-Add** in forward output (canonical `diff -u` order). When both dp neighbours are equal AND the cells DO match → Same (the equality short-circuit comes AFTER the strict-greater checks, so removing an old line at a position where a later match exists is preferred — this is what makes `"a\na\nb"` vs `"a\nb"` remove the SECOND `a`). Tests #4, #5, #6 pin exact strings against this convention.

enum DiffOp<'src> {
    Same(&'src str),
    Add(&'src str),
    Remove(&'src str),

/// Flat 2-D LCS table. Cells stored row-major: `cells[i*cols + j]`.
/// Single allocation, cache-friendly. `u16` is sufficient because for any
/// cell `dp[i][j] <= min(i, j) <= floor(sqrt(n*m)) <= floor(sqrt(MAX_DP_CELLS))
/// = floor(sqrt(100_000)) = 316`, well within `u16::MAX = 65_535`. A
/// `debug_assert!(dp_value < u16::MAX)` near the recurrence pins this.
struct DpTable {
    rows: usize,  // n + 1
    cols: usize,  // m + 1
    cells: Vec<u16>,
}

impl DpTable {
    fn new(rows: usize, cols: usize) -> Self { ... }
    fn get(&self, i: usize, j: usize) -> u16 { self.cells[i * self.cols + j] }
    fn set(&mut self, i: usize, j: usize, v: u16) { self.cells[i * self.cols + j] = v; }
}

    new: &[&'src str],

fn cap_fallback(old_lines: &[&str], new_lines: &[&str]) -> String

/// Returns (fp_count, fn_count, total_pos, total_neg).
fn measure(case: &AuditCase) -> (usize, usize, usize, usize) {
    let mut fp = 0;
    let mut fn_ = 0;
    let lookup = |input: &str| -> Option<String> {
        match case.measurement_mode {
            MeasurementMode::Rule => tayf::__test_api::match_named_rule(&case.rule_name, input),
            MeasurementMode::Pipeline => {
                tayf::__test_api::pipeline_spans(input, case.profile_context.as_deref())

                    .find(|(name, _)| name == &case.rule_name)
                    .map(|(_, span)| span)
            }
        }

        if lookup(input).as_deref() != Some(expected.as_str()) {
            fn_ += 1;
        }
    }
    for input in &case.negatives {
        if lookup(input).is_some() {
            fp += 1;
        }
    }
    (fp, fn_, case.positives.len(), case.negatives.len())
}

**Helper API (ratatui 0.30 correct API — R-C-1 fold):**

```rust
use ratatui::backend::TestBackend;
use ratatui::buffer::Buffer;
use ratatui::layout::Rect;
use ratatui::Frame;
use ratatui::Terminal;

use crate::config_tui::app::App;

/// Render bir `App` state'ini fixed-size TestBackend'e, buffer'ı plain-text
/// stringify et, snapshot golden'la karşılaştır.
///
/// `snap_name` is the snapshot file basename without `.snap` extension.
/// Snapshot files live in `src/config_tui/snapshots/<snap_name>.snap`.
///
/// `UPDATE_SNAPSHOTS=1` env var: regenerate the golden file (write `rendered`).
/// **CI guard (A-I-5 fold):** if `CI=true` env is set, helper refuses to
/// regenerate even when `UPDATE_SNAPSHOTS=1` — prevents silent golden
/// minting in CI runs.
///
/// Default: read golden, compare, panic on mismatch with LCS diff message.
pub(crate) fn assert_render_snapshot(
    width: u16,
    height: u16,
    app: &App,
    draw: impl Fn(&mut Frame, Rect, &App),
    snap_name: &str,
) {
    let backend = TestBackend::new(width, height);
    let mut terminal = Terminal::new(backend).expect("TestBackend init");
    terminal.draw(|f| draw(f, Rect::new(0, 0, width, height), app)).expect("draw");
    let rendered = stringify_buffer(terminal.backend().buffer());

    let abs_path = std::path::PathBuf::from(env!("CARGO_MANIFEST_DIR"))
        .join("src/config_tui/snapshots")
        .join(format!("{snap_name}.snap"));

    let update_requested = std::env::var("UPDATE_SNAPSHOTS").is_ok();
    let in_ci = std::env::var("CI").map(|v| v == "true" || v == "1").unwrap_or(false);

    if update_requested && in_ci {
        panic!(
            "UPDATE_SNAPSHOTS=1 refused under CI=true — golden minting only allowed locally"
        );
    }
    if update_requested {
        std::fs::write(&abs_path, &rendered).expect("write snapshot");
        eprintln!("UPDATED snapshot: {}", abs_path.display());
        return;
    }

    let expected = std::fs::read_to_string(&abs_path).unwrap_or_else(|_| {
        panic!(
            "snapshot not found: {} — rerun with UPDATE_SNAPSHOTS=1 to create",
            abs_path.display(),
        )
    });

    if rendered != expected {
        // Dogfood Item 5 LCS diff for the failure message.
        let diff = crate::config_tui::widgets::save_diff::build_diff(
            expected.as_bytes(),
            rendered.as_bytes(),
        );
        panic!(
            "render snapshot mismatch for {snap_name}:\n{diff}\n\
            re-run with UPDATE_SNAPSHOTS=1 to accept the new output"
        );
    }
}

fn stringify_buffer(buf: &Buffer) -> String {
    // R-C-1 fold: ratatui 0.30 API — `buf.area` field (not method),
    // `buf[(x, y)]` Index (not get). Verified against:
    //   tests/config_tui_conflict_list.rs:55-57
    //   tests/common/tui_harness.rs:49-75
    let area = buf.area;
    let mut out = String::with_capacity(
        usize::from(area.width).saturating_mul(usize::from(area.height).saturating_add(1)),
    );
    for y in 0..area.height {
        for x in 0..area.width {
            out.push_str(buf[(x, y)].symbol());
        }
        out.push('\n');
    }
    out
}
```
