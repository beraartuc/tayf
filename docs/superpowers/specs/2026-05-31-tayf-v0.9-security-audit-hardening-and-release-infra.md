## §4 — Kapsam: dört faz

### Faz A — Hardening & adversarial test altyapısı (TDD, subagent-driven)

**A1 — Fuzzing harness (cargo-fuzz + checked-in regression; Karar 4 hybrid).**
- `fuzz/` ayrı cargo-fuzz workspace (libFuzzer, nightly toolchain). Ürün crate'in dependency tree'sini ETKİLEMEZ (ayrı `fuzz/Cargo.toml`, workspace exclude).
- ~4 target:
  1. `ansi_sm` — `AnsiSm` byte-by-byte feed; chunk-boundary CSI/OSC/DCS/SOS-PM-APC split; cap (`SEQUENCE_BYTES_CAP`) fire; invariant: panic yok, state machine her byte'ı tüketir, ground'a döner.
  2. `line_buffer` — `feed_data_run` + overflow path; invariant: 64 KB cap aşılmaz, panic yok, UTF-8 split'te invalid-slice yok.
  3. `pipeline_feed` — full `Pipeline::feed`; **differential oracle:** kurallar boşken (no rules) çıktı girdiyle **byte-identical** olmalı (passthrough invariant). Ayrıca: hangi kural seti olursa olsun, çıkış asla orijinalin getirmediği bir escape-sequence introduce etmemeli (sadece SGR + kesin reset).
  4. `regex_compile` — user-pattern derleme; arbitrary pattern string `RegexBuilder` + `size_limit`/`dfa_size_limit` altında; invariant: derleme ya başarılı ya temiz hata, panic/timeout/OOM yok.
- Commit'li **seed corpora** (`fuzz/corpus/<target>/`); minimal başlangıç + edge-case seed'leri.
- **Crash → kalıcı regresyon:** bulunan her crash input'u `tests/` altında stable (`cargo test`, nightly gerektirmez) bir regresyon testine indirgenir. Fuzzing keşif, `tests/` koruyucu.
- **CI:** kısa nightly fuzz smoke job (örn. her target 60s); regresyon kapısı, derin keşif değil. Derin keşif local (manuel `cargo fuzz run`).
- **Fuzz erişim notu (spec-faz alt-kararı):** `AnsiSm` / `LineBuffer` / pipeline internal'leri şu an `pub` olmayabilir. Fuzz target'ları lib'e erişim ister. Stable public API'yı genişletmemek için (CLAUDE.md §4): bir `fuzzing` feature flag arkasında `#[doc(hidden)] pub` re-export VEYA `pub(crate)` + fuzz workspace'in `--cfg fuzzing` ile derlenmesi değerlendirilecek. Karar: paralel Rust-senior review + plan fazı.

**A2 — Adversarial regression testleri (stable, `tests/`).**
- partial-CSI-split: CSI/OSC dizisi her byte sınırında bölünüp ayrı chunk'larla beslenince doğru parse + chunk-boundary byte-identity.
- escape-sequence flood: tek satırda binlerce kısa OSC/SGR; cap + drain davranışı; bellek sınırlı.
- SGR-line stress: `respect_existing_colors` true/false altında SGR-yoğun satır; passthrough vs apply doğruluğu.
- panic-in-output-thread integration: output thread'de panic tetiklenince child shell termios'u (echo/line-discipline) restore ediliyor mu (panic-hook fallback fiilen test).
- signal-to-foreground-process-group integration: shell altında foreground subprocess'e SIGINT/SIGTERM grup'a ulaşıyor mu, orphan kalıyor mu.
- Recon ajanı bu boşlukları "PARTIAL/ABSENT" işaretledi; her test [feedback-test-assertion-specificity] ile byte/wording-pinned, loose `contains` yok.

**A3 — Adversarial ReDoS bench.**
- `benches/` criterion bench: pathological input (uzun no-newline satır, built-in pattern'lerin worst-case girdileri, 1 MiB limit altı yapay-karmaşık user pattern) matcher'a beslenir; linear-time davranış ampirik gösterilir (girdi 2× → süre ~2×, exponential değil).
- Mevcut `[[bench]]` setine (`throughput`, `e2e_overhead`, `pipeline_feed`) yeni bir `[[bench]]` olarak veya `throughput`'a grup olarak eklenir (plan fazı karar).
- Sayılar → `benches/BASELINE.md` v0.9 bölümü, **transcribe-discipline** ([feedback-transcribe-measured-numbers]): tee → Read → commit-öncesi digit-for-digit verify. Bellekten yazma yasak.

**A4 — cargo-deny hardening + dep dedup.**
- `[bans] multiple-versions = "deny"`; indirgenemez transitive duplicate'ler için belgeli `skip`/`skip-tree` exception (hashbrown 0.16/0.17, bitflags 1/2 — kaynağı transitive, doğrudan çözülemiyorsa rationale ile skip).
- `[advisories]` `unmaintained = "deny"` (veya "warn"→ölçülüp karar) + `unsound = "deny"` eklenir; `yanked = "deny"` korunur.
- `[sources]` zaten sıkı (`unknown-registry`/`unknown-git` = deny) — korunur.
- Mümkün olan dep dedup (Cargo.lock güncellemesi) — sadece gerçekten indirgenebilenler; aksi skip + rationale.
- `cargo deny check` lokal + CI'da green olmalı.

## §7 — Test stratejisi

- **TDD per feature** ([test-driven-development]): test-first, RED, GREEN, commit. Lean cycle'da bile atlanmaz.
- **Differential oracle (fuzz):** pipeline no-rules passthrough = byte-identity; injection-only-SGR invariant. Bunlar fuzz target'ın property assertion'ları.
- **Stable regresyon corpus:** her fuzz-crash → `tests/` altı stable test (nightly gerektirmez), CI-native koruyucu.
- **Assertion specificity** ([feedback-test-assertion-specificity]): error/Display/wording testleri byte-pinned + negatif regression guard; loose `contains` yok.
- **Transcribe-discipline** ([feedback-transcribe-measured-numbers]): tüm bench/fuzz/timing sayıları tee'd run-file'dan digit-for-digit, commit-öncesi verify.
- **Local pre-commit:** `cargo fmt && cargo clippy -- -D warnings && cargo test` + (fuzz target'lar için) `cargo +nightly fuzz build`.
