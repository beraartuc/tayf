## 1. Motivasyon

**N-1 carryover neden v0.5.0.** v0.4.1 final review §N-1 GHA-level uyarısı şunu dile getiriyor:

> Node.js 20 actions are deprecated. ... `actions/upload-artifact@v4` ... Actions will be forced to run with Node.js 24 by default starting June 2nd, 2026.

Escape hatch `ACTIONS_ALLOW_USE_UNSECURE_NODE_VERSION=true` opt-in env var, auto-safety net değil. v0.4.1 review "v0.5'in earliest infra-touching commit'inde fold" önerdi; **v0.5.0 İş A = Commit 1** bu fold'u uygular. 2026-05-25 itibarıyla cutoff'a 8 gün; risk-managed timing (§7).

**Bump hedefi correction.** v0.4.1 review §N-1 `@v5`'i "published successor" olarak nitelendirdi. v0.5 spec phase'inde release history verified:
- **v4** (current in workflow): Node 20.
- **v5**: Node 20 (yine). Deprecation uyarısını **temizlemez**.
- **v6.0.0**: Node 24'e geçiş (`runs.using: node24`, requires runner ≥ 2.327.1).
- **v7.0.1** (current, 2026-04-10): published current major.

**`@v5` yanlış hedef.** Bumb hedefi `@v7` (major-track pin, GHA convention) veya `@v7.0.1` (exact pin, supply-chain-conscious). Spec §2.1 major-track `@v7` önerir; security-conscious exact pinning v0.5.1+ post-task. v0.4.1 review §N-1 retroactive one-line correction note alır (v0.5.0 post-tag, ayrı commit).

**Capture-group naming neden v0.5.0.** v0.3.5 positional capture-group styling shipped (`styles."1" = {...}`); v0.5 umbrella §3.1 named-key extension. Named-key user-config readability'sini artırır (`styles.scheme` self-documenting vs `styles."1"`); built-in retrofit "what's group 1?" araştırmasını ortadan kaldırır (TOML key zaten dokümante). Compile-time resolution = **zero runtime delta** — v0.3.5 hot path (`captures.get(idx)`) byte-identical korunur; named keys compile-time'da `regex.capture_names()` üzerinden index'e çevrilir.

Foundational v0.5.1+ için: profile system rules de aynı TOML grammar'ı kullanır; capture-group naming v0.5.0'da locked olunca profile schema brainstorm'unda inherit edilir.

### 2.3 İş C — Dispatch order + named resolution (Rust senior I-1 absorb)

`resolve_group_styles_for_rule` ([src/rules.rs:901-1011](src/rules.rs#L901)) — TOML key resolution order **explicit ve fall-through yok**:

```rust
// Spec-level pseudocode — gerçek shape implementation pass'inde pin'lenir.
for (key, user_style) in map {
    // Step 1: literal "0" → group-zero forbidden (existing behavior).
    if key == "0" {
        emit_zero_forbidden(rule, source, ...);
        continue;
    }

    // Step 2: all-digit key → positional path (existing grammar gate).
    if key.bytes().all(|b| b.is_ascii_digit()) {
        match crate::config::validate_styles_map_key(key) {
            Some(idx) => {
                resolve_positional(idx, captures_len, ...);
            }
            None => {
                // "01" — KeyMalformed. DO NOT fall through to named.
                // Preserves v0.3.5 grammar: integration_capture_groups.rs:385
                // regression-guarded.
                emit_key_malformed(key, ...);
            }
        }
        continue;
    }

    // Step 3: non-numeric key → named resolution.
    // Compile-time `regex.capture_names()` lookup (no caching needed;
    // config-parse time, not hot path).
    match resolve_named(key, regex.capture_names()) {
        Some(idx) => {
            // Check duplicate-target invariant before assigning.
            resolve_via_index(idx, ...);
        }
        None => {
            let available: Vec<String> = regex.capture_names()
                .filter_map(|opt| opt.map(String::from))
                .collect();
            emit_name_unknown(key, available, ...);
        }
    }
}
```

**Key invariants (I-1 absorb):**
- Step 2 None branch (`"01"`) **never falls through** to Step 3. Existing `tests/integration_capture_groups.rs:385` regression-guarded (`CaptureGroupKeyMalformed`, NOT `CaptureGroupNameUnknown`).
- Step 3 only runs if Step 2's `all_ascii_digit()` returned false. `"foo"` directly enters Step 3.
- `available` Vec (I-2 absorb) regex `capture_names()` positional order (left-to-right), `None` filtered out. **NOT** alphabetical, **NOT** hash-order. (E.g., `url` rule's `available = ["scheme", "sep", "body"]` — pattern source order; `timestamp` rule's `available = ["date", "sep", "time", "ms", "tz"]` — ISO branch source order. Other 3 timestamp branches contribute no names; their absence is by construction, no special-case.)

**Compile-time name → index map.** Inline in `resolve_group_styles_for_rule` per Rust senior N-3 absorb (caching gerekmez — config-parse time, hot path değil). Implementation Task 3 detail.

**Duplicate target detection.** Track which capture-group indices have been assigned during this rule's `for` loop iteration; if a second key resolves to an already-assigned index → `CaptureGroupDuplicateTarget` error. Decision rule: at the moment second key resolves to occupied slot, emit error; report both keys (positional + named, regardless of which came first in iteration). Test §5.2 #6.

### 2.4 İş D — Error variants + Display (Rust senior I-2 + I-3 absorb)

**Two new `ThemeRuleErrorKind` variants** ([src/error.rs](src/error.rs)), additive on `#[non_exhaustive]` enum:

```rust
#[non_exhaustive]
pub enum ThemeRuleErrorKind {
    // ... existing variants ...

    /// User TOML key references a regex group name that does not exist in
    /// the rule's compiled regex. `available` lists actual named groups in
    /// the regex's `capture_names()` positional order (left-to-right,
    /// `None` filtered out). Empty `available` means the regex has no
    /// named groups at all.
    CaptureGroupNameUnknown {
        name: String,
        available: Vec<String>,
    },

    /// User TOML defines two keys (one numeric, one named) that resolve to
    /// the same capture-group index. Set exactly one.
    CaptureGroupDuplicateTarget {
        positional: String,
        named: String,
    },
}
```

**Display impl byte-pinned (I-2 absorb).** Three exact strings, no `.contains()`-based test assertions:

`CaptureGroupNameUnknown` with non-empty `available`:

```
styles."foo": rule's regex has no capture group named 'foo' (available: scheme, sep, body)
```

`CaptureGroupNameUnknown` with empty `available` (regex has zero named groups):

```
styles."foo": rule's regex has no named capture groups
```

`CaptureGroupDuplicateTarget`:

```
styles."1" and styles.date target the same capture group (index 1); set exactly one
```

(Field values: `positional = "1"`, `named = "date"`; index resolution = positional value parsed as usize.)

**Available list join format:** comma-space separator (`scheme, sep, body`), no trailing punctuation. Pin'lendi byte-exact tests'le.

**Duplicate-formatter audit (I-3 absorb).** `resolve_group_styles_for_rule`'un her iki path'i:
- **Theme path** (`Error::ThemeValidation` envelope): `theme_errors.push(ThemeRuleError { ... kind: ThemeRuleErrorKind::CaptureGroupNameUnknown { ... }, ... })`. Envelope render time'da `kind.to_string()` çağırır → Display impl.
- **UserConfig path** (`Error::Config` envelope): `format!("rule '{}': {kind}", rule.name)` where `{kind}` Display interpolation → aynı Display impl.

Her iki path'in diagnostic string'i envelope dışında **byte-identical** olur. v0.3.7 dersi (UserConfig inline format'ı Theme path'inden divergence) tekrarlanmaz. Regression test §5.3.
