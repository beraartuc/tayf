## §1 — Özet

## §4 — CLI surface

### §4.1 — clap derive shape

Mevcut flat `Args` struct'ı `RunArgs` olarak yeniden adlandır; kök `Args` struct'ı `RunArgs`'ı `#[command(flatten)]` ile gömer + `Option<Cmd>` subcommand taşır.

```rust
// src/cli.rs (v0.5.4 refactor)

use clap::{Args as ClapArgs, Parser, Subcommand, ValueEnum};

#[derive(Debug, Parser)]
#[command(name = "tayf", author, version = version_str(), about, long_about = None)]
#[non_exhaustive]
pub struct Args {
    /// When no subcommand is given, run the PTY wrapper with these flags.
    #[command(flatten)]
    pub run: RunArgs,

    #[command(subcommand)]
    pub cmd: Option<Cmd>,
}

#[derive(Debug, ClapArgs)]
#[non_exhaustive]
#[allow(clippy::struct_excessive_bools)]
pub struct RunArgs {
    /// Override the shell to launch.
    #[arg(long, value_name = "PATH")]
    pub shell: Option<PathBuf>,

    /// Spawn the shell as a login shell.
    #[arg(long, default_value_t = false)]
    pub login: bool,

    // ... (mevcut tüm field'lar — no_color, config, theme, profile, bypass, no_hot_reload)
}

#[derive(Debug, Subcommand)]
#[non_exhaustive]
pub enum Cmd {
    /// Interactive TUI for browsing and editing tayf config.
    Config(ConfigArgs),
}

#[derive(Debug, ClapArgs)]
#[non_exhaustive]
pub struct ConfigArgs {
    #[command(subcommand)]
    pub action: Option<ConfigAction>,
}

#[derive(Debug, Subcommand)]
#[non_exhaustive]
pub enum ConfigAction {
    /// Write built-in pattern/theme/profile catalog to stdout as TOML.
    Dump(DumpArgs),
    /// Print resolved config state + hot-reload event log tail.
    Status,
}

#[derive(Debug, ClapArgs)]
pub struct DumpArgs {
    /// Restrict dump to one section (default: all of patterns/themes/profiles).
    #[arg(long, value_enum)]
    pub kind: Option<DumpKind>,
}

#[derive(Debug, Clone, Copy, ValueEnum)]
pub enum DumpKind {
    Patterns,
    Themes,
    Profiles,
}
```

### §4.2 — Dispatch (src/main.rs)

```rust
fn main() -> ExitCode {
    match Args::try_parse_from_env() {
        Ok(args) => match args.cmd {
            None => match Tayf::run(args.run) {
                Ok(code) => code,
                Err(err) => { eprintln!("tayf: {err}"); ExitCode::from(map_error_to_exit_code(&err)) }
            },
            Some(Cmd::Config(cfg)) => match cfg.action {
                None => config_tui::run(args.run),
                Some(ConfigAction::Dump(dump)) => config_tui::dump(dump.kind),
                Some(ConfigAction::Status) => config_tui::status(args.run),
            },
        },
        Err(e) => { /* mevcut clap error handling */ }
    }
}
```

### §4.3 — Backward compat invariants + acknowledged API break

**Runtime behavior byte-identical:**
- `tayf` (no subcommand) tüm mevcut flag'lerle çalışır. `tests/integration_smoke.rs` byte-identical diff = 0.
- `--config` / `--theme` / `--profile` kök seviyede `RunArgs`'a flatten'lı → `tayf --theme dark` mevcut byte-identical çalışır, AYNI ZAMANDA `tayf --theme dark config` da çalışır (subcommand + flag birlikte). Kök flag'ler subcommand çağrıldığında TUI'ye **base context** olarak geçer (which config to load + initial theme/profile to highlight as active).
- `--profile foo --profile bar` duplicate detection clap default → memory `feedback_clap_error_wording_with_value_name` aktif; mevcut v0.5.2 test (`cli_profile_arg_parses_as_option_string` sub-assertion 3) byte-identical pass eder.

**Acknowledged public API break (C-3 fold):**

`src/lib.rs:72` currently has `pub use cli::Args;` with `pub` fields `args.shell`, `args.theme`, etc. The §4.1 refactor moves these into `args.run.shell`, `args.run.theme`, etc. This **is** a public-API break (`cargo public-api` diff will report the field-path move). Per CLAUDE.md §4 "Breaking changes require... CHANGELOG entry":

- v0.5.4 CHANGELOG MUST include `### Changed (breaking)` entry naming the `Args::shell` → `Args::run.shell` (and all `RunArgs`-flattened fields) migration.
- Defensible pre-1.0: tayf-as-library use case is `Tayf::run(args)` only; no known downstream consumer; field-path is an internal detail of the CLI parser the binary uses.
- Alternative considered + rejected: accessor-shim layer (`impl Args { pub fn shell(&self) -> ... }` for every flag, ~30 LOC). Rejected because (a) pre-1.0 API stability isn't the goal yet, (b) the shim creates a parallel surface that downstream would still need to migrate from in v1.0.
- Mevcut tüm `src/cli.rs::tests` test'leri field path migrate edilir (`args.shell` → `args.run.shell`). Test migration tek-PR change (Phase A2).

### §4.4 — Exit codes

| Invocation | Success | Failure |
|---|---|---|
| `tayf` (PTY wrapper) | child shell exit code | mevcut mapping (`src/main.rs::map_error_to_exit_code`) |
| `tayf config` (TUI) | 0 (clean exit, `q` veya Ctrl+C) | 70 (EX_SOFTWARE) — terminal render error / unrecoverable ratatui state |
| `tayf config dump` | 0 (TOML written) | 64 (EX_USAGE) — invalid `--kind`; 70 — serialize bug (unreachable, test-pinned) |
| `tayf config status` | 0 (status fully resolved + printed) | **64 (EX_USAGE)** — config parse error; partial status still printed to stdout (UNIX idiom: non-zero exit does not preclude stdout) |

**`config status` exit policy (I-10 fold):** Earlier draft proposed exit 0 always (always-partial-info). Revised: exit non-zero on user error so `tayf config status && echo ok` works in scripts. Stdout still prints the partial state (resolved fields show value, unresolved fields show `(unresolved: <reason>)`). Stderr gets the warning line. Behavior matches rest of tayf CLI surface (`tayf`, `tayf config dump` both EX_USAGE on user config error).

## §7 — Event loop + rendering pipeline

### §7.1 — Single-thread event loop

```rust
// src/config_tui/events.rs

pub(crate) fn run_event_loop(
    mut app: App,
    mut terminal: Terminal<CrosstermBackend<Stdout>>,
) -> Result<()> {
    while !app.should_quit {
        terminal.draw(|frame| render::frame(frame, &app))?;
        if crossterm::event::poll(Duration::from_millis(100))? {
            match crossterm::event::read()? {
                Event::Key(k) if k.kind == KeyEventKind::Press => dispatch_key(&mut app, k),
                Event::Resize(_, _) => { /* ratatui auto-recalcs on next draw */ }
                Event::Mouse(_) | Event::Paste(_)
                | Event::FocusGained | Event::FocusLost | Event::Key(_) => {}
            }
        } else {
            check_debounce(&mut app);
        }
    }
    Ok(())
}
```

### §7.2 — Key dispatch order

1. **Modal absorbs ALL keys** except: `Esc` (close modal), `Ctrl+C` (force quit — routes to quit-confirm modal stacking-replacement, see §12.1.1). All other global keys (including `Ctrl+S`, `?`, `P`, `F`, `s`, `/`) are **ignored** while a modal is open. Implementer guidance: rely on this rule to keep tab/global handlers simple; don't expose escape hatches.
2. **No modal stacking** — `App.modal` is `Option<Modal>`. Opening a new modal while one exists is a programmer bug; debug-assert. In practice the FSM never opens a second modal because every modal-opening key path is itself guarded by `modal.is_none()`.
3. **Global keys** (when `modal.is_none()`) — `q`, `Ctrl+C`, `Ctrl+S`, `?` / `F1`, `P` (preview toggle), `Shift+P` (full-preview — renamed from `F` to dodge F-key reliability + short-tab letter collision, see UX revision §12.1), `s` (sample set), `/` (search), `Esc` (no-op when no modal).
4. **Tab routing** — `Tab` / `Shift+Tab` / `1`-`4` direct.
5. **Tab-internal** — `app.tab` enum match → `tabs::<tab>::dispatch_key(&mut app, k)`.

### §7.3 — Render composition

```rust
// src/config_tui/render.rs

pub(crate) fn frame(frame: &mut Frame, app: &App) {
    let size = frame.size();

    // Narrow-terminal degradation gate (§7.4)
    if size.width < 60 || size.height < 16 {
        render_too_small(frame, size, app.terminal_caps);
        return;
    }

    let preview_visible = app.mini_preview_visible(size);
    let preview_rows = if preview_visible { 5 } else { 0 };

    let chunks = Layout::vertical([
        Constraint::Length(1),                        // tab strip
        Constraint::Min(10),                          // main pane
        Constraint::Length(preview_rows),             // mini-preview (collapsible)
        Constraint::Length(1),                        // status bar
    ]).split(size);

    render_tab_strip(frame, chunks[0], app);
    match app.tab {
        Tab::Patterns => tabs::patterns::render(frame, chunks[1], app),
        Tab::Themes   => tabs::themes::render(frame, chunks[1], app),
        Tab::Profiles => tabs::profiles::render(frame, chunks[1], app),
        Tab::Status   => tabs::status::render(frame, chunks[1], app),
    }
    if preview_visible {
        widgets::preview::render_mini(frame, chunks[2], app);
    }
    render_status_bar(frame, chunks[3], app);

    if let Some(modal) = &app.modal {
        widgets::render_modal(frame, size, modal, app);
    }
}
```

### §7.5 — RAII terminal restore

```rust
// src/config_tui/mod.rs

pub(crate) fn run(args: RunArgs) -> ExitCode {
    let _guard = TuiGuard::enter()?;  // enable raw mode + enter alt-screen
    let backend = CrosstermBackend::new(stdout());
    let terminal = Terminal::new(backend)?;
    let app = init_app(args)?;
    match events::run_event_loop(app, terminal) {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => { eprintln!("tayf config: {e}"); ExitCode::from(70) }
    }
    // _guard.drop() → disable raw mode + leave alt-screen
}

struct TuiGuard;
impl TuiGuard {
    fn enter() -> Result<Self> {
        enable_raw_mode()?;
        execute!(stdout(), EnterAlternateScreen)?;
        Ok(Self)
    }
}
impl Drop for TuiGuard {
    fn drop(&mut self) {
        let _ = execute!(stdout(), LeaveAlternateScreen);
        let _ = disable_raw_mode();
    }
}
```

Panic safety: `std::panic::set_hook` ekstra hook restore terminal (CLAUDE.md §3 — "on any exit path, terminal state MUST be restored"). Mevcut `src/tty_guard.rs` pattern'ı mirror.

## §8 — Save semantics + hot-reload coexistence

### §8.1 — D1 save flow (full detail)

**Trigger** — `Ctrl+S` global. Edit field içindeyken `Enter` field commit eder, sonra global `Ctrl+S` save modal aç.

**SaveDiff modal açma:**

```
1. let disk_now: Vec<u8> = fs::read(snapshot.source_path)?;
2. let disk_hash = sha256(&disk_now);
3. mode = if disk_hash == snapshot.source_hash {
       SaveDiffMode::Clean { tui_diff: render_diff(&snapshot.raw_bytes, &serialize(app)) }
   } else {
       SaveDiffMode::Conflict {
           tui_diff: render_diff(&snapshot.raw_bytes, &serialize(app)),
           manual_diff: render_diff(&snapshot.raw_bytes, &disk_now),
           disk_now,
       }
   };
4. app.modal = Some(Modal::SaveDiff(SaveDiffState { mode, .. }));
```

**Modal key dispatch:**

| Mode | Key | Action |
|---|---|---|
| Clean | `y` | `commit_save(...)` (commit flow §8.1) |
| Conflict | `y` (first press) | Updates modal to merged-preview view (3rd diff panel, ~10 line + scroll) — kullanıcı reconcile sonucunu görür (UX #5 fold) |
| Conflict | `y` (second press, post-preview) | `commit_save(...)` actually commits |
| Conflict | `m` (first press) | Opens secondary "Discard TUI changes and reload disk? [y/N]" confirm overlay (UX #4 fold — destructive action requires explicit second confirm; **default = N**) |
| Conflict | `m` confirm `y` | `app.snapshot = read_from_disk_now()?; app.edits = PendingEdits::default();` modal close; preview recompile |
| Conflict | `m` confirm `n` / `Esc` | Confirm overlay close; SaveDiff modal stays |
| Both | `n` / `Esc` | Modal close, no change |
| Both | `↑` / `↓` | Diff scroll (uzun diff'lerde) |

**Commit flow** (post-revision per Rust senior I-1, I-2, I-3 + UX #5 fold):

```
0. (conflict-y only — UX #5 fold) Compute merged result preview:
     let preview_content = build_new_content(mode, &app);
   Update modal to "merged preview" 3rd panel with diff(snapshot, preview_content)
   limited to ~10 lines + scroll. User confirms second 'y' → continue to step 1.

1. rotate_backups_to(cfg_dir, target_max = MAX_BACKUPS - 1 = 4);  // I-3 fold:
                                                                  // rotate BEFORE
                                                                  // backup write
                                                                  // so quota safety
                                                                  // is correct.
                                                                  // read_dir failure
                                                                  // → Toast::warn,
                                                                  // save proceeds.

2. let backup_path = format!("{}.tayf-backup-{}",
                              cfg_stem,
                              ts_for_backup_filename(now()));    // N-3 fold:
                                                                  // explicit helper
                                                                  // name, testable
                                                                  // fixture-pinning.
   fs::write(&backup_path, &disk_now_bytes)?;                    // (disk_now zaten
                                                                  // okundu; Clean
                                                                  // mode'da raw_bytes
                                                                  // ile identical.)

3. let new_content: String = build_new_content(mode, &app);     // re-uses step-0
                                                                  // result if cached.

4. // I-2 fold: mode preservation via OpenOptionsExt — preserve target's perms
   // so user-set 0o600 isn't silently relaxed to 0o644 by umask default.
   let preserved_mode: u32 = fs::metadata(&cfg_path)
       .map(|m| m.permissions().mode() & 0o777)
       .unwrap_or(0o600);  // default tight for new file creation
   let tmp_path = format!("{}.tayf-tmp-{}-{}", cfg_path, pid, ms_filename_safe);
   debug_assert_eq!(tmp_path.parent(), cfg_path.parent(),
                    "tmpfile MUST be in target's parent dir (EXDEV safety)");
   let mut tmp = TmpFileGuard::create_in_parent_dir(
       &tmp_path,
       preserved_mode,
   )?;                                          // I-2 fold: RAII Drop guard
                                                // unlinks tmpfile on every
                                                // error path until persist()
                                                // is called. ~30 LOC custom
                                                // guard in save.rs (no new
                                                // prod dep; tempfile already
                                                // dev-dep but custom guard
                                                // keeps deps minimal per
                                                // feedback_dependency_minimalism).
   tmp.write_all(new_content.as_bytes())?;
   tmp.sync_all()?;                             // I-1(a) fold: sync_all not
                                                // sync_data — fdatasync misses
                                                // metadata flush load-bearing
                                                // for ext4 data=writeback.

5. tmp.persist(&cfg_path)?;                    // atomic POSIX rename; Drop
                                                // guard disarms. EXDEV
                                                // impossible by §4 invariant.

6. // I-1(c) fold: parent dir sync_all — macOS APFS behavior here is
   // famously underdocumented; treat as best-effort, log on fail.
   if let Ok(dir) = File::open(cfg_dir) {
       if let Err(e) = dir.sync_all() {
           log_warn!("parent dir sync_all failed: {e} (rename completed; \
                      durability across crash is best-effort on APFS)");
       }
   }

7. app.snapshot = ConfigSnapshot {
       source_path: Some(cfg_path),
       source_hash: sha256(new_content.as_bytes()),
       raw_bytes: new_content.into_bytes(),
       doc: toml_edit::DocumentMut::from_str(&new_content)?,    // re-parse
       parsed: re_parse(&new_content)?,
   };
   app.edits = PendingEdits::default();
   app.toast = Some(Toast::ok("Saved. Hot-reload will pick this up shortly."));
```

**Invariants pinned:**
- **EXDEV safety**: `tmp_path.parent() == cfg_path.parent()` always — debug-assert + test in §10.2 row `save.rs`. Tmpfile naming co-locates by construction.
- **`sync_all` not `sync_data`**: fdatasync (sync_data) misses metadata; ext4 `data=writeback` can lose size after crash-replay. Use sync_all (fsync) per SQLite atomic-commit folklore.
- **Mode preservation**: tmpfile created with target's existing mode (snapshot before open), preserving user-set perms like `0o600`. Default to `0o600` when target doesn't exist (new file creation case).
- **TmpFileGuard RAII**: ~30 LOC guard in `save.rs` — `Drop` impl `unlink`s tmpfile unless `persist()` called. Eliminates leak between create_new and rename on panic. Alternative considered: `tempfile` prod dep — rejected to keep dep surface tight; tempfile already used as dev-dep for tests but bringing it into prod is one more crate per `feedback_dependency_minimalism`.
  - **API contract (Rust senior re-review nit):**
    ```rust
    struct TmpFileGuard {
        path: PathBuf,                  // tmp file location
        file: Option<File>,             // None after persist() consumes
        persisted: bool,                // set by persist(); Drop checks this
    }
    impl TmpFileGuard {
        fn create_in_parent_dir(tmp: &Path, mode: u32) -> io::Result<Self>;
        fn write_all(&mut self, bytes: &[u8]) -> io::Result<()>;
        fn sync_all(&mut self) -> io::Result<()>;
        fn persist(mut self, target: &Path) -> io::Result<()>;  // consumes self
    }
    impl Drop for TmpFileGuard {
        fn drop(&mut self) {
            if !self.persisted {
                let _ = fs::remove_file(&self.path);  // best-effort unlink
            }
        }
    }
    ```
    `persist(self, target)` consumes the guard (by value) and sets `persisted = true` before rename; Drop then no-ops the unlink. Any panic or `?`-bail between `create_in_parent_dir` and `persist` triggers Drop which unlinks the orphan tmpfile.
- **Merge collision** (I-6 fold): conflict-y `apply_edits_to_doc` operates on `RuleId` keys. Same-name `UserConfig(name)` collision = TUI #1 edits clobber TUI #2 addition silently. **Documented as last-writer-wins by-key** + new test `merge_collision_user_config_name_clobbers_silently` in §10.2 row `save.rs`. v0.6+ may add per-key conflict UI; v0.5.4 honest documentation only.

### §8.2 — Error paths

**Toast vs Modal::Error policy (🔵 #3 fold):**
- **Toast** = non-blocking, auto-dismiss 3s. Used for save success + non-fatal save warnings (e.g. fsync_dir failure where rename completed; rotation `read_dir` failure).
- **Modal::Error** = blocking, requires `Esc` to dismiss. Used for save failures requiring user attention (perm denied; toml_edit reconcile failure; post-save reparse failure).

| Hata noktası | Davranış |
|---|---|
| `rotate_backups_to(...)` `read_dir` fails | `Toast::warn("Backup rotation skipped: <reason>")`. Save proceeds (backup write step independent). |
| `fs::write(&backup_path, ...)` fails | Abort BEFORE tmpfile. `Modal::Error("Backup failed: <reason>. Aborting save to protect data.")`. Modal stays open (replaces SaveDiff). |
| `TmpFileGuard::create_in_parent_dir(...)` fails | `Modal::Error("Save failed: tmpfile create: <reason>")`. Backup zaten yazıldı (recoverable). SaveDiff modal closes; Error replaces. |
| `tmp.write_all(...)` veya `tmp.sync_all()` fails | `Modal::Error("Save failed: write: <reason>")`. TmpFileGuard drop'u tmpfile'ı unlink eder. Backup kalır. SaveDiff modal closes; Error replaces. |
| `tmp.persist(...)` (rename) fails | `Modal::Error("Atomic rename failed: <reason>")`. TmpFileGuard drop'u unlink. Snapshot unchanged. SaveDiff modal closes; Error replaces. |
| `dir.sync_all()` fails | Logged via `TAYF_LOG=warn` (stderr); save sayılır (rename completed). `Toast::ok("Saved (parent dir fsync best-effort).")` |
| `apply_edits_to_doc` fails (toml_edit reconcile error in Conflict-y path) | `Modal::Error(format!("Merge conflict: {e}. See backup at {backup_path}. Try Edit → Save again, or 'm' to discard TUI edits and reload disk."))`. SaveDiff modal closes; Error replaces. |
| `re_parse` after save fails (theoretically impossible — we just wrote valid TOML) | `Modal::Error("Post-save reparse failed (file integrity check). File integrity may be compromised; verify manually.")`; snapshot reverted to in-memory pre-save state. |

### §8.3 — Backup rotation

- **Naming**: `<cfg-stem>.tayf-backup-<rfc3339-ms-filename-safe>` örn. `config.toml.tayf-backup-2026-05-26T17-18-42-123Z`. Colon (`:`) `-` ile substitute edilir (Windows v1.0+ forward-friendly). Helper `ts_for_backup_filename(now: SystemTime) -> String` `save.rs`'te isolated, test'le fixture-pin'lenir.
- **Discovery**: `fs::read_dir(cfg_dir)` + filter `starts_with(format!("{cfg_stem}.tayf-backup-"))`.
- **Sort**: by `metadata.modified()` desc.
- **Rotation order (I-3 fold):** ROTATE FIRST (down to `MAX_BACKUPS - 1 = 4`), THEN write new (5th) backup. Eski sıra (write Nth then rotate to keep N) quota-tight kullanıcılarda silent fail (write OK, rotate fail) sonra unbounded growth. Yeni sıra: rotation fail olursa save proceeds (Toast::warn), backup count may exceed 5 — daha güvenli failure mode.
- **`read_dir` failure path:** `Toast::warn("Backup rotation skipped: <reason>")`. Save still proceeds (write step independent). Eventual unbounded growth flagged by reload.log warn cadence; v0.6+ rotation hardening.
- **Max retention** config-lenebilirlik (`[general] backup_max = N`) v0.6+'a defer. v0.5.4 constant `MAX_BACKUPS: usize = 5`.
- **Test**: `5 existing backups → save → still 5 (newest is just-written, eldest unlinked)`.

### §8.5 — `reload.log` event file infra

**Wrapper side** (`src/reload.rs` additive ~80 LOC):

```rust
pub(crate) struct ReloadLogger {
    state_dir: PathBuf,  // <cfg-dir>/runtime/
    enabled: bool,        // false if state_dir create failed at startup
}

impl ReloadLogger {
    pub(crate) fn new(cfg_dir: &Path) -> Self {
        let state_dir = cfg_dir.join("runtime");
        let enabled = fs::create_dir_all(&state_dir).is_ok();
        Self { state_dir, enabled }
    }

    pub(crate) fn append(&self, event: ReloadEvent) {
        if !self.enabled { return; }
        let line = format!("{} reload #{} {}\n",
            event.ts_rfc3339(),
            event.reload_count,
            event.outcome_str());
        let log_path = self.state_dir.join("reload.log");
        let _ = OpenOptions::new()
            .create(true).append(true).open(&log_path)
            .and_then(|mut f| f.write_all(line.as_bytes()));
        // Best-effort; failures logged via TAYF_LOG=warn but don't block reload.
    }
}

pub(crate) struct ReloadEvent {
    pub(crate) timestamp: SystemTime,
    pub(crate) reload_count: u64,
    pub(crate) outcome: ReloadOutcome,
}

pub(crate) enum ReloadOutcome {
    Ok,
    Err(String),
}
```

`ReloadOrchestrator::run()` her başarılı reload'da `logger.append(...)` çağrısı ekler. Mevcut precedence snapshot pattern (memory `feedback_reload_precedence_snapshot`) — logger create startup'ta yapılır, daha sonra new'lenmez (snapshot disiplinine paralel).

**Status reader side** (`src/config_tui/status_cmd.rs`):

```rust
pub(crate) fn read_recent_events(state_dir: &Path, n: usize) -> Vec<ReloadEvent> {
    let log_path = state_dir.join("reload.log");
    let content = match fs::read_to_string(&log_path) {
        Ok(c) => c,
        Err(_) => return Vec::new(),
    };
    content.lines()
        .rev().take(n)
        .filter_map(parse_reload_log_line)
        .collect()
}
```

**Truncation** — log unbounded grow eder. v0.5.4 truncation YOK; v0.6+ rotation (log4rs-style) demand-driven.

**1MB warn cadence (I-7 fold):** Earlier draft said "startup-only" warn — meant a long-running session (week+ uptime) crosses threshold silently. Revised: **per-append threshold check** via `metadata().len()` after each `append`. Bu cost ekstra `stat(2)` syscall per reload event (~50ns), reload event'leri kendisi rare (kullanıcı save'leri arası dakika-saat); negligible. Warn TAYF_LOG=warn'a yazılır once-per-threshold-cross (state: `last_warned_size: Option<u64>` ReloadLogger field).

**POSIX append atomicity (I-7 fold):** Birden fazla wrapper process aynı `reload.log`'a parallel append yapabilir (her wrapper kendi ReloadLogger'ı). POSIX `O_APPEND` write(2) ≤ PIPE_BUF (4096 byte) atomic — her line ~50-100 byte well under limit. Test `concurrent_appends_do_not_interleave_within_line` §10.2 row `reload.rs`.

**Precedence-chain invariant pin (I-4 fold):** ReloadLogger adding does NOT change any v0.2.1/v0.5.1/v0.5.2 precedence-chain snapshot. Reload thread continues snapshotting `theme`/`profile`/`bg_default` at startup exactly as today (memory `feedback_reload_precedence_snapshot`). Logger is purely an additive side-effect sink on the post-reload-decision path.

## §9 — Live preview pipeline (debouncer)

### §9.1 — Debounce semantic

- **Per-keystroke regex source field'ında**: `app.preview.last_edit = Instant::now(); app.preview.debounce_pending = true`.
- **Main loop 100ms timeout tick'inde**: `check_debounce(&mut app)` — `if debounce_pending && (now - last_edit) > 200ms { recompile() }`.
- **Recompile**:
  - `snapshot.parsed.clone()` → apply `edits` overlay → `Vec<UserRule>` (mevcut shape) → `rules::Compiled::load_with_theme(rules, active_theme, ...)` (mevcut public API; v0.5.3 `__bench__::load_profile_rules` pattern aynı yol).
  - `Ok(c)` → `preview.compiled = Some(Arc::new(c)); preview.compile_error = None`.
  - `Err(e)` → `preview.compile_error = Some(e.to_string())`; `compiled` (eski Ok) korunur — preview son-good rules ile çalışmaya devam eder + error inline mesajda görünür `"⚠ pattern won't compile: <reason> — save disabled until fix"` + Ctrl+S basıldığında SaveDiff açılmaz, error toast.

### §9.2 — Anlık (no debounce) etkileşimler

- Color picker'da color change (regex source unchanged, sadece style swap).
- Theme switch (active theme'i değiştir; rules unchanged).
- Profile switch (active profile'ı değiştir; rules unchanged).
- Tab switch.
- Modal aç/kapat.
- Sample input değiştir.

Bu etkileşimler `app.preview.last_edit`'i set etmez; render fn'i mevcut `preview.compiled` ile re-render eder.

### §9.4 — Compile cost guard

- 12 built-in + N user rule + (varsa) profile rule = tipik 15-30 regex. v0.4.0 RegexSet build benchmarks ~5-15ms cold compile (50 rule fixture). 200ms debounce comfortably altında.
- Catastrophic regex (`(a+)+` shape) edit sırasında compile asılırsa main thread freeze. **Önlem**: `regex` crate'in mevcut `RegexBuilder::size_limit` + `dfa_size_limit` v0.5.3'te güvenli default'ta (10 MB / 2 MB). v0.5.4 ek koruma eklemiyor (memory `feedback_dependency_minimalism` — premature complexity yok). User adversarial edit ederse compile error verir → preview "won't compile" mesajı.

### §12.1.1 — Quit-with-unsaved-edits confirm modal (UX #3 fold)

**Trigger:** `q` / `Ctrl+C` when `app.edits.is_dirty()`.

**Modal stacking interaction:** If another modal is open when `Ctrl+C` is pressed, the quit-confirm modal **replaces** the current modal (per §7.2 modal-stacking-forbidden rule — Ctrl+C is one of two keys that bypass modal-absorbs). The replaced modal's state is dropped (e.g., color picker selection abandoned); user can re-open it after canceling the quit. Plain `q` (vs `Ctrl+C`) does NOT bypass modal-absorbs — `q` only triggers the quit-confirm modal when no other modal is open.

**Wording (byte-pinned, EN-only per CLAUDE.md §1):**

```
You have unsaved changes.

  [n / Esc / Enter]  Cancel (return to editor)        ← DEFAULT (safe)
  [s]                Save and quit
  [d]                Discard and quit                  ← destructive
```

**Key bindings:**

| Key | Action |
|---|---|
| `n` / `Esc` / `Enter` | Cancel — return to editor. **DEFAULT — safe path.** |
| `s` | Save then quit — equivalent to `Ctrl+S` flow; SaveDiff modal opens inline; on save success, auto-quit. |
| `d` | Discard and quit — destructive; **no `Enter` shortcut** binds to this action. |

**Rationale:**
- Three-choice over binary `y/n` eliminates the "Discard? [y/n]" foot-gun where reflexive `Enter` after long edit session = data loss.
- "Save and quit" matches the most likely user intent after substantial edit work (saves AND exits in one keystroke; otherwise user must `Ctrl+S` → SaveDiff → `y` → `q` again).
- `Enter` selects default (Cancel) — safe muscle-memory.
- `d` (discard) is a deliberate keystroke not bound to `Enter`; misskey-resistant.
- Matches lazygit / gitui pattern.
