## §1 — Özet

v0.5 cycle'ın son sub-version'ı. v0.5.0 GHA bump + capture-group naming, v0.5.1 themes Phase-1 gate fix, v0.5.2 profile system mechanism, v0.5.3 built-in profile library — hepsi user-config layer'ın ergonomi tarafını besledi. v0.5.4 bu layer'ı text editor + manuel TOML edit yerine fullscreen interactive TUI ile düzenlenir hale getirir.

`tayf` binary'sine `Option<Cmd>` subcommand iskeleti eklenir. `tayf` (no subcommand) mevcut PTY wrapper behavior'ını **byte-identical** korur. Yeni iki kullanım:

- `tayf config` — fullscreen interactive TUI. Pattern list browse + edit, color picker (ANSI 16 / 256-palette / truecolor hex), theme/profile switch, debounced live preview, atomic save with conflict-aware diff confirm.
- `tayf config dump` — built-in pattern/theme/profile catalogunu stdout'a TOML olarak yazar (non-interactive; user-config seed olarak kullanılabilir).
- `tayf config status` — resolved config state (config path, active theme, active profile, bg-detect) + hot-reload watcher event log tail (last 100 events).

**Architectural anchor**: TUI ayrı kod path. `apply_rules` + Pipeline + IO loop + PTY runtime **DOKUNULMAZ**. Hot path bench-CI baseline regen yok. ratatui App tek thread; hot-reload integration ratatui kodu eklemez — TUI atomic rename yapar, mevcut v0.2.1 `ReloadOrchestrator` (başka tayf wrapper process'lerinde) file watcher event'ini görür ve precedence-chain reload (v0.5.2 D5 invariant) yapar. Wrapper içinden TUI çağrısı v0.3.0 alt-screen passthrough state machine'i ile temiz çalışır.

İki yeni direct dep — `ratatui` 0.30 (TUI rendering + crossterm backend + buffer diff + layout primitives + widgets) ve `toml_edit` 0.23 (round-trip TOML parse-mutate-serialize, manuel kullanıcı edit'lerini + comment'leri + ordering'i koruma). CLAUDE.md §3 audit gate her ikisi için: license MIT, weekly active commits, `cargo geiger` `unsafe` audit pinned, transitive surface scanned.

Carve-out: v0.5.3 final review'in işaret ettiği architectural collision fix (ARN/ipv6 + image_tag/fqdn root cause: RegexSet pattern-order priority) **v0.5.4'e dahil değil** — v0.5.5 olarak ayrı sub-version'da ship'lenir. v0.5.4 spec sadece forward-pointer tutar.

## §4 — CLI surface

### §4.1 — clap derive shape

Mevcut flat `Args` struct'ı `RunArgs` olarak yeniden adlandır; kök `Args` struct'ı `RunArgs`'ı `#[command(flatten)]` ile gömer + `Option<Cmd>` subcommand taşır.

```rust
// src/cli.rs (v0.5.4 refactor)

use clap::{Args as ClapArgs, Parser, Subcommand, ValueEnum};

#[derive(Debug, Parser)]
#[command(name = "tayf", author, version = version_str(), about, long_about = None)]
#[non_exhaustive]
pub struct Args {
    /// When no subcommand is given, run the PTY wrapper with these flags.
    #[command(flatten)]
    pub run: RunArgs,

    #[command(subcommand)]
    pub cmd: Option<Cmd>,
}

#[derive(Debug, ClapArgs)]
#[non_exhaustive]
#[allow(clippy::struct_excessive_bools)]
pub struct RunArgs {
    /// Override the shell to launch.
    #[arg(long, value_name = "PATH")]
    pub shell: Option<PathBuf>,

    /// Spawn the shell as a login shell.
    #[arg(long, default_value_t = false)]
    pub login: bool,

    // ... (mevcut tüm field'lar — no_color, config, theme, profile, bypass, no_hot_reload)
}

#[derive(Debug, Subcommand)]
#[non_exhaustive]
pub enum Cmd {
    /// Interactive TUI for browsing and editing tayf config.
    Config(ConfigArgs),
}

#[derive(Debug, ClapArgs)]
#[non_exhaustive]
pub struct ConfigArgs {
    #[command(subcommand)]
    pub action: Option<ConfigAction>,
}

#[derive(Debug, Subcommand)]
#[non_exhaustive]
pub enum ConfigAction {
    /// Write built-in pattern/theme/profile catalog to stdout as TOML.
    Dump(DumpArgs),
    /// Print resolved config state + hot-reload event log tail.
    Status,
}

#[derive(Debug, ClapArgs)]
pub struct DumpArgs {
    /// Restrict dump to one section (default: all of patterns/themes/profiles).
    #[arg(long, value_enum)]
    pub kind: Option<DumpKind>,
}

#[derive(Debug, Clone, Copy, ValueEnum)]
pub enum DumpKind {
    Patterns,
    Themes,
    Profiles,
}
```

### §4.2 — Dispatch (src/main.rs)

```rust
fn main() -> ExitCode {
    match Args::try_parse_from_env() {
        Ok(args) => match args.cmd {
            None => match Tayf::run(args.run) {
                Ok(code) => code,
                Err(err) => { eprintln!("tayf: {err}"); ExitCode::from(map_error_to_exit_code(&err)) }
            },
            Some(Cmd::Config(cfg)) => match cfg.action {
                None => config_tui::run(args.run),
                Some(ConfigAction::Dump(dump)) => config_tui::dump(dump.kind),
                Some(ConfigAction::Status) => config_tui::status(args.run),
            },
        },
        Err(e) => { /* mevcut clap error handling */ }
    }
}
```

### §4.3 — Backward compat invariants

- `tayf` (no subcommand) tüm mevcut flag'lerle çalışır. `tests/integration_smoke.rs` byte-identical diff = 0.
- Mevcut tüm `src/cli.rs::tests` test'leri compile + pass (sadece `Args` field path'i `args.shell` → `args.run.shell` shape'ine güncellenir).
- `--config` / `--theme` / `--profile` kök seviyede `RunArgs`'a flatten'lı → `tayf --theme dark` mevcut byte-identical çalışır, AYNI ZAMANDA `tayf --theme dark config` da çalışır (subcommand + flag birlikte). Kök flag'ler subcommand çağrıldığında TUI'ye **base context** olarak geçer (which config to load + initial theme/profile to highlight as active).

| Invocation | Success | Failure |
|---|---|---|

## §6 — Data model

### §6.1 — Core types

```rust
// src/config_tui/snapshot.rs

/// Frozen view of disk config at last successful read.
pub(crate) struct ConfigSnapshot {
    /// Resolved config file path. None = no config file existed at startup.
    pub(crate) source_path: Option<PathBuf>,
    /// SHA256 of raw_bytes. Used by save_diff to detect manual edits since
    /// TUI opened (D1 conflict-mode trigger).
    pub(crate) source_hash: [u8; 32],
    /// Raw TOML bytes at last read.
    pub(crate) raw_bytes: Vec<u8>,
    /// Round-trip parsed doc — mutations via toml_edit preserve comments,
    /// ordering, and formatting.
    pub(crate) doc: toml_edit::DocumentMut,
    /// Semantic typed view — reuses existing tayf::config parse types.
    pub(crate) parsed: ParsedConfigView,
}

/// Lightweight typed view derived from `doc`. Reuses existing semantics
/// without owning rules::Compiled (Compiled is rebuilt for live preview).
pub(crate) struct ParsedConfigView {
    pub(crate) general: GeneralSection,
    pub(crate) rules: Vec<UserRule>,
    pub(crate) theme_ref: Option<String>,
    pub(crate) profile_ref: Option<String>,
}
```

## §7 — Event loop + rendering pipeline

### §7.1 — Single-thread event loop

```rust
// src/config_tui/events.rs

pub(crate) fn run_event_loop(
    mut app: App,
    mut terminal: Terminal<CrosstermBackend<Stdout>>,
) -> Result<()> {
    while !app.should_quit {
        terminal.draw(|frame| render::frame(frame, &app))?;
        if crossterm::event::poll(Duration::from_millis(100))? {
            match crossterm::event::read()? {
                Event::Key(k) if k.kind == KeyEventKind::Press => dispatch_key(&mut app, k),
                Event::Resize(_, _) => { /* ratatui auto-recalcs on next draw */ }
                Event::Mouse(_) | Event::Paste(_)
                | Event::FocusGained | Event::FocusLost | Event::Key(_) => {}
            }
        } else {
            check_debounce(&mut app);
        }
    }
    Ok(())
}
```

### §7.2 — Key dispatch order

1. **Modal absorbs** — `Some(modal)` ise tab key'leri görmez. Modal kendi dispatch fn'i.
2. **Global keys** — `q`, `Ctrl+C`, `Ctrl+S`, `?` / `F1`, `P` (preview toggle), `F` (full-preview), `s` (sample set), `/` (search), `Esc` (modal close / edit cancel).
3. **Tab routing** — `Tab` / `Shift+Tab` / `1`-`4` direct.
4. **Tab-internal** — `app.tab` enum match → `tabs::<tab>::dispatch_key(&mut app, k)`.

### §7.3 — Render composition

```rust
// src/config_tui/render.rs

pub(crate) fn frame(frame: &mut Frame, app: &App) {
    let size = frame.size();

    // Narrow-terminal degradation gate (§7.4)
    if size.width < 60 || size.height < 16 {
        render_too_small(frame, size, app.terminal_caps);
        return;
    }

    let preview_visible = app.mini_preview_visible(size);
    let preview_rows = if preview_visible { 5 } else { 0 };

    let chunks = Layout::vertical([
        Constraint::Length(1),                        // tab strip
        Constraint::Min(10),                          // main pane
        Constraint::Length(preview_rows),             // mini-preview (collapsible)
        Constraint::Length(1),                        // status bar
    ]).split(size);

    render_tab_strip(frame, chunks[0], app);
    match app.tab {
        Tab::Patterns => tabs::patterns::render(frame, chunks[1], app),
        Tab::Themes   => tabs::themes::render(frame, chunks[1], app),
        Tab::Profiles => tabs::profiles::render(frame, chunks[1], app),
        Tab::Status   => tabs::status::render(frame, chunks[1], app),
    }
    if preview_visible {
        widgets::preview::render_mini(frame, chunks[2], app);
    }
    render_status_bar(frame, chunks[3], app);

    if let Some(modal) = &app.modal {
        widgets::render_modal(frame, size, modal, app);
    }
}
```

### §7.4 — Narrow-terminal degradation

Graceful, hard-block sadece extreme case.

| Boyut | Davranış |
|---|---|
| ≥ 80 × 24 | Full layout (tab strip + main + 5-row mini-preview + 1-row status) |
| 80 × 18-23 | Mini-preview otomatik gizlenir; `P` ile geri açılır. Status bar tek satır. |
| 60-79 × any | Tab strip kısa harfler (`P`/`T`/`F`/`S`). Main pane daralır. Mini-preview gizli (`P` toggle yok bu boyutta). |
| < 60 × 16 | **Block render**: tek satır mesaj — `Resize to ≥60×16 (currently <w>×<h>)`. Resize event → otomatik kalkar. |

### §7.5 — RAII terminal restore

```rust
// src/config_tui/mod.rs

pub(crate) fn run(args: RunArgs) -> ExitCode {
    let _guard = TuiGuard::enter()?;  // enable raw mode + enter alt-screen
    let backend = CrosstermBackend::new(stdout());
    let terminal = Terminal::new(backend)?;
    let app = init_app(args)?;
    match events::run_event_loop(app, terminal) {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => { eprintln!("tayf config: {e}"); ExitCode::from(70) }
    }
    // _guard.drop() → disable raw mode + leave alt-screen
}

struct TuiGuard;
impl TuiGuard {
    fn enter() -> Result<Self> {
        enable_raw_mode()?;
        execute!(stdout(), EnterAlternateScreen)?;
        Ok(Self)
    }
}
impl Drop for TuiGuard {
    fn drop(&mut self) {
        let _ = execute!(stdout(), LeaveAlternateScreen);
        let _ = disable_raw_mode();
    }
}
```

## §8 — Save semantics + hot-reload coexistence

### §8.1 — D1 save flow (full detail)

**Trigger** — `Ctrl+S` global. Edit field içindeyken `Enter` field commit eder, sonra global `Ctrl+S` save modal aç.

**SaveDiff modal açma:**

```
1. let disk_now: Vec<u8> = fs::read(snapshot.source_path)?;
2. let disk_hash = sha256(&disk_now);
3. mode = if disk_hash == snapshot.source_hash {
       SaveDiffMode::Clean { tui_diff: render_diff(&snapshot.raw_bytes, &serialize(app)) }
   } else {
       SaveDiffMode::Conflict {
           tui_diff: render_diff(&snapshot.raw_bytes, &serialize(app)),
           manual_diff: render_diff(&snapshot.raw_bytes, &disk_now),
           disk_now,
       }
   };
4. app.modal = Some(Modal::SaveDiff(SaveDiffState { mode, .. }));
```

**Modal key dispatch:**

| Mode | Key | Action |
|---|---|---|
| Both | `y` | `commit_save(...)` (yukarıda flow) |
| Conflict | `m` | `app.snapshot = read_from_disk_now()?; app.edits = PendingEdits::default();` modal close; preview recompile |
| Both | `n` / `Esc` | Modal close, no change |
| Both | `↑` / `↓` | Diff scroll (uzun diff'lerde) |

**Commit flow:**

```
1. let backup_path = format!("{}.tayf-backup-{}", cfg_stem, rfc3339_ms_filename_safe(now()));
   fs::write(&backup_path, disk_now)?;       // disk_now zaten okundu (Clean mode'da snapshot.raw_bytes ile aynı)
2. rotate_backups(cfg_dir, max_keep = 5);    // scandir + mtime sort + unlink eldest

3. let new_doc = match mode {
       Clean => snapshot.doc.clone(),         // apply edits via toml_edit ops
       Conflict if y => toml_edit::parse(&disk_now)?,  // start from manual-edited disk
   };
   apply_edits_to_doc(&mut new_doc, &app.edits);
   let new_content: String = new_doc.to_string();

4. let tmp_path = format!("{}.tayf-tmp-{}-{}", cfg_path, pid, ms);
   let mut tmp = OpenOptions::new()
       .write(true).create_new(true).open(&tmp_path)?;
   tmp.write_all(new_content.as_bytes())?;
   tmp.sync_data()?;                          // fsync tmpfile content

5. fs::rename(&tmp_path, &cfg_path)?;         // atomic on POSIX

6. let dir = File::open(cfg_dir)?;
   let _ = dir.sync_all();                    // fsync parent dir (rename durability)

7. app.snapshot = ConfigSnapshot {
       source_path: Some(cfg_path),
       source_hash: sha256(new_content.as_bytes()),
       raw_bytes: new_content.into_bytes(),
       doc: new_doc,
       parsed: re_parse(&app.snapshot.raw_bytes)?,
   };
   app.edits = PendingEdits::default();
   app.toast = Some(Toast::ok("Saved. Hot-reload will pick this up shortly."));
```

### §8.2 — Error paths

| Hata noktası | Davranış |
|---|---|
| `fs::write(&backup_path, ...)` fails | Abort BEFORE tmpfile. `Toast::err("Backup failed: <reason>. Aborting save to protect data.")`. Modal stays open. |
| `OpenOptions::create_new(true).open(&tmp_path)` fails | `Toast::err("Save failed: tmpfile: <reason>")`. Backup kalır (recoverable). Modal close. |
| `tmp.write_all(...)` veya `tmp.sync_data()` fails | `Toast::err("Save failed: write: <reason>")`. `fs::remove_file(&tmp_path).ok()`. Backup kalır. Modal close. |
| `fs::rename(...)` fails | `Toast::err("Atomic rename failed: <reason>")`. `fs::remove_file(&tmp_path).ok()`. Snapshot unchanged. Modal close. |
| `dir.sync_all()` fails | Logged via `TAYF_LOG=warn` (stderr); save sayılır (rename completed). Toast: ok. |
| `apply_edits_to_doc` fails (toml_edit reconcile error in Conflict-y path) | `app.modal = Some(Modal::Error(format!("Merge conflict: {e}. See backup at {backup_path}")));` |
| `re_parse` after save fails (theoretically impossible — we just wrote valid TOML) | `Toast::err("Post-save reparse failed (file integrity check)")`; snapshot reverted to in-memory pre-save state; user invited to manually verify file. |

### §8.3 — Backup rotation

- **Naming**: `<cfg-stem>.tayf-backup-<rfc3339-ms-filename-safe>` örn. `config.toml.tayf-backup-2026-05-26T17-18-42-123Z`. Colon (`:`) `-` ile substitute edilir (Windows v1.0+ forward-friendly).
- **Discovery**: `fs::read_dir(cfg_dir)` + filter `starts_with(format!("{cfg_stem}.tayf-backup-"))`.
- **Sort**: by `metadata.modified()` desc.
- **Keep**: en yeni 5. Eldest `unlink`. Best-effort — `unlink` fail → `TAYF_LOG=warn` log, sav proceed eder.
- **Max retention** config-lenebilirlik (`[general] backup_max = N`) v0.6+'a defer. v0.5.4 constant `MAX_BACKUPS: usize = 5`.

### §8.4 — Hot-reload coexistence (4 scenarios)

| Senaryo | Davranış |
|---|---|
| **A — TUI standalone (no wrapper)** | Save → disk write. Kimse watching değil. TUI'nin kendi `preview.compiled` debounce'la zaten güncel. Status tab: `"hot-reload: no active wrapper detected"`. |
| **B — Wrapper başka terminal'de + TUI ayrı** | Wrapper'ın v0.2.1 `ReloadOrchestrator` `notify` watcher'ı atomic rename event'ini görür → precedence-chain snapshot + reload (v0.5.2 D5 invariant) → `arc-swap` ile `Compiled` swap. **TUI tarafında zero new code.** Pin: `tests/integration_tui_save_roundtrip.rs` doesn't pin cross-process behavior (in-process only); cross-process is verified by existing v0.2.1 reload tests + manual smoke. |
| **C — Wrapped shell içinden TUI** (`tayf bash` → inside bash, `tayf config`) | ratatui startup `\x1b[?1049h` (alt-screen enter) yazar → wrapper'ın v0.3.0 alt-screen passthrough state machine bytes-through mode'a geçer (kendi colorization'ı bypass) → TUI temiz render → `q` ile `\x1b[?1049l` (alt-screen leave) → wrapper main-screen'e döner. **Zero new infra; v0.3.0 zaten çözdü.** Pin: `tests/integration_tui_in_wrapper.rs` smoke. |
| **D — İki TUI process simultaneous** | No locking. TUI #2 save → TUI #1'in `snapshot.source_hash` mismatch → TUI #1 sonraki `Ctrl+S` conflict mode'a düşer → D1 modal `m`/`y`/`n`. **Acceptable**: rare scenario, lock infrastructure cost (stale locks, holder-dies) yararsız. |

### §8.5 — `reload.log` event file infra

**Wrapper side** (`src/reload.rs` additive ~80 LOC):

```rust
pub(crate) struct ReloadLogger {
    state_dir: PathBuf,  // <cfg-dir>/runtime/
    enabled: bool,        // false if state_dir create failed at startup
}

impl ReloadLogger {
    pub(crate) fn new(cfg_dir: &Path) -> Self {
        let state_dir = cfg_dir.join("runtime");
        let enabled = fs::create_dir_all(&state_dir).is_ok();
        Self { state_dir, enabled }
    }

    pub(crate) fn append(&self, event: ReloadEvent) {
        if !self.enabled { return; }
        let line = format!("{} reload #{} {}\n",
            event.ts_rfc3339(),
            event.reload_count,
            event.outcome_str());
        let log_path = self.state_dir.join("reload.log");
        let _ = OpenOptions::new()
            .create(true).append(true).open(&log_path)
            .and_then(|mut f| f.write_all(line.as_bytes()));
        // Best-effort; failures logged via TAYF_LOG=warn but don't block reload.
    }
}

pub(crate) struct ReloadEvent {
    pub(crate) timestamp: SystemTime,
    pub(crate) reload_count: u64,
    pub(crate) outcome: ReloadOutcome,
}

pub(crate) enum ReloadOutcome {
    Ok,
    Err(String),
}
```

`ReloadOrchestrator::run()` her başarılı reload'da `logger.append(...)` çağrısı ekler. Mevcut precedence snapshot pattern (memory `feedback_reload_precedence_snapshot`) — logger create startup'ta yapılır, daha sonra new'lenmez (snapshot disiplinine paralel).

**Status reader side** (`src/config_tui/status.rs`):

```rust
pub(crate) fn read_recent_events(state_dir: &Path, n: usize) -> Vec<ReloadEvent> {
    let log_path = state_dir.join("reload.log");
    let content = match fs::read_to_string(&log_path) {
        Ok(c) => c,
        Err(_) => return Vec::new(),
    };
    content.lines()
        .rev().take(n)
        .filter_map(parse_reload_log_line)
        .collect()
}
```

**Truncation** — log unbounded grow eder. v0.5.4 truncation YOK; v0.6+ rotation (log4rs-style) demand-driven. Mevcut TAYF_LOG warn'ı `reload.log` size > 1MB iken bilgilendirir (basit threshold check ReloadOrchestrator startup'ta).

## §9 — Live preview pipeline (debouncer)

### §9.1 — Debounce semantic

- **Per-keystroke regex source field'ında**: `app.preview.last_edit = Instant::now(); app.preview.debounce_pending = true`.
- **Main loop 100ms timeout tick'inde**: `check_debounce(&mut app)` — `if debounce_pending && (now - last_edit) > 200ms { recompile() }`.
- **Recompile**:
  - `snapshot.parsed.clone()` → apply `edits` overlay → `Vec<UserRule>` (mevcut shape) → `rules::Compiled::load_with_theme(rules, active_theme, ...)` (mevcut public API; v0.5.3 `__bench__::load_profile_rules` pattern aynı yol).
  - `Ok(c)` → `preview.compiled = Some(Arc::new(c)); preview.compile_error = None`.
  - `Err(e)` → `preview.compile_error = Some(e.to_string())`; `compiled` (eski Ok) korunur — preview son-good rules ile çalışmaya devam eder + error inline mesajda görünür `"⚠ pattern won't compile: <reason> — save disabled until fix"` + Ctrl+S basıldığında SaveDiff açılmaz, error toast.

### §9.2 — Anlık (no debounce) etkileşimler

- Color picker'da color change (regex source unchanged, sadece style swap).
- Theme switch (active theme'i değiştir; rules unchanged).
- Profile switch (active profile'ı değiştir; rules unchanged).
- Tab switch.
- Modal aç/kapat.
- Sample input değiştir.

Bu etkileşimler `app.preview.last_edit`'i set etmez; render fn'i mevcut `preview.compiled` ile re-render eder.

### §9.3 — Sample input

```rust
// src/config_tui/render.rs
```

`s` global key → `Modal::SampleSet(SampleSetState { buffer: app.sample_input.text.clone() })`; text input + Enter accept; session-only. Persist v0.6+.

### §9.4 — Compile cost guard

- 12 built-in + N user rule + (varsa) profile rule = tipik 15-30 regex. v0.4.0 RegexSet build benchmarks ~5-15ms cold compile (50 rule fixture). 200ms debounce comfortably altında.
- Catastrophic regex (`(a+)+` shape) edit sırasında compile asılırsa main thread freeze. **Önlem**: `regex` crate'in mevcut `RegexBuilder::size_limit` + `dfa_size_limit` v0.5.3'te güvenli default'ta (10 MB / 2 MB). v0.5.4 ek koruma eklemiyor (memory `feedback_dependency_minimalism` — premature complexity yok). User adversarial edit ederse compile error verir → preview "won't compile" mesajı.

### §9.5 — Mini-preview render

`widgets::preview::render_mini(frame, area, app)`:

- Take `app.preview.compiled` (veya fallback `snapshot.compiled` None ise).
- Apply to `app.sample_input.text` (sample text).
- Render colorized result (truncated to fit `area.height`; ratatui Paragraph + Style spans).
- Header line: `─── live preview ─── [s] sample [P] hide [F] full ───────`.

Full-preview overlay (`F` global key): `app.modal = Some(Modal::FullPreview)` → modal render fn full-screen Clear + sample render. `Esc` close.
