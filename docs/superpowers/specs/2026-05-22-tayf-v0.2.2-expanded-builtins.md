# tayf v0.2.2 — Expanded Built-in Pattern Set Tasarım Dokümanı

**Tarih:** 2026-05-22
**Kapsam:** v0.2.2 — built-in pattern setini 8 → 13'e genişlet (`permission`, `timestamp` multi-format, `uuid`, `url`, `email`)
**Prereqs:** v0.2.1 (hot reload) yayınlanmış olmalı.

Master tasarım hâlâ otorite. v0.1 spec'i 8 built-in pattern'i tanımladı. v0.2.0 user config + override/disable mekanizmasını ekledi. v0.2.1 hot reload getirdi. v0.2.2 yeni built-in pattern eklemekten ibaret — yeni public API yok, yeni dep yok.

---

## 1. Vizyon

8 mevcut built-in (ipv4, ipv6, mac, log_level, http_status, filename, fqdn, duration) terminal çıktısının önemli bir bölümünü yakalıyor ama yaygın bilgi sınıflarını kaçırıyor: timestamp, UUID, URL, POSIX permission, email adresi. Bu 5'i ekleyerek "kurulduğu anda fark eder" deneyimini büyütüyoruz.

### Hedefler

- 5 yeni built-in: hepsi shape-unique, FP riski ~sıfır.
- Mevcut user-config mekanizması (override by name, `enabled = false`, color override) yeni rule'lara otomatik uygulanır — config schema değişikliği yok.
- Pattern modeli korunur: first-match-wins, `regex::bytes::Regex`, size_limit 1 MiB.

### Hedef olmayan (v0.3+'a)

- `git@host:path` SSH URL alt-form — v0.3 (farklı şekil, ayrı alternation branch'i gerekir).
- Trailing-punctuation trim in URL match — v0.3 (lookbehind ihtiyacı).
- Daha fazla timestamp formatı (örn. Unix epoch detection) — v0.3.
- Built-in pattern set'inin user'a ait config dosyasından `tayf config dump` ile dökümü — v0.5.

## 3. FP analizi — neden bu 5?

Her built-in eklemeden önce uygulanan filtre: "shape-unique + prose-immune." Kabul edilen:

| Pattern | Shape | Prozada çıkar mı? | Karar |
|---|---|---|---|
| permission | `[dlcbps-][rwxsStT-]{9}\+?` 10/11 char | Hayır | KABUL |
| timestamp (4 format) | Anchor-bounded sayı/ay kombinasyonu | Hayır | KABUL |
| uuid | 8-4-4-4-12 hex + hyphen | Hayır | KABUL |
| url | `(?:https?\|ssh\|ftp)://` prefix | Hayır | KABUL |
| email | `\w+@\w+\.\w+` | Çok nadir prozada | KABUL |

Reddedilen / ertelenen adaylar:

| Pattern | Sebep |
|---|---|
| git SHA | Naïve `[0-9a-f]{7,40}` FP riskli; context gerektirir |
| byte size (1.2 GB) | Prozada nadir ama çıkabiliyor; v0.3'e user-config örneği |
| yüzde (42%) | Prozada `%100 garanti` gibi nadir ama mümkün; v0.3'e ertelendi |
| hex literal (`0x...`) | Kullanışlı ama dar audience; v0.3'e ertelendi |
| HTTP method (GET/POST) | Düz proza kullanımı (`POST`/`HEAD` kelimeleri) var; user-config'e |

## 5. Match priority sırası

Yeni rule'lar en başa eklenir (en spesifik şekil önce). Tam sıra:

```
1. permission
2. timestamp
3. uuid
4. url
5. email
6. ipv4
7. ipv6
8. mac
9. log_level
10. http_status
11. filename
12. fqdn
13. duration
```

`url` ve `email`, `fqdn`'den ÖNCE çalışmalı. `apply_rules` overlap rejection ile bunu doğrular.

## 7. Güvenlik

CLAUDE.md §3 mandate'leri:

- **ReDoS:** Her yeni pattern linear-time. Bounded counts (`\d{4}`, `[A-Za-z]{2,}`), no nested alternation with backtracking risk. `regex::bytes` 1 MiB size_limit (mevcut, v0.2.0'dan miras).
- **SGR collision:** Yeni pattern'ler escape sequence içinde match etmemeli. Mevcut `duration_does_not_match_sgr_parameters` test pattern'ı her yeni rule için tekrar edilir.
- **No new attack surface:** Yeni public API yok, yeni dep yok, yeni FS path yok. Saf rule set genişlemesi.

## 8. Test stratejisi

### Unit
- Her yeni rule için pozitif ve negatif match testi.
- `compiled_load_succeeds`: `n == 13`.
- `builtin_names_match_builtin_rules_order`: mevcut invariant; yeni 5 isim de `BUILTIN_NAMES`'te.
- SGR collision regression: her yeni rule için, `apply_rules` ANSI escape sequence içine inject etmemeli.
- Cross-rule overlap: `url` vs `fqdn`, `email` vs `fqdn`, `permission` vs `mac` (ikisi de `-` barındırır; permission'da placeholder, MAC'te byte separator) çakışma case'leri.

### Integration
- Mevcut `tests/integration_smoke.rs` ve `tests/integration_hot_reload.rs` regresyona uğramamalı (default rule set değişti).

### Manual
- Gerçek `ls -l` çıktısı: permission satırları renkli.
- Gerçek `journalctl` çıktısı: timestamp renkli.
- `curl -v` veya `httpie`: URL renkli.
