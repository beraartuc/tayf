## 1. Vizyon

### 1.1 Kapsam A — URL trailing punctuation trim

Mevcut `url` built-in pattern'i `\b(?:https?|ssh|ftp)://[^\s<>"\\^`{|}]+`. Karakter sınıfı sonu noktalama karakterlerini exclude etmiyor — match greedy bir şekilde cümle-bitiş punctuation'ını yiyor. Pratik etkisi: log/markdown/chat yapıştırmasında `Bkz https://example.com.` veya `urls: https://a.com, https://b.com.` çıktıları için URL match'inin son karakteri trailing punctuation oluyor; click-to-open destekleyen terminallerde (iTerm2 Cmd-click, Wezterm hyperlink) link patlıyor.

Rust `regex` crate'i look-behind desteklemiyor. Standart "match URL but not trailing punctuation" tekniği: pattern'in son karakterini ayrı bir character class'la bağla, o class'ın trailing-punct karakterlerini exclude etsin; regex engine middle class'ı greedy ye, sonra final class'ın constraint'ini sağlamak için bir karakter geri backtrack et. v1.x `regex` crate'i bu pattern shape'ini lineer zamanda DFA'lar; backtracking depth bounded (1 karakter).

**Trim karakter kümesi:** `.`, `,`, `;`, `:`, `!`, `?` — yalnızca cümle-bitiş noktalaması. Closing brackets (`)`, `]`) **trim edilmez** — Rev2 düzeltmesi. Gerekçeler:
- **Wikipedia/MDN regression önlenir.** `https://en.wikipedia.org/wiki/Foo_(disambig)` URL'leri sayısız wiki/dok kaynağında geçer; trailing `)` URL'in legitimate parçası. `)` trim edilirse Cmd-click 404 verir (paren-balance unbalanced).
- **IPv6 literal host korunur.** `https://[::1]:8080/v1`'de orta `]`'ler zaten exclude class içinde değil; ama bare `https://[::1]` formunda son `]` korunmalı. `]` trim edilirse `https://[::1` çıkar, broken.

**Bilinçli takas:** `(https://example.com)` gibi paren-wrap'lı yazımda URL match'i `https://example.com)` döner — trailing `)` match içinde. Browser address bar bunu strip eder; click-to-open URL'i yine resolve eder (most terminals tolerate). Wikipedia regression'ından kötü değil; kullanıcı `[[rules]]` ile özelleştirebilir. CHANGELOG'da explicit not.

### 1.2 Kapsam B — `git@host:path` SSH form

v0.2.2 `url` built-in'i HTTPS/SSH/FTP scheme'lerini ship etti; `git@host:path` formu (CHANGELOG v0.2.2: "git@host:path SSH URL alt-form deferred to v0.3") explicit'çe v0.3'e ertelenmişti. Bu form `git`, `gitlab`, `bitbucket`, `gitea` gibi tüm major hosting'lerin clone URL'lerinde kullanılıyor; özellikle script çıktısında ve git remote listing'inde sık görülür.

Pattern shape: `git@HOST:PATH`. `git@` literal — diğer user identifier'ları (`ec2-user@host`, `root@host`) SSH-config / scp form'larında geçer ama Git remote için convention sadece `git@`. `:` zorunlu — path olmadığı durumda match etmez, böylece `clone git@github.com` ifadesi mevcut `email` built-in'ine düşer (precedence aşağıda §3.2'de işlenir).

**Host class:** `[A-Za-z0-9][A-Za-z0-9.-]*[A-Za-z0-9]` — Rev2 düzeltmesi. Önceki `[A-Za-z0-9.-]+` shape'i `git@.host:path`, `git@host.:path` ve `git@-host:path` gibi pathological string'leri match'liyordu. Yeni shape: en az 2 karakter (start ve end alphanumeric), arada `.` ve `-` serbest. Trade-off: tekli host (`git@h:path`) reject — Git workflow'unda gerçek dünyada görülmez. Consecutive dots (`git@a..b:p`) hâlâ tolere edilir — YAGNI shortcut.

### 1.3 Kapsam C — Bare duration units restore + compound desteği

v0.1 `duration` built-in'i `\b\d+(?:\.\d+)?\s?(?:ns|us|μs|ms|[smh])\b` ship etmişti; bare units (`s`, `m`, `h`) v0.2.2'de çıkarıldı çünkü `apply_rules` SGR byte'larını line buffer içinde "normal text" olarak görüyordu, `\x1b[49m` gibi sequence'in `m` byte'ı `\d+...[smh]` pattern'inin bir parçası olarak match'leniyordu — sonuç: SGR ortasına SGR injection, Powerlevel10k-class prompt'ların patlaması.

v0.3.0 ANSI SM (CHANGELOG v0.3.0) tüm CSI/ESC trigger byte'larını per-pipeline `sequence_scratch` buffer'ına alıyor; SGR sequence completion'da scratch içeriği `line_buffer`'a flush oluyor VE `line_has_sgr=true` set ediliyor. `respect_existing_colors=true` (v0.3.0 default) iken `apply_rules` SGR-bearing satırlarda hiç çalışmıyor — duration regex'i `\x1b[49m`'nin `49m`'sini hiç görmez. **Default config'te collision yapısal olarak imkansız.**

Bu durumda bare units geri eklenebilir. v0.3.2 ek olarak:
- `d` (days) ünitesini ekler — `git log --since=5d`, `find -mtime +5d`, log retention policy'leri.
- **Compound formları tek span olarak yakalar** (Rev2 değişikliği): `\b\d+UNIT(?:\d+UNIT)*\b` repeat-group shape ile `kubectl`'in `AGE 2d3h` çıktısını ve `docker ps`'in `STATUS 1h30m20s` çıktısını tek match olarak boyar. Rev1'in `(?:\b|(?=\d))` lookahead önerisi Rust regex'inde desteklenmediği için reddedildi; repeat-group lineer zamanlı ve aynı semantiği veriyor.

**Bilinçli known limitation:** `respect_existing_colors=false` set eden kullanıcılar SGR-bearing satırları rule application'ına sokar. `\x1b[49m` içinde `49m` bare-unit ile match'lenir → SGR injection. Bu yapısal v0.1 sınıfı bug'ın `respect=false`'da geri gelmesi anlamına gelir. `respect=true` default güvenli; opt-out edenler trade-off'u kabul etmiş sayılır. CHANGELOG ve README'de explicit not.

### 1.4 Kapsam D — macOS portable-pty + OSC 11 hang RC investigation

v0.3.1 release sırasında `bg_detect::resolve()` integration test ortamında — `tests/integration_smoke.rs` ve diğer integration test'lerinin portable-pty subprocess'lerinde — macOS runner'larda deep hang yapıyor. Hızlı çözüm olarak `.github/workflows/ci.yml`'a `COLORFGBG: "15;15"` env satırı eklendi (commit `423b9ca`); `detect_from_colorfgbg` env-var path'ı erken döner, OSC 11 path'ı (`/dev/tty` open + cfmakeraw + tcsetattr + poll(POLLIN, 100ms) + read) hiç çalışmaz.

Bu workaround pragmatik ama iki açıdan yetersiz:

1. **Gerçek bug izole edilmedi.** `OSC11_READ_TIMEOUT = 100ms` (`src/bg_detect.rs:203`) ve `nix::poll::poll(POLLIN, 100ms)` çağrısı normalde 100 ms'i aşmamalı. Aşıyorsa, ya `poll` macOS slave PTY fd'sinde gerçekten honor etmiyor (BSD quirk), ya da hang `poll`'dan önce/sonra başka bir aşamada (`tcgetattr`, `cfmakeraw`, `tcsetattr`, `open("/dev/tty")`, panic-hook OnceLock contention, drain loop, echo suppression). Bilmeden patch atmak future regression demek.
2. **Workaround'un kapsamı bütün test'leri etkiliyor.** `COLORFGBG=15;15` global env olarak set ediyor; unit test'ler `parse_colorfgbg`'i direkt çağırdığı için etkilenmiyor ama integration test'lerinin tamamı bg detection'ın env-var koluyla erken kapanışı varsayar.

v0.3.2 bu iki sorunu kapatır: önce minimal repro (production fonksiyonun **10 fazının hepsini** mirror eden bir binary) ile RC'yi izole et, sonra deliverable-gated karar ağacında ya gerçek fix at ya da temiz `TAYF_DISABLE_BG_DETECT` env-var bypass'a düş.

**Honest framing (Rev2 cross-cutting fix):** D-fix ile D-fallback **co-equal seçenekler**, biri "yetersiz" diğeri "yetkili" değil. RC investigation sonucu hangisi düşük risk + makul cost ise o ship olur. Her iki yolda da CI workflow'unda `COLORFGBG=15;15` hack'i kalkar.

### 1.5 Kapsam E — `watch::drop_stops_debounce_thread` macOS flake

`src/watch.rs:230-243` test'i `ConfigWatcher::Drop`'un her iki kaynağı (OS watcher + debounce thread) temiz kapattığını doğrular. Assertion: `rx.recv_timeout(Duration::from_millis(500)).is_err()`. macOS FSEvents `RecommendedWatcher::Drop` runloop join'i yüklü CI runner'da 100–500 ms alabiliyor (notify crate maintainer'larının bilinen davranışı; v0.3.1 release sırasında iki ardışık fail ile gözlemlendi); toplam Drop chain (watcher drop → raw_tx drop → debounce_loop noticed Disconnected → debounce_loop exit → tx drop → rx Disconnected) 500 ms'i aşıp test fail ediyor.

v0.3.1 release sırasında bu test iki kez fail oldu, ikincide `gh run rerun --failed` ile geçti. Bu intermittent davranış memory'de "tayf release workflow"un flake handling adımına alındı. Ama test'in kendisi makaslama; assertion'ı yeniden çerçevelemek doğru çözüm.

## 3. Mimari etki ve dosya bazlı değişiklikler

### 3.1 `src/rules.rs`

İki built-in pattern'i değiştirilir; `BUILTIN_NAMES` order ve `builtin_rules()` fonksiyon shape'i aynı kalır.

**`url` built-in** (`src/rules.rs:300-305`):

Eski:
```rust
BuiltinRule {
    name: "url".into(),
    pattern: r#"\b(?:https?|ssh|ftp)://[^\s<>"\\^`{|}]+"#.into(),
    style: Style { fg: Some(Color::BrightBlue), underline: true, ..Style::DEFAULT },
    is_user_supplied: false,
},
```

Yeni:
```rust
// See docs/superpowers/specs/2026-05-23-tayf-v0.3.2-pattern-polish-tech-debt.md §3.1.
// Char classes here are byte classes under regex::bytes — bytes 0x80..0xFF
// (UTF-8 continuation, IDN, percent-decoded paths) are implicitly included
// because the negation only lists ASCII bytes. Trailing-trim set is cümle-bitiş
// punctuation only (.,;:!?); closing brackets ) and ] stay in the match to
// preserve Wikipedia/MDN URLs and IPv6 literal host syntax.
BuiltinRule {
    name: "url".into(),
    pattern: concat!(
        r#"\b(?:https?|ssh|ftp)://[^\s<>"\\^`{|}]*[^\s<>"\\^`{|}.,;:!?]"#,
        r#"|"#,
        r#"\bgit@[A-Za-z0-9][A-Za-z0-9.-]*[A-Za-z0-9]:[^\s<>"\\^`{|}]*[^\s<>"\\^`{|}.,;:!?]"#,
    ).into(),

// Bare units [smhd] match without whitespace (e.g. "5m", "30s"); multi-letter
// units (ns/us/μs/ms) keep optional single-space prefix. Compound forms like
// kubectl AGE "2d3h" or docker STATUS "1h30m20s" match as a single span via
// the repeat group — Rust regex has no lookahead; this shape is the lookahead-
// free equivalent and remains linear-time DFA.
// SGR collision safety: v0.3.0 ANSI SM separates SGR bytes into sequence_scratch;
// with default respect_existing_colors=true, apply_rules skips SGR-bearing lines
// entirely. Users opting out (respect_existing_colors=false) re-introduce the
// v0.1-class collision (e.g. "49m" inside "\x1b[49m") — known limitation, see
// CHANGELOG and spec §1.7.
BuiltinRule {
    name: "duration".into(),
    pattern: r"\b\d+(?:\.\d+)?(?:\s?(?:ns|us|μs|ms)|[smhd])(?:\d+(?:\.\d+)?(?:\s?(?:ns|us|μs|ms)|[smhd]))*\b".into(),
    style: Style { fg: Some(Color::Green), ..Style::DEFAULT },
    is_user_supplied: false,
},
```

**Notlar:**
- İki branch grup: multi-letter units (optional space prefix) VEYA bare units (no space, single char).
- `[smhd]`: seconds, minutes, hours, days.
- Repeat group `(?:...)*` compound formları tek span olarak yakalar.
- `\b` sonu zorlar; `5min` match'lenmez (`m` sonra `i` word-char, no boundary).

```rust
#[test]
fn drop_stops_debounce_thread() {
    let dir = tempfile::tempdir().unwrap();
    let path = dir.path().join("config.toml");
    fs::write(&path, "initial\n").unwrap();

    let (tx, rx) = mpsc::channel::<ReloadRequest>();
    {
        let _watcher =
            ConfigWatcher::spawn_with_window(&path, tx, TEST_DEBOUNCE_WINDOW).unwrap();
        warmup_watcher();
        // Drain any in-flight events from the initial write before testing Drop.
        // macOS FSEvents can emit a CREATE event for the initial file write that
        // arrives after warmup; we don't want the assertion loop to panic on it.
        while rx.try_recv().is_ok() {}
    }

    // After both senders (watcher's raw_tx and debounce_loop's tx) drop, rx
    // must observe Disconnected. macOS FSEvents RecommendedWatcher::Drop runloop
    // join can take 100-500 ms under CI load; budget generously and poll for
    // the terminal state. Mirrors the resilient try_recv idiom used by
    // burst_of_edits_coalesces_to_bounded_event_count.
    let start = Instant::now();
    let max = Duration::from_secs(5);
    loop {
        match rx.try_recv() {
            Err(mpsc::TryRecvError::Disconnected) => break,
            Err(mpsc::TryRecvError::Empty) => {
                assert!(
                    start.elapsed() < max,
                    "watcher Drop did not disconnect channel within {max:?}"
                );
                std::thread::sleep(Duration::from_millis(50));
            }
            // Tolerate in-flight events from FSEvents shutdown; only Disconnected
            // is the terminal state we care about.
            Ok(_) => continue,
        }
    }
}
```

### 4.3 D investigation: minimal repro skeleton

`examples/repro_osc11_hang.rs` — production `detect_from_osc11` (`src/bg_detect.rs:101-130`) ile `read_until_terminator` (`src/bg_detect.rs:341-383`) ile `drain_remaining` (`src/bg_detect.rs:405-431`) ile `suppress_query_echo` (`src/bg_detect.rs:436-444`) **byte-for-byte mirror**:

```rust
//! OSC 11 hang diagnostic. Spawn under portable-pty subprocess on macOS CI
//! to measure where the bg_detect path stalls. Mirrors detect_from_osc11
//! phase-by-phase (open / tcgetattr / install_panic_hook / cfmakeraw /
//! tcsetattr / write / read loop / drain / suppress / restore). Prints
//! per-phase wall-clock timing to stderr; exit 0 regardless of outcome.
//!
//! Usage: cargo run --example repro_osc11_hang
//! CI usage: tests/integration_bg_detect.rs spawns this under portable-pty
//! and parses the stderr output for budget assertions.

use std::fs::OpenOptions;
use std::os::fd::{AsRawFd, BorrowedFd, RawFd};
use std::sync::{Mutex, OnceLock};
use std::time::{Duration, Instant};

use nix::fcntl::{fcntl, FcntlArg, OFlag};
use nix::poll::{PollFd, PollFlags, PollTimeout};
use nix::sys::termios::{cfmakeraw, tcgetattr, tcsetattr, SetArg, Termios};
use nix::unistd::{read, write};

const OSC11_READ_TIMEOUT_MS: u32 = 100;
const OSC11_WRITE_TIMEOUT_MS: u32 = 50;

static PANIC_SLOT: OnceLock<Mutex<Option<(RawFd, Termios)>>> = OnceLock::new();

fn main() {
    let overall = Instant::now();
    let mut phases: Vec<(&'static str, Duration)> = Vec::new();

    // Phase 1: open
    let t = Instant::now();
    let tty = match OpenOptions::new().read(true).write(true).open("/dev/tty") {
        Ok(f) => f,
        Err(e) => { eprintln!("open /dev/tty failed: {e}"); print_phases(&phases, overall); return; }
    };
    phases.push(("open", t.elapsed()));
    let fd = tty.as_raw_fd();
    let borrowed = unsafe { BorrowedFd::borrow_raw(fd) };

    // Phase 2: tcgetattr
    let t = Instant::now();
    let original = match tcgetattr(borrowed) {
        Ok(t) => t,
        Err(e) => { eprintln!("tcgetattr failed: {e}"); print_phases(&phases, overall); return; }
    };
    phases.push(("tcgetattr", t.elapsed()));

    // Phase 3: install_panic_hook (mirrors bg_detect::install_panic_hook)
    let t = Instant::now();
    let mux = PANIC_SLOT.get_or_init(|| Mutex::new(None));
    if let Ok(mut g) = mux.lock() { *g = Some((fd, original.clone())); }
    // (Skipping actual set_hook to avoid affecting siblings; the OnceLock+Mutex
    // contention path is what we measure here.)
    phases.push(("install_panic_hook", t.elapsed()));

    // Phase 4: cfmakeraw
    let t = Instant::now();
    let mut raw = original.clone();
    cfmakeraw(&mut raw);
    phases.push(("cfmakeraw", t.elapsed()));

    // Phase 5: tcsetattr(raw)
    let t = Instant::now();
    if let Err(e) = tcsetattr(borrowed, SetArg::TCSANOW, &raw) {
        eprintln!("tcsetattr raw failed: {e}"); print_phases(&phases, overall); return;
    }
    phases.push(("tcsetattr_raw", t.elapsed()));

    // Phase 6: write OSC query
    let t = Instant::now();
    let _ = write(borrowed, b"\x1b]11;?\x1b\\");
    phases.push(("write_osc11", t.elapsed()));

    // Phase 7: read_until_terminator loop
    let t = Instant::now();
    let deadline = Instant::now() + Duration::from_millis(OSC11_READ_TIMEOUT_MS as u64);
    let mut buf: Vec<u8> = Vec::with_capacity(64);
    let mut poll_iters = 0usize;
    loop {
        let now = Instant::now();
        if now >= deadline { break; }
        let remaining = deadline - now;
        let mut pollfds = [PollFd::new(borrowed, PollFlags::POLLIN)];
        let timeout = PollTimeout::try_from(remaining.as_millis() as i32).unwrap_or(PollTimeout::MAX);
        poll_iters += 1;
        let ready = match nix::poll::poll(&mut pollfds, timeout) {
            Ok(n) => n,
            Err(e) => { eprintln!("poll error: {e}"); break; }
        };
        if ready == 0 { break; }
        let mut chunk = [0u8; 64];
        match read(borrowed.as_raw_fd(), &mut chunk) {
            Ok(0) | Err(_) => break,
            Ok(n) => {
                buf.extend_from_slice(&chunk[..n]);
                if buf.iter().any(|&b| matches!(b, 0x07 | 0x1B | 0x9C)) { break; }
                if buf.len() >= 128 { break; }
            }
        }
    }
    eprintln!("  read_loop_iters: {poll_iters}");
    eprintln!("  read_bytes: {}", buf.len());
    phases.push(("read_until_terminator", t.elapsed()));

    // Phase 8: drain_remaining (O_NONBLOCK toggle)
    let t = Instant::now();
    if let Ok(prior_bits) = fcntl(borrowed.as_raw_fd(), FcntlArg::F_GETFL) {
        let prior = OFlag::from_bits_truncate(prior_bits);
        if fcntl(borrowed.as_raw_fd(), FcntlArg::F_SETFL(prior | OFlag::O_NONBLOCK)).is_ok() {
            let mut drain_buf = [0u8; 64];
            for _ in 0..256 {
                match read(borrowed.as_raw_fd(), &mut drain_buf) {
                    Ok(0) | Err(_) => break,
                    Ok(_) => {}
                }
            }
            let _ = fcntl(borrowed.as_raw_fd(), FcntlArg::F_SETFL(prior));
        }
    }
    phases.push(("drain_remaining", t.elapsed()));

    // Phase 9: suppress_query_echo
    let t = Instant::now();
    let _ = write(borrowed, b"\r\x1b[K");
    phases.push(("suppress_echo", t.elapsed()));

    // Phase 10: tcsetattr(restore)
    let t = Instant::now();
    let _ = tcsetattr(borrowed, SetArg::TCSANOW, &original);
    if let Some(mux) = PANIC_SLOT.get() {
        if let Ok(mut g) = mux.lock() { *g = None; }
    }
    phases.push(("tcsetattr_restore", t.elapsed()));

    print_phases(&phases, overall);
}

fn print_phases(phases: &[(&'static str, Duration)], overall: Instant) {
    eprintln!("overall: {:?}", overall.elapsed());
    for (name, d) in phases {
        eprintln!("  {name}: {d:?}");
    }
}
```

### 4.4 D karar ağacı (deliverable-gated sub-task'lar)

**Sub-task D-1 — Implement diagnostic.** `examples/repro_osc11_hang.rs` yazılır (§4.3 skeleton). Lokal macOS terminalde çalıştırılır (OSC 11 response gelmesi beklenir) ve CI'de portable-pty subprocess'inde çalıştırılır (response yok, hang gözlemi). Çıktı: phase timings.

**Sub-task D-2 — Interpret + select scenario.** D-1 çıktısına göre:

**Sub-task D-3 — Apply chosen scenario.**
