## §4 — Module structure

### §4.1 — Yeni `src/config_tui/reconcile.rs`

```
//! PendingEdits → DocumentMut walk + serialize.
//!
//! Pure data-transform module: takes a frozen DocumentMut + staged
//! edits, returns the new TOML source bytes. No I/O, no side effects.
//!
//! Public-to-crate API:
//!   pub(crate) fn apply_edits(doc, edits) -> Result<String, ReconcileError>
//!
//! Spec §5 — handler-by-handler walk. Spec §6 — ReconcileError variants.
```

**Public-to-crate items:**
- `pub(crate) fn apply_edits(doc: &toml_edit::DocumentMut, edits: &PendingEdits) -> Result<String, ReconcileError>` — **honesty note (B3 fold):** implementation clones `doc` internally (`let mut working = doc.clone();`). `DocumentMut::clone()` is O(n) tree-walk; acceptable for save-on-Ctrl+S frequency (not a hot path). Caller passes `&snapshot.doc`; defensive clone keeps snapshot.doc immutable.
- `pub(crate) enum ReconcileError { ... }` (Display impl + Debug + `#[derive(thiserror::Error)]`)

**Private items:**
- `fn apply_general(doc: &mut DocumentMut, ge: &GeneralEdits) -> Result<(), ReconcileError>`
- `fn apply_user_config_rule(doc: &mut DocumentMut, name: &str, edit: &RuleEdit) -> Result<(), ReconcileError>`
- `fn apply_new_rule(doc: &mut DocumentMut, rule: &NewRule) -> Result<(), ReconcileError>`
- `fn apply_deletion(doc: &mut DocumentMut, rule_id: &RuleId) -> Result<(), ReconcileError>`
- `fn set_or_insert(target: StyleTargetMut<'_>, key: &str, val: toml_edit::Value)` — **B4 + I2 fold:** branches on Inline vs Table; `Inline` branch uses `insert(key, val)` (avoids `InlineTable::IndexMut` panic on absent key); `Table` branch uses `table[key] = Item::Value(val)`. Returns nothing (no error path — both branches are panic-free).
- `fn write_style_table(target: StyleTargetMut<'_>, ns: &NewStyle) -> Result<(), ReconcileError>` — Color encode + bool axes; uses `set_or_insert` for add/replace; `target.remove(key)` for fg/bg clear.
- `fn ensure_general_table(doc: &mut DocumentMut) -> Result<&mut toml_edit::Table, ReconcileError>` — **B5 fold:** Result return; emits `TypeMismatch { path: "general", expected: "table", actual: ... }` when key exists as non-Table Item (e.g., user wrote `[[general]]`).
- `fn find_rule_index_by_name(rules: &toml_edit::ArrayOfTables, name: &str) -> Option<usize>` — **I1 fold:** signature reconciled — takes `&ArrayOfTables` (not `&DocumentMut`); no lifetime parameter; linear scan, ilk eşleşen `name = "X"` index'i. **Defensive N-bound (N1 NIT):** linear scan acceptable because N is bounded by `MAX_CONFIG_BYTES / minimum-entry-size ≈ 20k`; expected N is 5-50 in real use.

**Reconcile.rs uzunluk hedefi:** ~150-200 LOC handler logic + ~150-200 LOC test = ~300-400 LOC total.

### §4.4 — `commit_save` impact (save.rs:226)

Mevcut:


`?` operator io::Result return type ile uyumlu. commit_save signature `Result<ConfigSnapshot>` (io::Result) — değişmez.

**Orphan-backup-on-reconcile-fail trade-off (I6 fold):** `build_new_content` Step 4'te (rotate Step 1 + read_disk Step 2 + write_backup Step 3'ten SONRA) çağrılır. Reconcile fail ederse `?` propagates ve commit_save erken return eder — ama **backup zaten yazılmıştır** (Step 3). Bu **kabul edilebilir** çünkü:
- (a) **Quota.** Step 1 rotated to `MAX_BACKUPS - 1`; Step 3 yazdı; toplam `MAX_BACKUPS`. Cap aşılmaz.
- (b) **Backup content.** Orphan backup `disk_now` içerir (pre-edit on-disk bytes) — backup semantics'in tam vaat ettiği şey.
- (c) **User perception.** Failed save bir backup üretti; user retry eder, sonraki başarılı save bir backup daha üretir, rotation orphan'ı zamanla dışarı atar.

Test I5 (§7.2) post-fail backup-file-exists assertion'ı ekler (memory `feedback_parallel_call_site_invariant_audit` mandate).

## §5 — PendingEdits → DocumentMut walk algoritması

### §5.1 — Top-level orchestrator (`apply_edits`)

```rust
pub(crate) fn apply_edits(
    doc: &DocumentMut,
    edits: &PendingEdits,
) -> Result<String, ReconcileError> {
    let mut doc = doc.clone(); // Defensive — snapshot.doc dokunulmaz
    apply_general(&mut doc, &edits.general)?;
    for (rule_id, rule_edit) in &edits.rules {
        match rule_id {
            RuleId::UserConfig(name) => apply_user_config_rule(&mut doc, name, rule_edit)?,
            // v0.5.4 tabs sadece UserConfig stage ediyor; defensive skip:
            RuleId::Builtin(_) | RuleId::Embedded { .. } | RuleId::DiskProfile { .. } => {
                // No-op: edit'ler bu variants altında staged değil; v0.6+ bu paths wire'lanır
            }
        }
    }
    for new_rule in &edits.added {
        apply_new_rule(&mut doc, new_rule)?;
    }
    for rule_id in &edits.deleted {
        apply_deletion(&mut doc, rule_id)?;
    }
    Ok(doc.to_string())
}
```

**Order of operations (deterministic for test pinning):**
1. General — `[general]` table mutations en başta (doc'un en altında ya da en üstündeki [general]'ı bulur, mevcut konum korunur).
2. UserConfig rule edits — HashMap iter order non-deterministic, ama her edit ATOMİK ve birbirinden bağımsız (rule_id unique). Test'lerde tek-edit case'leri kullanılır; multi-edit test'lerde HashMap iter order'ı assertion'ı bozmaz çünkü output'un her satırını ayrı pin'leriz.
3. New rules append — sondan başlar; Vec order korunur.
4. Deletions — son; en güvenli (önce edit, sonra silme — referential consistency için).

### §5.2 — `apply_general(doc, &GeneralEdits)` + `ensure_general_table` (B5 + N1 + N4 fold)

```rust
fn apply_general(doc: &mut DocumentMut, ge: &GeneralEdits) -> Result<(), ReconcileError> {
    // N1 fold: no early-return; both arms (None/Some) below are no-ops if no edit.
    let general = ensure_general_table(doc)?;
    match &ge.theme {
        None => {} // unedited — preserve disk state
        Some(None) => { general.remove("theme"); }
        Some(Some(name)) => { general["theme"] = toml_edit::value(name.as_str()); }
    }
    match &ge.profile {
        None => {}
        Some(None) => { general.remove("profile"); }
        Some(Some(name)) => { general["profile"] = toml_edit::value(name.as_str()); }
    }
    Ok(())
}

fn ensure_general_table(doc: &mut DocumentMut) -> Result<&mut toml_edit::Table, ReconcileError> {
    if !doc.contains_key("general") {
        let mut t = toml_edit::Table::new();
        // N4 NIT: set_implicit(false) defensive — Table::new() default is non-implicit
        // but explicit pin guards against toml_edit default-change in future versions.
        t.set_implicit(false);
        doc["general"] = toml_edit::Item::Table(t);
        // Fresh-create path: as_table_mut succeeds by construction.
        return Ok(doc["general"].as_table_mut().unwrap_or_else(|| {
            unreachable!("doc[\"general\"] was just set to Item::Table; toml_edit invariant violation if not Table now")
        }));
    }
    // B5 fold: existing-key path — emit TypeMismatch on non-Table Item.
    let item = &mut doc["general"];
    let actual_ty = item.type_name();
    item.as_table_mut().ok_or(ReconcileError::TypeMismatch {
        path: "general".into(),
        expected: "table",
        actual: actual_ty,
    })
}
```

**Tri-state pin'leri:**
- `None` — disk state preserve (key var ise korunur; yok ise yok kalır).
- `Some(None)` — key DELETE (TUI'de user explicit clear etti).
- `Some(Some(s))` — key SET (TUI'de user yeni name seçti).

**Dotted-form preservation (TOML §3):** Eğer disk'te `general.theme = "dark"` dotted-key form'unda yazılmış (no explicit `[general]` header), `contains_key("general")` true döner, `ensure_general_table` mevcut `Item::Table` (`set_dotted(true)`) ile döner; mutation dotted form'u korur (`general.theme = "light"` çıktısı). Test gerekirse §7.1 ekstradan kapsayabilir; v0.5.5 contract: "form-preserving on existing keys".

**Key-removal comment-attachment (TOML §1):** `remove("theme")` öncesi `# this controls theme\ntheme = "dark"` ise comment removed key ile birlikte gider (yorum mevcut anahtara aitti, anahtar yok artık → yorum da yok). Doğru semantik.

### §5.3 — `apply_user_config_rule(doc, name, &RuleEdit)`

```rust
fn apply_user_config_rule(
    doc: &mut DocumentMut,
    name: &str,
    edit: &RuleEdit,
) -> Result<(), ReconcileError> {
    let rules = ensure_rules_array(doc)?;
    let idx = find_rule_index_by_name(rules, name);
    let rule_table = match idx {
        Some(i) => {
            // B1 fold: hoist type_name() capture BEFORE as_table_mut() to avoid
            // closure-reads-rules-while-mutably-borrowed double-borrow.
            let item = rules.get_mut(i).unwrap_or_else(|| {
                unreachable!("find_rule_index_by_name returned valid idx {i}; toml_edit ArrayOfTables index invariant violation if hit")
            });
            let actual_ty = item.type_name();
            item.as_table_mut().ok_or(ReconcileError::TypeMismatch {
                path: format!("rules[{i}]"),
                expected: "table",
                actual: actual_ty,
            })?
        }
        None => {
            // I12 fold: Table::insert("name", ...) uses bare-quoted form
            // automatically; that's fine for "name" key (no quoting controversy).
            let mut t = toml_edit::Table::new();
            t["name"] = toml_edit::value(name);
            rules.push(t);
            // I4 fold: replace .expect("just pushed").expect("just made") with
            // unreachable! since both branches just-constructed the value.
            let last_idx = rules.len() - 1;
            rules.get_mut(last_idx)
                .unwrap_or_else(|| unreachable!("just pushed; toml_edit invariant violation"))
                .as_table_mut()
                .unwrap_or_else(|| unreachable!("just constructed as Table; toml_edit invariant violation"))
        }
    };
    if let Some(pat) = &edit.pattern {
        rule_table["pattern"] = toml_edit::value(pat.as_str());
    }
    for (style_key, ns) in &edit.styles {
        let style_target = match style_key {
            StyleKey::Default => ensure_style_target(rule_table, "style")?,
            StyleKey::Numbered(i) => {
                let styles = ensure_subtable(rule_table, "styles")?;
                // I12 fold: use Key::new("\"i\"") (literal-string repr) to
                // preserve v0.3.5 documented convention styles."1" (quoted).
                ensure_style_target_quoted_numbered(styles, *i)?
            }
            StyleKey::Named(n) => {
                let styles = ensure_subtable(rule_table, "styles")?;
                ensure_style_target(styles, n.as_str())?
            }
        };
        write_style_table(style_target, ns)?;
    }
    Ok(())
}
```

**ensure_rules_array:** `doc.entry("rules").or_insert(ArrayOfTables::new())` benzeri; type mismatch ise `ReconcileError::TypeMismatch { path: "rules", expected: "array-of-tables", actual: ... }`.

**find_rule_index_by_name:** `fn find_rule_index_by_name(rules: &ArrayOfTables, name: &str) -> Option<usize>` — linear scan, ilk eşleşen `name = "X"` index'i. **N-bound (N1 NIT):** linear scan acceptable çünkü N bounded by `MAX_CONFIG_BYTES / minimum-entry-size ≈ 20k`; expected N 5-50 real use.

**ensure_style_target + form-preservation contract (I3 + I10 fold):** mevcut anahtar varsa **existing form preserve eder** — `style = { fg = "red" }` inline ise inline kalır (`as_inline_table_mut`'tan `StyleTargetMut::Inline(&mut InlineTable)` döner), `[rules.style]` block ise block kalır (`as_table_mut`'tan `StyleTargetMut::Table(&mut Table)` döner). **Yeni create case: always inline** — fresh `style` veya `styles."N"` slot'u inline-table olarak başlar (v0.5.5 contract: assets/profiles/*.toml mevcut konvansiyonu + user-config çoğunlukla inline). **NEVER form-flip** — edit'te bir form'dan diğerine convert etmez. Test #18a/#18b (§7.1) bu invariant'ı pin'ler.

**Pattern repr mutation contract (I8 fold):** `rule_table["pattern"] = toml_edit::value(pat.as_str())` mevcut `Repr`'i drop eder; `Value::String(Formatted::new(s))` yeni `repr: None` ile yaratılır. `Display` time'da toml_edit `as_default()` formatting seçer — `as_basic_pretty` → `as_literal` → `as_ml_basic_pretty` → `as_ml_literal` → fallback. `\b[a-z]+\b` regex'i için: `\` içerir → `as_basic_pretty` reject; `'` yok, newline yok → `as_literal` accept → **çıktı: `pattern = '\b[a-z]+\b'` literal-string, no escaping, byte-identical regex semantic**. Test #16 (§7.1) bu invariant'ı pin'ler.

**Caveat — user-written escaped basic-string form not preserved (I8):** Disk'te `pattern = "\\b[a-z]+\\b"` (escaped basic-string) varsa ve TUI mutation yaparsa, çıktı `pattern = '\b[a-z]+\b'` (literal-string) olur. Functionally identical regex; visually different. v0.5.5 documented contract; v0.6+ regex-source editor revisit edebilir.

**Key reformatting on mutation (I9 fold):** `Table::insert("pattern", ...)` mevcut key occupied ise `key_mut().fmt()` çağırır → `Key::repr`'i temizler (auto-format) ama `Key::leaf_decor`'u (key satırı öncesi comment block) **korur**. v0.5.5 contract: mutate eden key'in preceding comment'leri survive eder. ### §5.4 — `write_style_table` + `set_or_insert` dispatcher (B4 + I2 + I10 fold)

**StyleTargetMut helper enum + set_or_insert helper-fn:**

```rust
// Helper-fn dispatch (I2 fold: drop StyleTarget<'a> enum proposal — too lifetime-coupled).
// StyleTargetMut is a borrow handle, not a stored type.
pub(crate) enum StyleTargetMut<'a> {
    Inline(&'a mut toml_edit::InlineTable),
    Table(&'a mut toml_edit::Table),
}

impl<'a> StyleTargetMut<'a> {
    fn remove(&mut self, key: &str) {
        match self {
            Self::Inline(it) => { it.remove(key); }
            Self::Table(t) => { t.remove(key); }
        }
    }
}

// B4 fold: insert helper avoids InlineTable::IndexMut panic-on-absent.
// For Inline: always use insert(key, val) (replaces or adds).
// For Table: use Table::insert (also replaces-or-adds via IndexMap entry).
fn set_or_insert(target: &mut StyleTargetMut, key: &str, val: toml_edit::Value) {
    match target {
        StyleTargetMut::Inline(it) => { it.insert(key, val); }
        StyleTargetMut::Table(t) => { t.insert(key, toml_edit::Item::Value(val)); }
    }
}

fn write_style_table(
    mut target: StyleTargetMut<'_>,
    ns: &NewStyle,
) -> Result<(), ReconcileError> {
    match &ns.fg {
        None => {}
        Some(None) => { target.remove("fg"); }
        Some(Some(color)) => set_or_insert(&mut target, "fg", value(color.to_toml_str()).into_value().expect("scalar")),
    }
    match &ns.bg {
        None => {}
        Some(None) => { target.remove("bg"); }
        Some(Some(color)) => set_or_insert(&mut target, "bg", value(color.to_toml_str()).into_value().expect("scalar")),
    }
    if let Some(b) = ns.bold { set_or_insert(&mut target, "bold", value(b).into_value().expect("scalar")); }
    if let Some(b) = ns.italic { set_or_insert(&mut target, "italic", value(b).into_value().expect("scalar")); }
    if let Some(b) = ns.underline { set_or_insert(&mut target, "underline", value(b).into_value().expect("scalar")); }
    if let Some(b) = ns.dim { set_or_insert(&mut target, "dim", value(b).into_value().expect("scalar")); }
    Ok(())
}
```

**Form-preservation contract (I10 fold):** `write_style_table` mevcut form'u **NEVER form-flip etmez** — `style = { ... }` inline ise inline kalır; `[rules.style]` block ise block kalır.
