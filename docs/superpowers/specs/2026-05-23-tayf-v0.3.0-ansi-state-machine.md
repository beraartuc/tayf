## 1. Vizyon

`src/pipeline.rs::TuiModeSm` (v0.1) byte stream'inde sadece `CSI ? Pm h/l` sequence'lerini tanıyor. Geri kalan her şey (OSC, SGR, non-CSI ESC, DCS/PM/APC) `Ground` state'ine atılıyor → byte'lar line buffer'a giriyor → regex'lere maruz kalıyor. Sonuçlar:

- **OSC hyperlink** (`\e]8;;https://...\alabel\e]8;;\a`) URL'si `url` rule'una takılıyor → görsel kaza.
- **OSC title** (`\e]2;...\a`), **OSC prompt marker** (`\e]133;A\a`), **OSC clipboard** (`\e]52;...\a`) ile aynı sorun.
- **SGR sequence** (`\e[31m`) line buffer'a giriyor; mevcut `respect_existing_colors = true` config field'ı hot path'a girmediği için no-op.
- **Non-CSI ESC** (`\eM`, `\e7`, `\e=`) ve özellikle `\ec` (RIS, full terminal reset) line buffer'a girip rule'lara takılabiliyor.
- **Multi-byte ESC** (`\e(B` G0 designate, `\e#8` DEC alignment test) — `vim`, `less`, `reset(1)` bunları gönderir; line buffer'a giriyor.
- **DCS/PM/APC** (`\eP...\e\\`, `\e^...\e\\`, `\e_...\e\\`) — kitty graphics, tmux passthrough, terminal device attribute query'leri kullanır; line buffer'a giriyor.

v0.3.0 mevcut SM'i **Paul Williams' VT500 parser şemasına** (https://vt100.net/emu/dec_ansi_parser) oturtarak yukarıdaki tüm kategorileri doğru parse eder. Trigger sequence byte'ları (`\e[?1049h` gibi alt-screen entry) line_buffer'a hiç girmez — Pipeline bir scratch buffer'da sequence'i biriktirir, sequence türü belirlenince scratch ya stdout'a (TUI toggle / string payload öncesi introducer) ya da line_buffer'a (SGR / diğer CSI / single-byte ESC) aktarılır. `respect_existing_colors` config'i hot-reload-aware olarak devreye girer.

### Hedefler

- Williams VT500 parser şemasının tayf'ın ihtiyacına gore yeterli alt-kümesi: 14 state (Williams' 17 state'inin alt kümesi; SOS_PM_APC ayrı state, X state'i hariç).

- Hot-reload-aware: `respect_existing_colors`'ı `Compiled` struct'ına koy, mevcut `ArcSwap<Compiled>` üzerinden atomic okuma (line boundary'de).
- State machine kendi modülünde (`src/ansi.rs`, ~280-320 satır). `src/pipeline.rs` SM'den temizlenir, sadece Pipeline + apply_rules kalır (~380 satır).
- Adversarial test corpus'u: 27 unit, 6 integration test.
- Throughput regression < %20 (umbrella §4.2 bütçesi); criterion baseline ile doğrulanır.

## 3. State machine — Williams VT500 şeması

### 3.1 Referans

Paul Williams' parser şeması (https://vt100.net/emu/dec_ansi_parser) modern ANSI terminal parser'larının canonical referansı. `vte` crate, `Alacritty`, `WezTerm`, `kitty`, `xterm` hepsi Williams şemasını implement ediyor. `src/ansi.rs`'in module doc-comment'ı bu referansa explicit link verir; gelecekte bir sequence türü eklemek isteyen herkes Williams'a bakmak zorundadır, kendi state'ini icat etmez.

### 3.2 State listesi (14 state)

Williams'ın tam 17 state'inin tayf'a yeten 14'ü. (Karar 6 uyarınca 8-bit C1 hassasiyetli state'ler hariç.)

| # | State | Anlam |
|---|---|---|
| 1 | `Ground` | Normal text; her byte data |
| 2 | `Escape` | `\e` tüketildi; bir sonraki byte sequence şeklini belirler |
| 3 | `EscapeIntermediate` | `\e` + intermediate byte (0x20..0x2F); multi-byte ESC için (`\e(B`, `\e#8`) |
| 4 | `CsiEntry` | `\e[` tüketildi |
| 5 | `CsiParam` | CSI parametre toplama; `?`/`<`/`=`/`>` private prefix de burada |
| 6 | `CsiIntermediate` | CSI parametre sonrası intermediate byte |
| 7 | `CsiIgnore` | CSI ortasında geçersiz byte (colon-as-separator vd.); final byte gelene kadar drop |
| 8 | `OscString` | `\e]` payload toplama; terminator: BEL (0x07) veya 7-bit ST (`\e\\`) |
| 9 | `OscEsc` | `OscString` içinde `\e` görüldü; ST peek-ahead için (sonraki byte `\` ise ST tamamlanır, değilse string abort) |
| 10 | `DcsEntry` | `\eP` tüketildi |
| 11 | `DcsParam` | DCS parametre toplama |
| 12 | `DcsIntermediate` | DCS intermediate byte |
| 13 | `DcsPassthrough` | DCS final byte tüketildi, payload bekleniyor; terminator: ST |
| 14 | `DcsIgnore` / `SosPmApcString` | Birleşik state: DCS-ignore ve PM/APC string'i aynı davranışa sahip — ST gelene kadar drop/passthrough |

Williams'ın `DcsHook` vs `DcsPassthrough` ayrımı tayf için gereksiz; `DcsHook` ile `DcsPassthrough`'u tek state olarak birleştiriyoruz çünkü tayf payload'ı interpret etmiyor.

### 3.3 Byte range adlandırması (Williams' nomenclature)

```
0x00..0x17, 0x19, 0x1C..0x1F          C0_CONTROL    (BS, BEL, vd. — passthrough)
0x18, 0x1A                             CAN_SUB       (YAGNI — Karar 4)
0x1B                                   ESC           (sequence başlatır)
0x20..0x2F                             INTERMEDIATE  (intermediate byte)
0x30..0x39                             DIGIT         (digit parametresi)
0x3A                                   COLON         (parametre separator candidate)
0x3B                                   SEMICOLON     (parametre separator)
0x3C..0x3F                             PRIVATE_PREFIX (`<=>?`)
0x40..0x7E                             FINAL         (CSI/ESC final byte)
0x7F                                   DEL           (passthrough)
0x80..0xFF                             UTF8/8BIT     (data; 8-bit C1 destek dışı — Karar 6)
```

`PARAMETER` range Williams'ta tek bir kategori (0x30..0x3F) ama tayf için davranış farkı önemli:
- `DIGIT` + `SEMICOLON` (param ayraç): `CsiParam` accum'a yazar.
- `COLON` (0x3A): tayf'ta ignored — `CsiIgnore`'a düşer (ECMA-48 reserved separator; tayf'ın 13 built-in pattern'i colon kullanmıyor).
- `PRIVATE_PREFIX` (`<=>?`): `CsiParam`'da accum'a yazılmaz, sadece bayrak set eder (`private_mode: bool`). Sequence final'ında private_mode'a göre toggle kararı verilir.

### 3.4 Transition tablosu

Williams' "Anywhere + ESC → Escape" (entry actions clear scratch). Tablonun tüm satırları "Anywhere" kuralının altında — herhangi bir state'te `\e` görmek mevcut sequence'i abort eder ve `Escape`'e atlar.

```
Anywhere     + ESC                 → Escape          (resync; SM scratch flag set: aborted)
Anywhere     + 8-bit C1 (0x80..0x9F) → (ignored as data; passthrough Data event) (Karar 6: 7-bit only)

Ground       + DIGIT|SEMI|COLON|FINAL|PRIVATE_PREFIX|INTERMEDIATE → Data event
Ground       + ESC                  → Escape

Escape       + INTERMEDIATE         → EscapeIntermediate
Escape       + [                    → CsiEntry
Escape       + ]                    → OscString
Escape       + P                    → DcsEntry
Escape       + X | ^ | _            → SosPmApcString
Escape       + DIGIT|SEMI|COLON|FINAL (0x30..0x7E excluding [, ], P, X, ^, _, \)
                                    → SequenceCompleted::EscFinal (single-byte ESC final; Ground)
Escape       + \  (0x5C)            → (Williams: ST in Escape state has no effect; consume → Ground)

EscapeIntermediate + INTERMEDIATE   → EscapeIntermediate (chain)
EscapeIntermediate + 0x30..0x7E     → SequenceCompleted::EscIntermediateFinal (Ground)

CsiEntry     + DIGIT                → CsiParam (accum digit)
CsiEntry     + SEMICOLON            → CsiParam (separator)
CsiEntry     + COLON                → CsiIgnore (reserved)
CsiEntry     + PRIVATE_PREFIX       → CsiParam (set private_mode flag)
CsiEntry     + INTERMEDIATE         → CsiIntermediate
CsiEntry     + FINAL                → SequenceCompleted with kind based on final byte (Ground)
                                       - if final == 'h' or 'l' with private_mode set and accum is TUI mode: TuiToggleOn/Off
                                       - if final == 'm': Sgr
                                       - else: OtherCsi

CsiParam     + DIGIT                → CsiParam (accum digit)
CsiParam     + SEMICOLON            → CsiParam (param boundary)
CsiParam     + COLON                → CsiIgnore
CsiParam     + PRIVATE_PREFIX       → CsiIgnore (Williams: private prefix only at sequence start)
CsiParam     + INTERMEDIATE         → CsiIntermediate
CsiParam     + FINAL                → SequenceCompleted with kind (same logic as CsiEntry + FINAL)

CsiIntermediate + INTERMEDIATE      → CsiIntermediate
CsiIntermediate + DIGIT|SEMICOLON|COLON|PRIVATE_PREFIX → CsiIgnore
CsiIntermediate + FINAL             → SequenceCompleted::OtherCsi (Ground) (Williams: intermediates change final semantics; tayf treats as non-SGR)

CsiIgnore    + FINAL                → SequenceCompleted::OtherCsi (Ground; sequence dropped, scratch goes to line_buffer)
CsiIgnore    + (0x00..0x3F)         → CsiIgnore (consume, no-op; Williams)

OscString    + 0x07 (BEL)           → Ground (sequence ended; StringPayloadByte for the BEL)
OscString    + ESC                  → OscEsc (peek-ahead for ST)
OscString    + (other data 0x00..0xFF except ESC and BEL) → OscString (StringPayloadByte event)

OscEsc       + \  (0x5C)            → Ground (ST completed; both \e and \ as StringPayloadByte events emitted in order)
OscEsc       + (other)              → Escape's behavior on the new byte (string sequence aborted;
                                       \e of OscEsc consumed silently; new byte starts new sequence from Escape state)

DcsEntry     + DIGIT|SEMICOLON      → DcsParam
DcsEntry     + COLON|PRIVATE_PREFIX → DcsIgnore (treated like CsiIgnore for DCS)
DcsEntry     + INTERMEDIATE         → DcsIntermediate
DcsEntry     + FINAL                → DcsPassthrough (data follows)

DcsParam     + DIGIT|SEMICOLON      → DcsParam
DcsParam     + INTERMEDIATE         → DcsIntermediate
DcsParam     + COLON|PRIVATE_PREFIX → DcsIgnore
DcsParam     + FINAL                → DcsPassthrough

DcsIntermediate + INTERMEDIATE      → DcsIntermediate
DcsIntermediate + 0x30..0x3F        → DcsIgnore
DcsIntermediate + FINAL             → DcsPassthrough

DcsPassthrough + ESC                → DcsEsc (analogous to OscEsc)
DcsPassthrough + (other)            → DcsPassthrough (StringPayloadByte event)

DcsEsc       + \                    → Ground (ST completed)
DcsEsc       + (other)              → Escape (DCS aborted; new sequence from new byte)

SosPmApcString + ESC                → SosPmApcEsc
SosPmApcString + (other)            → SosPmApcString (StringPayloadByte event)

SosPmApcEsc  + \                    → Ground (ST completed)
SosPmApcEsc  + (other)              → Escape (string aborted)

DcsIgnore    + ESC                  → DcsEsc (terminate handling)
DcsIgnore    + (other)              → DcsIgnore (silently dropped)
```

### 3.5 `StepEvent` enum (Karar 7)

Pipeline'a sunulan event modeli. Karar: byte başına event döner ama sequence tamamlandığında SM `SequenceCompleted(kind)` döner — kind Pipeline'a scratch'in nereye gideceğini söyler.

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum StepEvent {
    /// Ground state'inde normal data byte. Pipeline byte'ı line_buffer'a yazar.
    /// Invariant: bu event geldiğinde SM scratch'i boş (Ground state'inde).
    Data,

    /// Sequence'in ortasındaki byte. Pipeline byte'ı sequence_scratch'e ekler.
    /// SM hangi sequence kategorisinde olduğunu henüz Pipeline'a söylemiyor.
    SequenceByte,

    /// OSC/DCS-passthrough/PM/APC payload byte'ı. Pipeline byte'ı direkt stdout'a yazar.
    /// Invariant: bu event geldiğinde scratch boş veya az önce StringPayloadByte
    /// olarak flush edildi (introducer byte'larıyla).
    StringPayloadByte,

    /// Bir CSI veya ESC sequence'i tamamlandı. Kind'a göre Pipeline scratch'in
    /// destination'ını belirler. Final byte da scratch'e eklendikten sonra event işlenir.
    /// Çıkış action: SM Ground'a döner; scratch flush sonrası temizlenir.
    SequenceCompleted(SequenceKind),
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum SequenceKind {
    /// CSI ?Pm h/l bir TUI flag (alt-screen / paste / mouse) set etti.
    /// Pipeline: scratch'i (final byte dahil) stdout'a yazar; sonraki byte'ları
    /// TUI passthrough modunda işler (tüm byte'lar stdout'a).
    TuiToggleOn,

    /// Yukarıdakinin tersi.
    /// Pipeline: scratch'i stdout'a yazar; TUI passthrough modundan çıkar.
    TuiToggleOff,

    /// CSI ending in 'm' (SGR).
    /// Pipeline: scratch'i line_buffer'a aktarır; line_has_sgr=true.
    Sgr,

    /// CSI ending in any other final, OR CsiIgnore terminated.
    /// Pipeline: scratch'i line_buffer'a aktarır; line_has_sgr değişmez.
    OtherCsi,

    /// Non-CSI ESC sequence: single-byte final (`\e=`, `\eM`, `\e7`, `\e8`, `\ec`, vd.).
    /// Pipeline: scratch'i (2 byte) line_buffer'a aktarır.
    EscFinal,

    /// Multi-byte ESC sequence (`\e(B`, `\e#8`).
    /// Pipeline: scratch'i (3+ byte) line_buffer'a aktarır.
    EscIntermediateFinal,
}
```

**OSC/DCS/PM/APC introducer bytes' handling:** İlk byte (`\e`) `SequenceByte` (scratch'e). İkinci byte (`]`, `P`, `^`, `_`, `X`) SM'i string state'ine geçirir; aynı zamanda Pipeline'a `StringPayloadByte` döner — Pipeline scratch'i (`\e` byte'ını) stdout'a flush eder ve mevcut byte'ı stdout'a yazar. Sonraki tüm payload byte'ları `StringPayloadByte` (scratch boş, byte direct stdout). Terminator (`\a` BEL, `\e\\` ST) de `StringPayloadByte` döner — terminal terminator'ü görmek zorunda.

**OSC/DCS abort path (lone ESC mid-string):** `OscString + \e → OscEsc` state'ine geçer. Sonraki byte:
- `\` → ST completed. SM iki `StringPayloadByte` event'i emit eder: önce `\e` (peek-ahead'in tamamlandığı an), sonra `\` (terminator'ün son byte'ı). SM `Ground`'a döner.
- Diğer byte → string aborted. SM `\e`'yi sessizce drop eder (terminal ne yapacak: kendisi de abort eder; tayf'ın stdout'a yazmaması ekstra desync getirmez). Sonraki byte `Escape` state'inden işlenir (bu byte için SM `Escape` davranışını uygular ve uygun event döner).

### 3.6 `tui_mode_active()`

Pipeline.feed `self.sm.tui_mode_active()` predicate'ini okur:

- Mevcut `TuiModeSm::passthrough()` davranışı: alt-screen / paste / mouse bayraklarından biri set mi?
- `SequenceCompleted::TuiToggleOn` event'i bu flag'i set eder; `TuiToggleOff` clear eder.
- State'in `Ground` veya `Escape` olması bu flag'i etkilemez.

## 4. Yeni davranışlar

### 4.1 OSC / DCS / PM / APC passthrough — partial line preserved

OSC sequence başladığında (`\e]`) SM `OscString` state'ine geçer. Pipeline `StringPayloadByte` event'lerini görür ve byte'ları doğrudan `out.write_all`'a yazar. Line_buffer'a hiç sokulmaz — line_buffer'ın o anki kısmi içeriği **korunur**. Sequence bittikten sonra normal data byte'ları yeniden line_buffer'a girer; `\n` geldiğinde sequence öncesi + sonrası tek satır olarak `apply_rules`'a geçer.

Senaryo: `error \e]8;;https://x\aclick\e]8;;\a here\n`
- `error ` → 6 Data event → line_buffer.
- `\e` → SequenceByte → scratch.
- `]` → StringPayloadByte → scratch (`\e`) flush stdout, `]` stdout.
- `8;;https://x` → StringPayloadByte her byte → stdout.
- `\a` → StringPayloadByte → stdout (OSC bitti, SM Ground'a döndü).
- `click` → 5 Data event → line_buffer.
- `\e]8;;\a` → ikinci OSC, aynı şekilde stdout direct.
- ` here\n` → 5 Data + 1 newline → line_buffer; `\n` line'ı kapatır.
- `apply_rules` `error  here` üzerinde çalışır (boşluk x2 — sequence öncesi/sonrası). Hyperlink byte'ları görünmüyor.

Stdout output: `error \e]8;;https://x\aclick\e]8;;\a here\n` — hyperlink intakt, byte ordering korunmuş, regex hyperlink URL'sine müdahale etmedi.

### 4.2 SGR-aware line flag + cross-line caveat

`Pipeline` struct'ına alan:

```rust
pub(crate) struct Pipeline {
    sm: crate::ansi::AnsiSm,
    buffer: LineBuffer,
    sequence_scratch: Vec<u8>,    // YENİ: sequence biriktirme buffer'ı
    rules: Arc<ArcSwap<Compiled>>,
    line_has_sgr: bool,            // YENİ: bu satırda SGR completed mu?
}
```

SM `SequenceCompleted(Sgr)` event'i döndüğünde Pipeline:
1. `sequence_scratch`'i (CSI bytes including final `m`) line_buffer'a aktarır.
2. `self.line_has_sgr = true` yapar.
3. Scratch'i temizler.

SM `SequenceCompleted(OtherCsi | EscFinal | EscIntermediateFinal)` event'i döndüğünde Pipeline:
1. Scratch'i line_buffer'a aktarır.
2. `line_has_sgr` değişmez.
3. Scratch'i temizler.

`\n` geldiğinde (Data event'i ile birlikte `feed_byte_with_overflow` `Some(line)` döndüğünde):

```rust
let compiled = self.rules.load_full();
if compiled.respect_existing_colors && self.line_has_sgr {
    out.write_all(&line)?;          // verbatim
} else {
    apply_rules(&line, &self.rules, out)?;
}
self.line_has_sgr = false;          // reset
```

**Cross-line SGR caveat (senior review C2).** Line-level semantik şunu izlemiyor: bir satırda set edilen SGR state (`\e[31m`) terminal'de sonraki satırlara da taşınır. Şu örnekte:

```
\e[31mline 1\n
line 2 still red\n
\e[0m line 3
```

Line 1 → `line_has_sgr=true` → verbatim. Doğru.
Line 2 → `line_has_sgr=false` (bu satırda SGR byte'ı yok) → `apply_rules` çalışır. **Ama terminal hâlâ kırmızı modunda**; tayf bir match wraplerse (örn. `\e[36mfoo\e[0m`), trailing `\e[0m` kırmızı'yı clear eder; "still red" cyan-then-default olur.

Bu kabul edilmiş trade-off:
- Çözmek için **gerçek SGR state machine** (current foreground/background/attrs takip eden) gerekir.
- Line-entry SGR state default değilse skip kararını `is_in_sgr_state` ile vermek lazım.
- v0.3.0 scope'unu büyütüyor; **v0.4 segment-level mode'una bırakılıyor**.

README'de `respect_existing_colors`'ın bu kısıtlamasını dokümante ediyoruz: "best-effort line-level; tek satırda renkli text uygun çalışır, multi-line color blocks (örn. `git log --color=always`) için garanti yok — v0.4'te segment-level mode planlanıyor."

### 4.3 Non-CSI ESC ve EscIntermediate

Williams'a göre `\e=` (single-byte) ve `\e(B` (intermediate + final) farklı path'lerden geçer:

- `\e=`: `Escape + 0x3D` (FINAL range) → `SequenceCompleted::EscFinal`. SM scratch'te 2 byte (`\e`, `=`); Pipeline scratch'i line_buffer'a aktarır.
- `\e(B`: `Escape + 0x28` (INTERMEDIATE) → `EscapeIntermediate`; `EscapeIntermediate + 0x42` (FINAL) → `SequenceCompleted::EscIntermediateFinal`. SM scratch'te 3 byte; Pipeline scratch'i line_buffer'a aktarır.

`\ec` (RIS — Reset to Initial State): tek-byte final. `Escape + 0x63 → SequenceCompleted::EscFinal`. Scratch line_buffer'a aktarılır; çıktıya ESC sequence verbatim geçer.

**Note:** Mevcut v0.2 davranışında `\e=`, `\eM`, `\e7`, `\e8` byte'ları line_buffer'a giriyordu (Ground state'e atılıyordu). v0.3.0 bunları "trigger sequence" olarak işleyip scratch üzerinden line_buffer'a aktarıyor — net davranış aynı (line_buffer'a girer), ama mekanizma artık SM-aware.

## 5. Pipeline.feed mimari — three-path + scratch buffer (Karar 10)

```rust
pub(crate) fn feed<W: Write>(&mut self, chunk: &[u8], out: &mut W) -> std::io::Result<()> {
    for &byte in chunk {
        // Path 1: TUI mode aktif → tüm byte'lar stdout direct.
        if self.sm.tui_mode_active() {
            out.write_all(&[byte])?;
            // SM'i adımla — Mode-exit sequence için.
            // Step event'larını ignore et; flag-flip için tui_mode_active() polled.
            let _ = self.sm.step(byte);
            continue;
        }

        // Path 2: SM step, event'a göre route.
        let event = self.sm.step(byte);
        match event {
            StepEvent::Data => {
                // Invariant: scratch boş (Ground'da).
                debug_assert!(self.sequence_scratch.is_empty());
                if let Some(line) = self.buffer.feed_byte_with_overflow(byte) {
                    self.apply_or_passthrough(&line, out)?;
                }
            }

            StepEvent::SequenceByte => {
                // Sequence ortasındayız; byte scratch'e.
                self.sequence_scratch.push(byte);
            }

            StepEvent::StringPayloadByte => {
                // Path 3: OSC/DCS-passthrough/PM/APC payload byte direct stdout.
                // İlk StringPayloadByte event'i ise scratch'i flush et (introducer
                // `\e]` gibi byte'lar scratch'te birikmişti).
                if !self.sequence_scratch.is_empty() {
                    out.write_all(&self.sequence_scratch)?;
                    self.sequence_scratch.clear();
                }
                out.write_all(&[byte])?;
            }

            StepEvent::SequenceCompleted(kind) => {
                // Final byte'ı scratch'e ekle, sonra kind'a göre destination.
                self.sequence_scratch.push(byte);
                match kind {
                    SequenceKind::TuiToggleOn | SequenceKind::TuiToggleOff => {
                        // Trigger sequence'i stdout'a — terminal görmeli.
                        out.write_all(&self.sequence_scratch)?;
                    }
                    SequenceKind::Sgr => {
                        // SGR scratch'i line_buffer'a — line position preserved.
                        let drained = std::mem::take(&mut self.sequence_scratch);
                        // feed_byte_with_overflow değil, çoklu byte feed.
                        let (lines, overflow) = self.buffer.feed_with_overflow(&drained);
                        if let Some(crate::error::Error::BufferOverflow { cap }) = overflow {
                            crate::log::warn_msg!("line buffer overflowed; cap={cap}");
                        }
                        for line in lines {
                            self.apply_or_passthrough(&line, out)?;
                        }
                        self.line_has_sgr = true;
                    }
                    SequenceKind::OtherCsi
                    | SequenceKind::EscFinal
                    | SequenceKind::EscIntermediateFinal => {
                        // CSI non-SGR veya ESC sequence; scratch line_buffer'a.
                        let drained = std::mem::take(&mut self.sequence_scratch);
                        let (lines, overflow) = self.buffer.feed_with_overflow(&drained);
                        if let Some(crate::error::Error::BufferOverflow { cap }) = overflow {
                            crate::log::warn_msg!("line buffer overflowed; cap={cap}");
                        }
                        for line in lines {
                            self.apply_or_passthrough(&line, out)?;
                        }
                    }
                }
                self.sequence_scratch.clear();
            }
        }
    }
    Ok(())
}

fn apply_or_passthrough<W: Write>(&mut self, line: &[u8], out: &mut W) -> std::io::Result<()> {
    // Karar 11: snapshot at line boundary.
    let compiled = self.rules.load_full();
    if compiled.respect_existing_colors && self.line_has_sgr {
        out.write_all(line)?;
    } else {
        apply_rules(line, &self.rules, out)?;
    }
    self.line_has_sgr = false;
    Ok(())
}

fn flush_partial<W: Write>(&mut self, out: &mut W) -> std::io::Result<()> {
    // tick() ve drain() tarafından kullanılır.
    // Eğer scratch'te kısmi bir sequence varsa — Pipeline shutdown sırasında ortada bir sequence
    // kaldıysa — scratch byte'larını line_buffer'a aktarır (sequence tamamlanmadı,
    // ama byte'lar input'taydı; line'a giriyor olarak ele alıyoruz).
    if !self.sequence_scratch.is_empty() {
        let drained = std::mem::take(&mut self.sequence_scratch);
        let (lines, _) = self.buffer.feed_with_overflow(&drained);
        for line in lines {
            self.apply_or_passthrough(&line, out)?;
        }
    }
    Ok(())
}
```

**Önemli noktalar:**

- **Per-byte step çağrısı** korundu; mevcut "segment break on passthrough toggle" loop'u **kaldırıldı** — yerine Pipeline byte başına step + match. Mevcut testler (özellikle `alt_screen_toggle_forwarded_and_content_bypasses_rules`) bu yapıyla geçer çünkü TuiToggleOn/Off event'leri tetik sequence byte'larını stdout'a flush ediyor.

- **`apply_rules` API mevcut imzasıyla kullanılır** (senior review I1): `apply_rules(line, &self.rules, out)`. Rev2'deki `apply_rules_with` rename'i drop edildi.

- **`feed_byte_with_overflow`** yeni LineBuffer API'sı. Signature ve contract aşağıda §6.

- **`flush_partial`** yeni Pipeline method'u. Semantic: "scratch'te byte varsa line_buffer'a aktar, sonra line_buffer'ı drain et". `tick()` ve `drain()` bunu çağırır.

- **`tui_mode_active`** flag-based. SM state'inden bağımsız.

## 7. Güvenlik (CLAUDE.md §3)

### 7.1 Adversarial input

**Sequence scratch DoS riski (rev3 yeni):**
- `sequence_scratch: Vec<u8>` byte başına büyür; bir sequence (CSI/ESC/EscIntermediate) ~512 byte üst sınırla biriktirir. ECMA-48 sequence'leri pratikte 10 byte civarı.
- **Mitigation:** Scratch'in `Vec::with_capacity(64)` ile başlatılması yeterli. Adversarial input bir sequence içinde 4 GB byte gönderirse: Williams'a göre CSI sequence final byte ile bitmek zorundadır; tamamlanmayan sequence sonsuza dek scratch'i büyütür mü? **Hayır** — `\e` herhangi bir state'te (Anywhere kuralı) sequence'i restart eder, scratch implicitly clear olur (entry action). Buffer 1 MiB cap'ine bir sefer ulaşan sequence için ek bir koruma: spec **AnsiSm dahili scratch cap'i 4 KiB** olarak set eder; aşılırsa SM Ground'a düşer, scratch drop edilir, bir warning loglanır.

**OSC / DCS / PM / APC payload size cap:**
- Hiçbir explicit cap yok; payload byte'ları doğrudan `out.write_all`'a gidiyor.
- Sonsuz OSC durumu: SM `OscString`'de sticky; tick/drain sequence-of-bytes'i kesintiye uğratırsa scratch boştur (string payload scratch'i kullanmaz), line_buffer kısmi line'ı tutar; pre-OSC partial line korunur.

**`accum` overflow:**
- `accum: u32` `saturating_mul`/`saturating_add` ile. `\e[?9999999999h` → `accum = u32::MAX`; `flag_for_mode(u32::MAX) = 0`; ignored. SM `Ground`'a döner.

**DCS embedded ESC trade-off:**
- Williams uyumlu davranış: lone ESC mid-string-sequence → abort + new sequence başlat (vte/tmux ile aynı).
- `xterm-very-old` bazı modlarda preserve ediyor; tayf desteklemiyor. Test §8.1 `dcs_lone_esc_aborts_and_resyncs` ile dokümante.

**OSC 52 truncation:**
- Terminal kendi limit'ini uygular (xterm default 8KB). tayf verbatim geçirir; **amplifier riski yok**.

### 7.2 Memory

- SM: `state: SmState` (1 byte `#[repr(u8)]`), `flags: u32` (4 byte), `accum: u32` (4 byte), `private_mode: bool` (1 byte), `param_idx: u8` (1 byte). Total ~12 byte.
- Pipeline: `sequence_scratch: Vec<u8>` (24 byte struct, 64 byte initial cap'le ~88 byte initial heap), `line_has_sgr: bool` (1 byte).

### 7.3 No new attack surface

- Yeni dep yok → cargo audit/deny aynı.
- Yeni FS path yok.
- Yeni public API yok.
- `Error` enum değişmiyor.

### 7.4 Performans güvenliği

- Mevcut baseline `benches/throughput.rs`'da; ns/byte exact değer release-prep'te ölçülür.
- Yeni SM 14 state, byte başına 1 match expression + 1 scratch push (sequence içindeyse).
- Three-path Pipeline.feed: byte başına 1 step + 1 match. Scratch push/clear amortized O(1).
- Umbrella §4.2 bütçesi: < %20 regression. `BASELINE.md` benchmark sonuçlarıyla güncellenir.
- **Senior review observation:** Mevcut baseline criterion ile **release-prep'ten ÖNCE** ölçülür (v0.3.0 plan dosyasının ilk task'ı), v0.3.0 sonrası tekrar ölçülür, %20 budget enforce edilir.
