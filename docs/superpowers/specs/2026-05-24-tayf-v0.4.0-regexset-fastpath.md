## 1. Motivasyon

`Compiled.set: RegexSet` v0.1'den beri compile ediliyor ([src/rules.rs:550](src/rules.rs#L550)) ama `apply_rules` ([src/pipeline.rs:48](src/pipeline.rs#L48)) onu okumadan `compiled.individuals.iter()` üzerinde lineer geziyor. v0.3 boyunca `#[allow(dead_code)] // reason: reserved for v0.4 RegexSet fast-path` notuyla shape-stable bırakıldı. v0.4.0 bu rezervi nakde çevirir.

Her satır için bugünkü iş 13 bireysel regex'in `find_iter` (10 hot-path) + `captures_iter` (3 captures-styled) çağrısı; çoğu satırda çoğu pattern hiç hit etmez. `RegexSet::matches(line)` aynı line üzerinde **tek bir multi-pattern scan** ile hangi rule indices'in hit edebileceğini O(line_len) sürede üretir; downstream'de sadece o subset için individual `find_iter`/`captures_iter` dispatch edilir. Capture extraction hâlâ individual regex'ten gelir — RegexSet sadece pre-filter.

v0.3.5 BASELINE.md ipv4-heavy 2.4199 ms (v0.3.4'e göre %68.7 daha hızlı, overlap-check refactor'unun ürünü). RegexSet pre-filter buna mixed-syslog'da %40-70, ipv4-heavy'de %30-60 daha düşürür (umbrella §3.2 direction band'leri; gerçek sayı v0.4.0 measurement'ından sonra spec §6'da pin'lenir). Captures-heavy'de delta küçük (%10-20) çünkü her captures rule fixture'da fire ediyor — pre-filter çoğu kez redundant.

**Pipeline-owned scratch** ikinci, ortogonal kazanç: `apply_rules` her satırda 4 Vec allocate ediyor (`accepted_spans`, `runs`, `event_scratch`, `active_scratch`); RegexSet hit indices'i için 5.'si gerek. Allocator pressure satır başına ms-scale değil µs-scale ama miss-heavy fixture'larda set-scan sonrası iş azaldığında allocator katkısı oransal büyür. Bench harness'ın da aynı zero-allocation contract'ı taşıması gerekiyor — yoksa v0.4.0 BASELINE'ı allocator'ı ölçer, scanner'ı değil (umbrella §4.1).

**v0.3.7 carryover** ([rules.rs:923-947](src/rules.rs#L923-L947)): `RuleSource::UserConfig` arm'ı `CaptureGroupIndexZeroForbidden` için hâlâ inline `format!(...)` kullanıyor; `ThemeRuleErrorKind::CaptureGroupIndexZeroForbidden` Display'i ([src/error.rs:94-96](src/error.rs#L94-L96)) tam aynı metni üretiyor. v0.3.7'nin OutOfRange + KeyMalformed delegasyon pattern'ini bu üçüncü arm'a uygula — drift surface'i kapat, source of truth tekleşsin. v0.3.7 final cross-cutting review I-1.

```rust
pub(crate) struct PipelineScratch {
    pub(crate) accepted_spans: Vec<(usize, usize)>,
    pub(crate) runs: Vec<(usize, usize, Style)>,
    pub(crate) event_scratch: Vec<(usize, OpenClose, u32)>,
    pub(crate) active_scratch: Vec<u32>,
    pub(crate) set_match_scratch: Vec<usize>,
}

pub(crate) fn apply_rules<W: Write>(
    line: &[u8],
    compiled_handle: &ArcSwap<Compiled>,
    scratch: &mut PipelineScratch,
    out: &mut W,
) -> std::io::Result<()> {
    let snapshot: Arc<Compiled> = compiled_handle.load_full();
    let compiled: &Compiled = snapshot.as_ref();

    scratch.accepted_spans.clear();
    scratch.runs.clear();
    scratch.event_scratch.clear();
    scratch.active_scratch.clear();
    scratch.set_match_scratch.clear();

    // ... §2.4 RegexSet pre-filter populates scratch.set_match_scratch ...
    // ... selective dispatch reads scratch.set_match_scratch ...
    // ... runs/spans/event/active borrow from scratch.* ...

    scratch.runs.sort_by_key(|&(s, _, _)| s);

    let mut cursor = 0usize;
    for &(start, end, style) in scratch.runs.iter() {
        out.write_all(&line[cursor..start])?;
        let sgr = style.to_sgr();
        if !sgr.is_empty() {
            out.write_all(sgr.as_bytes())?;
        }
        out.write_all(&line[start..end])?;
        out.write_all(Style::reset_sgr().as_bytes())?;
        cursor = end;
    }
    out.write_all(&line[cursor..])?;
    Ok(())
}
```

**Yeni:**

```rust
// Pre-filter: ask RegexSet which rule indices CAN hit; skip the rest.
// `SetMatches::iter()` yields indices in pattern-definition order
// (regex 1.12 stable contract). NO HashSet/BTreeSet here — first-match-
// wins overlap kontract'ı pattern order'a bağlı.
scratch.set_match_scratch.extend(compiled.set.matches(line).iter());

for &i in scratch.set_match_scratch.iter() {
    let re = &compiled.individuals[i];
    if compiled.uses_capture_styling[i] {
        for caps in re.captures_iter(line) {
            let m = caps.get(0).expect("capture 0 is always the full match");
            let (start, end) = (m.start(), m.end());
            if overlaps_accepted(&scratch.accepted_spans, start, end) {
                continue;
            }
            emit_capture_runs(
                &caps,
                start, end,
                compiled.styles[i],
                &compiled.group_styles[i],
                &mut scratch.event_scratch,
                &mut scratch.active_scratch,
                &mut scratch.runs,
            );
            insert_accepted(&mut scratch.accepted_spans, start, end);
        }
    } else {
        for m in re.find_iter(line) {
            let (start, end) = (m.start(), m.end());
            if overlaps_accepted(&scratch.accepted_spans, start, end) {
                continue;
            }
            scratch.runs.push((start, end, compiled.styles[i]));
            insert_accepted(&mut scratch.accepted_spans, start, end);
        }
    }
}
```

**API notu — `RegexSet::matches`:**
- `regex::bytes::RegexSet::matches(haystack: &[u8]) -> SetMatches`. `SetMatches` `IntoIterator<Item = usize>`. `.iter()` consume etmeden yield eder; `scratch.set_match_scratch.extend(...)` Vec'i populate eder.
- `matches_into(&mut Vec)` **yok** (regex crate API'sinde). Umbrella §3.2'nin önceki "matches_into" pseudocode'u rev2'de düzeltildi; bu spec'in pseudocode'u canonical.
- `SetMatches::matched_any() -> bool` empty-check için kullanılabilir ama `extend` zaten boş Vec'le no-op. Erken çıkış optimizasyonu: `if scratch.set_match_scratch.is_empty()` boş emit'e gider; mevcut kod zaten `runs` boşsa `out.write_all(&line[cursor..])?` direkt orjinal byte'ları yazar — pre-filter empty path zero-cost düşer.

**Cross-rule ordering invariant:** `SetMatches::iter()` pattern-definition order'ında index yield ediyor (regex stable doc). `compiled.individuals` ve `compiled.styles` aynı order'da inşa ediliyor ([src/rules.rs:841](src/rules.rs#L841) civarı). First-match-wins overlap kontratı ([src/pipeline.rs:39](src/pipeline.rs#L39) doc-comment) korunuyor: pattern N'in `(start, end)` match'i pattern 1'in daha geç match'ini accepted_spans üzerinden bloke edebilir, ama bu zaten mevcut behavior. **HashSet/BTreeSet/sort by anything-other-than-pattern-index YASAK** — implementer notu.

**Empty rule set guard:** `Compiled::empty()` ([src/rules.rs:585](src/rules.rs#L585)) `RegexSet::empty()` döner. `RegexSet::empty().matches(line)` boş `SetMatches`. Bypass mode path zero-iteration; davranış değişmez.

```rust
#[doc(hidden)]
pub mod __bench__ {
    use std::io::Write;

    pub struct CompiledRules(std::sync::Arc<arc_swap::ArcSwap<crate::rules::Compiled>>);

    /// Bench-only scratch container. Wraps `crate::pipeline::PipelineScratch`
    /// so the `benches/` crate can hoist scratch allocation outside `b.iter`
    /// loops, matching the production Pipeline's per-line zero-allocation
    /// contract. Not part of the public API.
    pub struct BenchScratch(crate::pipeline::PipelineScratch);

    impl Default for BenchScratch {
        fn default() -> Self {
            Self(crate::pipeline::PipelineScratch::default())
        }
    }

    pub fn load_builtin_rules() -> crate::Result<CompiledRules> {
        crate::rules::Compiled::load_builtins()
            .map(|c| CompiledRules(std::sync::Arc::new(arc_swap::ArcSwap::from_pointee(c))))
    }

    /// Drive the rule scanner against `line`. Scratch is caller-owned and
    /// MUST be hoisted outside any `b.iter` loop so the measurement reflects
    /// the scanner, not the allocator.
    pub fn apply_rules<W: Write>(
        line: &[u8],
        rules: &CompiledRules,
        scratch: &mut BenchScratch,
        out: &mut W,
    ) -> std::io::Result<()> {
        crate::pipeline::apply_rules(line, &rules.0, &mut scratch.0, out)
    }
}
```

   ```rust
   fn pipeline_scratch_is_reused_across_apply_rules_calls() {
       let rules = test_rules_arcswap();  // helper from existing tests
       let mut scratch = PipelineScratch::default();
       let mut out: Vec<u8> = Vec::new();

           scratch.runs.capacity(),
           scratch.event_scratch.capacity(),
           scratch.active_scratch.capacity(),
           scratch.set_match_scratch.capacity(),
   ```
