### 3.2 Public API Surface (sadece `lib.rs` aracılığıyla)

```rust
// lib.rs
pub use cli::Args;
pub use error::Error;

pub struct Tayf;
impl Tayf {
    /// Top-level entry. Owns the session, the TTY guard, signal installation,
    /// and joins the runtime threads.
    pub fn run(args: Args) -> Result<std::process::ExitCode, Error>;
}
```

Diğer her şey `pub(crate)`. Public surface bilinçli olarak küçük: tayf bir kütüphane değil, integration test'lerin lib API üzerinden çalışabilmesi için bu kadarı yeterli.

### 3.3 `PtySession::into_parts` Dekompozisyonu

`Session` overloaded olmasın diye: `PtySession::into_parts(self) -> (Reader, Writer, Resizer, ChildHandle)`.

- `Reader` — output thread'in tek owner'ı, master read tarafını owned olarak tutar.
- `Writer` — input thread'in owner'ı, master write tarafını owned olarak tutar. Ayrı bir fd (dup'lanmış) olduğu için `shutdown()` Reader tarafını etkilemez; sadece input thread'i sonlandırmak için kullanılır.
- `Resizer` — signal thread'in owner'ı; içinde master fd'nin ayrı bir dup'u var, `ioctl(TIOCSWINSZ)` çağırır. Thread-safe; signal thread'inden güvenle çağrılabilir.
- `ChildHandle` — main thread'in owner'ı; `wait()`, `exit_code()`, ve child PGID accessor'ı sağlar.

Hepsi `'static` ownership ile move edilir; `Arc`/`Mutex` yok.

Bu split, herhangi bir `Arc<Mutex<PtySession>>` ihtiyacını ortadan kaldırır.

### 3.4 Shutdown Protokolü (v0.1'de en kritik tasarım kararı)

Numaralı sıra:

1. **Child exit eder** (normal exit, signal, ne sebeple olursa).
2. **Output thread** master.read() çağrısı:
   - Linux'ta `EIO` döner.
   - macOS'ta `Ok(0)` döner.
   - Her ikisi "child kapandı, drain et" olarak yorumlanır.
3. Output thread `line_buffer.flush_partial()` çağırır (regex uygulanmadan, partial line as-is); stdout'a yazar.
4. Output thread temiz exit eder. Main thread'e bunun bilgisi yok (heuristic gerek yok).
5. **Main thread** `child.wait()` üzerinden child reap'i tetikler ve exit kodunu alır.
6. Main thread `master_writer.shutdown()` çağırır — master write fd kapanır.
7. **Input thread** bir sonraki `master.write_all(...)` çağrısında `EPIPE` alır. Loop'tan çıkar.
   - **v0.1 limit:** input thread şu anda `stdin.read()`'te bloke ise, kullanıcı bir karakter yazana kadar bekler. Bu pratikte sorun değil çünkü:
     - Child exit'te terminal zaten kullanıcıya geri döner.
     - Main thread input thread'in `JoinHandle`'ını `join` etmek yerine `drop` eder; thread `main` return ettiğinde process exit ile birlikte OS tarafından sonlandırılır (Rust thread'leri default'ta `join`'lenmediği takdirde process exit'inde sonlanır).
   - v0.2+ planı: `nix::poll::poll` ile stdin + self-pipe (eventfd ya da pipe pair) wakeup mekanizması; ana thread shutdown sinyali bu pipe'a yazar, poll uyanır, input thread temiz exit eder.
8. **Signal thread** `SignalGuard::drop` üzerinden `signal_hook::Signals::halt()` ile durdurulur ve `join`'lenir.
9. **`TtyGuard::drop`** termios'u restore eder.
10. `main` `ExitCode`'u döner.

Exit code mapping:
- Child exit kodu varsa, onu kullan.
- CLI parse hatası: `64` (`EX_USAGE`).
- PTY/signal/internal: `71` (`EX_OSERR`).
- Logic error (unreachable!): `70` (`EX_SOFTWARE`).
- Crash: `134` (SIGABRT) veya signal+128 — `main` dönmeden gelir, kernel set eder.

### 3.5 TUI Mode Parser (State Machine)

`pipeline.rs` içinde 5-state machine — **DEC private mode set/reset** sequence'larını (CSI ? Pm h / l) algılar. Tek bir `bool` yerine, hangi TUI mod'unun aktif olduğunu tutan bir **bitmask** vardır; herhangi bir flag set olduğu sürece pipeline passthrough'tadır.

```
GROUND   ──ESC (0x1b)──► ESC_SEEN   [hold ESC]
ESC_SEEN ──'['─────────► CSI         [hold "ESC ["]
ESC_SEEN ──other───────► GROUND      [emit held + char]
CSI      ──'?'─────────► QUESTION    [hold "ESC [ ?"]
CSI      ──other───────► GROUND      [emit held + char]
QUESTION ──digit───────► DIGITS      [accumulate digit]
QUESTION ──other───────► GROUND      [emit held + char]
DIGITS   ──digit───────► DIGITS      [accumulate digit]
DIGITS   ──'h'─────────► GROUND      [if num ∈ TUI_TRIGGERS → set flag(num); emit held + 'h']
DIGITS   ──'l'─────────► GROUND      [if num ∈ TUI_TRIGGERS → clear flag(num); emit held + 'l']
DIGITS   ──other───────► GROUND      [emit held + char]
```

**TUI_TRIGGERS** ve bitmask flag'leri:

| Num | Mode | Flag bit | Açıklama |
|---|---|---|---|
| 47 | Legacy alt-screen | `ALT_SCREEN` | Eski xterm varyantı |
| 1047 | Legacy alt-screen (with clear) | `ALT_SCREEN` | Aynı bit'i set/clear eder |
| 1049 | Modern alt-screen | `ALT_SCREEN` | xterm save+switch (yaygın) |
| 2004 | Bracketed paste | `BRACKETED_PASTE` | Yapıştırma içeriği marker'la sarılır; ortasına byte eklemek paste'i bozar |
| 1000 | X11 mouse (button) | `MOUSE` | Mouse tracking aktif |
| 1002 | Button-event mouse | `MOUSE` | Aynı bit |
| 1003 | Any-event mouse | `MOUSE` | Aynı bit |
| 1006 | SGR extended mouse | `MOUSE` | Aynı bit |

**Passthrough koşulu:** `flags != 0`. Üç bayrak da clear edilince pipeline normale döner.

**Neden bu kombinasyon:** Modern TUI uygulamaları (Claude Code, neovim, htop, lazygit, k9s, gum, bubbletea-tabanlı araçlar, vb.) bu mod'lardan en az birini aktive eder. Üçünü birden takip etmek "false negative" (TUI'yi kaçırma) riskini pratikte sıfıra indirir. "False positive" (renkleme fırsatını kaçırma) bedeli minimum — kullanıcı bir TUI'den çıktığında pipeline tekrar devreye girer.

**Önemli incelikler:**
- "Hold" = state machine matching halinde olan byte'ları biriktirir; transition'da ya tüketir ya da olduğu gibi emit eder. State machine **byte yutmaz**; sadece TUI mode flag'lerini yönetir.
- State chunk'lar arasında korunur. Bir `\x1b[?1049h` veya `\x1b[?2004h` sequence'i iki ayrı `read()` chunk'ı arasında bölünebilir — state machine bunu doğal olarak handle eder.
- Passthrough modda da state machine çalışmaya devam eder ki kapanış sequence'ı (örn. `\x1b[?2004l`) görülebilsin.
- Aynı flag bit'i birden fazla num tarafından paylaşılabilir (örn. 1000/1002/1003/1006 hepsi `MOUSE`). Bit kümülatif değil — `47h` veya `1049h` set ederse bit set olur; herhangi bir varyantın `l`'si bit'i clear eder. Bu kabul edilebilir bir yaklaşımdır çünkü uygulamalar aynı session içinde varyant değiştirmez.

### 3.7 Style → SGR Audit Gate

`Style::to_sgr(&self) -> String` sadece `\x1b[…m` ve `\x1b[0m` üretir. Test:

```rust
#[test]
fn to_sgr_only_emits_sgr_sequences() {
    let re = regex::Regex::new(r"^\x1b\[[0-9;]+m$|^\x1b\[0m$").unwrap();
    for style in all_test_styles() {
        let sgr = style.to_sgr();
        assert!(re.is_match(&sgr), "style {style:?} emitted non-SGR: {sgr:?}");
    }
}
```

Bu, escape injection saldırı yüzeyini bir fonksiyona daraltır.

Pattern derleme algoritması (`rules::build_filename_pattern`):
1. Listeyi uzunluk-azalan sırala (regex alternation longest-first eşleştirsin, böylece `tar.gz` `gz`'den önce match etsin).
2. Her uzantıyı `regex::escape` ile escape et (içinde `.` veya başka regex metachar varsa).
3. Alternation ile birleştir: `(?:tar\.gz|tar\.bz2|...|json)`.
4. Çevreleyici pattern: `\b[\w.-]+\.(?:LIST)\b`.

Sonuç regex'i `regex` crate'i tarafından otomatik DFA-leme yapıldığı için `n` alternative için O(input) lineer kalır. ReDoS riski yok.

**Renk:** `Style { fg: Some(Color::BrightCyan), ..DEFAULT }` — MAC'in `Cyan`'ından ayrı, dikkat çekici ama bağırmayan.

**Çakışma örnekleri:**
- `192.168.1.1.log` → IPv4 önce match eder (ilk-eşleşme-kazanır). Filename bütün eşleşmesi düşer. Kabul.
- `/var/log/syslog.gz` → `syslog.gz` matches. Yol prefix'i renksiz kalır. Kabul.
- `cargo.lock` → `cargo.lock` matches. Bekleneni karşılar.
- `package-lock.json` → matches. `[\w.-]+` `-`'yi kabul eder.

## 4. Hata Modeli

Tek `tayf::Error` enum, `thiserror` ile:

```rust
#[derive(Debug, thiserror::Error)]
pub enum Error {
    #[error("could not determine shell: {0}")]
    ShellDiscovery(String),
    #[error("PTY operation failed: {0}")]
    Pty(#[from] std::io::Error),
    #[error("terminal control failed: {0}")]
    Tty(#[from] nix::errno::Errno),
    #[error("regex compilation failed: {0}")]
    RegexCompile(#[from] regex::Error),
    #[error("signal installation failed: {0}")]
    Signal(std::io::Error),
    #[error("line buffer exceeded {cap} bytes; flushing as-is")]
    BufferOverflow { cap: usize },  // log only, not fatal
}
```

`Error` üzerinden çıkan her `Display` cümlesi: (a) ne başarısız, (b) neden, (c) kullanıcı ne yapmalı. `main.rs` bunları stderr'e yazar, exit code'a çevirir.

Built-in pattern'lerin compile etmemesi imkansız (test ile garanti edilir). `rules::load_builtins()` içinde:

```rust
.unwrap_or_else(|e| {
    unreachable!("builtin pattern must compile: {e}")
})
```

CLAUDE.md §2 "proven-unreachable paths" izniyle.

## 6. Güvenlik Sınırları

CLAUDE.md §3 maddelerini v0.1 implementasyonuna bağlayan tablo:

| Tehdit | v0.1'de nasıl kapatılır |
|---|---|
| **ReDoS** | Built-in 7 pattern manuel olarak linear-time tasarlandı. Backtracking yok. `proptest` ile adversarial input testi v0.2'de kullanıcı pattern'leri eklendiğinde. |
| **Memory exhaustion** | `line_buffer` 64KB hard cap, aşılırsa partial flush + reset. `BufferOverflow` log atılır. |
| **Escape injection** | `Style::to_sgr` audit gate ile SGR dışında byte emit edilemez. Pattern eşleşmesinin **içine** zaten ANSI varsa, v0.1'de "ilk match kazanır" semantiği bunu naive korur ama tam koruma v0.3 (master §6.2). v0.1 limit. |
| **Terminal corruption** | `TtyGuard` Drop + `std::panic::set_hook` fallback. Exit yolları tek noktadan (`main.rs` → `ExitCode`) — `std::process::exit` kullanılmaz; dep'lerde `process::exit` çağrısı `cargo geiger` ile audit. |
| **SIGKILL / abort** | In-process saving yok. README'de "`tayf` aniden öldürülürse `reset` çalıştır" uyarısı. |
| **Credential/PII leak** | tracing default off; `TAYF_LOG` set edilmeden hiçbir log yazılmaz. Asla stdout'a debug yazılmaz. |
| **Config file traversal** | v0.1'de config dosyası yok. v0.2'de `canonicalize` + `~/.config/tayf/` whitelist. |
| **Shell injection** | `portable-pty` `CommandBuilder` `argv`-style. `sh -c` yok. `--shell` flag value'su `argv[0]` olarak gider, string interpolation yok. |
| **Signal forwarding** | SIGINT/SIGTERM child process group'a (`killpg(pgid, sig)`) forward. PID'e değil. |
| **Dependency surface** | v0.1 direct deps: `portable-pty`, `regex`, `nix`, `clap`, `thiserror`, `signal-hook`, `tracing`, `tracing-subscriber`. Her birinin son commit tarihi, license, `unsafe` line sayısı README'ye not edilir. `cargo audit` lokal'de çalıştırılır. |
