### 3.2 Builtin overlay route — synth-UserRule push

#### Problem (v0.6 limitation)

`compile_pending` (kod: `src/config_tui/compile_pending.rs:107-118`) sadece `RuleId::UserConfig(name)` entry'leri için overlay uygular. `RuleId::Builtin`, `RuleId::Embedded`, `RuleId::DiskProfile` silently skipped. ColorPicker bir builtin rule'a bind edilince edits.rules'a yazılır, toast "color bound" der, ama compile_pending overlay'i no-op olduğu için preview değişmez (events.rs:473-481 inline limitation comment).

#### Çözüm

`compile_pending` içinde overlay loop, `RuleId::UserConfig` özel-case'inden **çıkarılıp**, dört variant için de aynı stratejiyi uygular:

1. `RuleId::UserConfig(name)` → mevcut path: `user_rules` içinde name'le bul, in-place edit.
2. `RuleId::Builtin(name)` | `RuleId::Embedded { rule, .. }` | `RuleId::DiskProfile { rule, .. }` →
   `user_rules` array'inin **sonuna** synth bir `UserRule { name: <rule_name>, pattern, style }` push edilir.

`compile_from_config` (`src/rules.rs`) → `apply_user_rules_with_source` (line 783-799) name match'inde in-place mutate yapar (REPLACE styles_override semantics, Rev2 Karar 27). Yani disk config'te kullanıcı bir built-in adıyla `[[rules]]` entry'si yazmış gibi davranır — kanonik mekanizma.

**Edge case'ler:**
- Aynı builtin için hem `RuleId::Builtin(name)` overlay hem de UserConfig'de `[[rules]]` entry'si varsa: snapshot'taki user_rules zaten override'ı içerir; sonra Builtin synth UserRule ondan SONRA push edilir → son yazan kazanır (TUI edit > disk config). v0.6 PendingEdits semantic'iyle tutarlı.
- `Embedded` ve `DiskProfile` variant'larının `rule` alanı zaten o profile'ın append_rules girişinin adıdır. Aynı şekilde synth UserRule push edilir; rules.rs'in profile-then-user-config layer ordering'i (line 762-799) user-config'i append_rules üstüne yazar → simetri korunur.
- `edits.deleted` zaten `RuleId::UserConfig` için filter ediliyor (line 123); diğer variantlar için **DEFER v0.7**. v0.6.1 d/Delete keystroke sadece UserConfig rules için aktif (Patterns tab'de selected rule UserConfig variant'ındaysa enable; aksi halde toast "built-in/profile rules cannot be deleted").

#### Pattern overlay symmetry

`RuleEdit.pattern` field'ı `compile_pending` UserConfig path'inde (line 110) zaten kullanılıyor. Builtin/Embedded/DiskProfile için synth UserRule'a aynı `pattern: Some(rule_edit.pattern.unwrap_or(<original>))` semantic'i: orijinal pattern'i de snapshot'tan resolve etmek gerekiyor (BuiltinRule.pattern alanı). Bunun için `apply_pending_compiled` veya `snapshot.parsed.rules` yeterli **DEĞİL** — built-in patterns sadece `Compiled.individuals[i].as_str()` üzerinden veya `rules::builtin_rules()` static catalog'undan alınır.

**Karar:** `compile_pending` Builtin/Embedded/DiskProfile için **pattern overlay'in `Some(...)` olduğu durumlarda** synth UserRule'a pattern overlay'i yazar; **pattern overlay yoksa** (`RuleEdit.pattern: None`) synth UserRule'a `pattern: None` yazar → `apply_user_rules_with_source` source-of-truth'a (snapshot'taki built-in/profile rule'a) dokunmaz, **sadece style override eder**. Bu rules.rs'in mevcut "absent field = no override" semantic'ine uyar.

#### events.rs:473-481 limitation comment

Bu comment Group A'nın son adımında silinir. Yerine `apply_pending_and_recompile` doc-comment kısa bir paragraf alır: "Builtin / Embedded / DiskProfile rules apply via synth-UserRule push in `compile_pending`; see §3.2 of v0.6.1 design".

### 4.1 `compile_pending` Builtin overlay (Group A)

`src/config_tui/compile_pending.rs:100-118` (mevcut UserConfig-only loop) yerine:

```rust
let mut user_rules = snapshot.parsed.rules.clone();

for (rule_id, rule_edit) in &edits.rules {
    match rule_id {
        RuleId::UserConfig(name) => {
            if let Some(existing) = user_rules.iter_mut().find(|r| &r.name == name) {
                if let Some(new_pat) = &rule_edit.pattern {
                    existing.pattern = Some(new_pat.clone());
                }
                if let Some(new_style) = rule_edit.styles.get(&StyleKey::Default) {
                    apply_new_style_to_user_rule(existing, new_style);
                }
            }
        }
        RuleId::Builtin(name)
        | RuleId::Embedded { rule: name, .. }
        | RuleId::DiskProfile { rule: name, .. } => {
            // Synth UserRule pushed; apply_user_rules_with_source
            // (rules.rs:783-799) finds the matching name and applies
            // REPLACE styles_override semantics (Rev2 Karar 27).
            let mut synth = crate::config::UserRule {
                name: name.to_string(),
                pattern: rule_edit.pattern.clone(),
                style: rule_edit
                    .styles
                    .get(&StyleKey::Default)
                    .map(new_style_to_user_style),
                enabled: true,
                styles: None,
                priority: None,
            };
            user_rules.push(synth);
        }
    }
}
```

(`Embedded` ve `DiskProfile` variant pattern match — şu anki `edit.rs` `RuleId` enum'unun gerçek field adlarını mirror'lar; implementer impl phase'inde sözdizimini doğrulamalı.)
