# tayf v0.4.1 — Bench-CI + Regression Detection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.4.1 — the final sub-version of the v0.4 minor. Wire up a `bench-regression` CI job that runs `cargo bench --bench throughput` on every push and PR (ubuntu-latest + macos-latest matrix), compares each bench's mean time against a git-canonical baseline JSON committed at `benches/baselines/<version>/<os>.json`, and emits workflow annotations on threshold breach (apply_rules/* > +20%; passthrough/write_all > +30%, accounting for sub-µs jitter). Plus the C-1 carryover from v0.3.7 → v0.4.0: two bare `unreachable!()` arms in `src/rules.rs::resolve_group_styles_for_rule` grow reason strings per CLAUDE.md §2. Plus the new release-ceremony step that writes per-OS baseline JSON at every tag push, so the v0.4.1 release is also the first canonical CI baseline.

**Architecture:** Three orthogonal pieces. (1) `src/rules.rs`'s two bare `unreachable!()` arms become `unreachable!("...constructor-guaranteed unreachable; reach only through UserConfig/Theme paths handled above")`. Zero behavior change, message-only. (2) `.github/workflows/ci.yml` gains a `bench-regression` matrix job (ubuntu+macos). The job runs benches, validates `target/criterion/<bench>/new/estimates.json` shape, compares `mean.point_estimate` against canonical baselines via `jq` + single-pass `awk` delta computation, and emits annotations. `[bench-ci-strict]` PR label opts in to error severity (workflow fails). (3) `benches/baselines/v0.4.0/{ubuntu,macos}-latest.json` and `benches/baselines/latest/{ubuntu,macos}-latest.json` ship as canonical baselines, populated via a bootstrap commit-back step that downloads criterion artifacts from the first CI run and extracts mean+std_dev via jq.

**Tech Stack:** Rust 2021, no new Cargo deps. GHA workflow uses jq (preinstalled on both runners) + POSIX awk (eliminates `bc` per senior review I-2). `actions/upload-artifact@v4` for the criterion tree (14-day retention) so the bootstrap commit-back is a one-script reviewer task, no manual ms/µs → ns conversion.

- [ ] **Step 3: Append `bench-regression` job to `.github/workflows/ci.yml`**

Open `.github/workflows/ci.yml`. After the existing `audit` job (around line 48), append the following at the end of the `jobs:` mapping. **The indentation matters — `bench-regression:` is at the same level as `test:` and `audit:` (two spaces).**

```yaml

  bench-regression:
    name: Bench regression (${{ matrix.os }})
    runs-on: ${{ matrix.os }}
    needs: test  # only run if test passes (don't bench broken code)
    strategy:
      fail-fast: false  # ubuntu + macos independent
      matrix:
        os: [ubuntu-latest, macos-latest]
    steps:
      - uses: actions/checkout@v5
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2

      # jq is preinstalled on ubuntu-latest (1.7) and macos-latest (1.8.1)
      # per actions/runner-images. No install step needed.

      - name: Run benches
        run: cargo bench --bench throughput

      - name: Smoke test estimates.json + baseline JSON shape
        shell: bash
        run: |
          set -euo pipefail
          for bench in apply_rules/ipv4-heavy apply_rules/mixed-syslog apply_rules/captures-heavy passthrough/write_all; do
            file="target/criterion/${bench}/new/estimates.json"
            test -f "$file" || { echo "::error::missing $file"; exit 1; }
            jq -e '.mean.point_estimate' "$file" > /dev/null || {
              echo "::error::unexpected schema in $file (mean.point_estimate missing)"; exit 1
            }
          done

          baseline="benches/baselines/latest/${{ matrix.os }}.json"
          if [[ -f "$baseline" ]]; then
            for bench in apply_rules/ipv4-heavy apply_rules/mixed-syslog apply_rules/captures-heavy passthrough/write_all; do
              jq -e --arg b "$bench" '.benches[$b].mean_ns' "$baseline" > /dev/null || {
                echo "::error::baseline $baseline missing benches[\"$bench\"].mean_ns"; exit 1
              }
            done
          fi

      - name: Compare against baseline
        id: compare
        shell: bash
        env:
          LC_NUMERIC: C
          STRICT_MODE: ${{ contains(github.event.pull_request.labels.*.name, 'bench-ci-strict') }}
        run: |
          set -euo pipefail
          baseline="benches/baselines/latest/${{ matrix.os }}.json"
          if [[ ! -f "$baseline" ]]; then
            echo "::warning::no baseline at $baseline; skipping comparison"
            exit 0
          fi

          breach_found=0
          for bench in apply_rules/ipv4-heavy apply_rules/mixed-syslog apply_rules/captures-heavy passthrough/write_all; do
            new_mean=$(jq -e '.mean.point_estimate' "target/criterion/${bench}/new/estimates.json") || {
              echo "::error::failed to read mean.point_estimate from ${bench}'s estimates.json"; exit 1
            }
            base_mean=$(jq -e --arg b "$bench" '.benches[$b].mean_ns' "$baseline") || {
              echo "::error::baseline $baseline missing benches[\"$bench\"].mean_ns"; exit 1
            }

            if [[ "$base_mean" == "0" ]]; then
              echo "::warning::baseline for $bench is placeholder (mean_ns=0); skipping comparison"
              continue
            fi

            if [[ "$bench" == "passthrough/write_all" ]]; then
              threshold_pct=30
            else
              threshold_pct=20
            fi

            read -r delta_pct breach < <(awk -v new="$new_mean" -v base="$base_mean" -v t="$threshold_pct" '
              BEGIN {
                d = (new - base) / base * 100
                printf "%.2f %d\n", d, (d > t) ? 1 : 0
              }')

            if [[ "$breach" == "1" ]]; then
              breach_found=1
              if [[ "$STRICT_MODE" == "true" ]]; then
                echo "::error::${bench} regressed +${delta_pct}% vs baseline (threshold: ${threshold_pct}%)"
              else
                echo "::warning::${bench} regressed +${delta_pct}% vs baseline (threshold: ${threshold_pct}%) — strict mode opt-in via [bench-ci-strict] label"
              fi
            fi
          done

          if [[ "$breach_found" == "1" && "$STRICT_MODE" == "true" ]]; then
            exit 1
          fi

      - name: Upload criterion artifacts (for baseline extraction)
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: criterion-${{ matrix.os }}
          path: target/criterion/
          retention-days: 14
```

- [ ] **Step 3: Extract real baseline numbers via jq script**

For each OS, build the baseline JSON from the criterion artifacts. The COMMIT_SHA and DATE arguments are read from git/system; the schema fields are spec §2.2 mandated.

```bash
COMMIT_SHA="c0eb945"  # v0.4.0 tag commit
DATE="2026-05-25"      # v0.4.0 release date

for os in ubuntu macos; do
  src="/tmp/criterion-bootstrap/${os}-latest"
  out="benches/baselines/v0.4.0/${os}-latest.json"

  jq -n \
    --arg ver "v0.4.0" \
    --arg tag "v0.4.0" \
    --arg commit "$COMMIT_SHA" \
    --arg date "$DATE" \
    --arg host "GitHub Actions ${os}-latest" \
    --arg runner_class "${os}-latest" \
    --argjson ipv4_mean   "$(jq '.mean.point_estimate'    "$src/apply_rules/ipv4-heavy/new/estimates.json")" \
    --argjson ipv4_sd     "$(jq '.std_dev.point_estimate' "$src/apply_rules/ipv4-heavy/new/estimates.json")" \
    --argjson syslog_mean "$(jq '.mean.point_estimate'    "$src/apply_rules/mixed-syslog/new/estimates.json")" \
    --argjson syslog_sd   "$(jq '.std_dev.point_estimate' "$src/apply_rules/mixed-syslog/new/estimates.json")" \
    --argjson cap_mean    "$(jq '.mean.point_estimate'    "$src/apply_rules/captures-heavy/new/estimates.json")" \
    --argjson cap_sd      "$(jq '.std_dev.point_estimate' "$src/apply_rules/captures-heavy/new/estimates.json")" \
    --argjson pt_mean     "$(jq '.mean.point_estimate'    "$src/passthrough/write_all/new/estimates.json")" \
    --argjson pt_sd       "$(jq '.std_dev.point_estimate' "$src/passthrough/write_all/new/estimates.json")" \
    '{
      version: $ver, tag: $tag, commit: $commit, date: $date, host: $host,
      runner_class: $runner_class, rustc: "1.95.0", criterion_version: "0.8",
```
