# tayf v0.10.0 — Public Flip & Distribution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make tayf public-release-ready: harden CI against fork-PR RCE, turn the dry-run release pipeline live (signed binaries + crates.io + Homebrew), add the `TAYF_SESSION` always-on marker, clean the public file surface, and ship public docs — all on a feature branch, leaving the irreversible OUTWARD steps (public flip, tag, publish) to the gated ceremony.

**Architecture:** Almost zero runtime-logic change. One `src/` behavior touch (`pty.rs` env marker) + 11 doc-comment repoints + 1 test one-liner. The bulk is GitHub Actions YAML, docs, lockfile regeneration, and git removals. Baseline is v0.9.1 (Neon palette) at `main`.

**Tech Stack:** Rust 1.88 (MSRV), portable-pty 0.9, GitHub Actions, cargo (publish/deny/audit/cyclonedx/fuzz), Sigstore/`gh attestation`, Homebrew.

**Source of truth:** the spec `docs/superpowers/specs/2026-05-31-tayf-v0.10.0-public-flip.md`, especially **§17** (rev1 review folds) which supersedes earlier sections where they conflict. Read §17 before each task.

**Scope note:** Tasks 1–13 are the branch impl (this plan). The OUTWARD release ceremony (§11: public flip → push → tag → live release → crates.io → brew) and the repo-settings checklist (§17.5 G items) are executed INTERACTIVELY with per-step user approval AFTER this plan completes and CI is green — they are NOT plan tasks.

**Conventions (every task):** English in code/comments/commits; `cargo fmt && cargo clippy --all-targets -- -D warnings && cargo test` is the pre-commit gate; small atomic commits, imperative title <70 chars, `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>` footer; measured numbers transcribed tee→Read→verify ([[feedback-transcribe-measured-numbers]]).

    assert!(

    );
