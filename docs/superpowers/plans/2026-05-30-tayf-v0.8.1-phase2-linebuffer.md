# tayf v0.8.1 — Phase 2 (line_buffer non-gated optimization) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Remove the O(L²) per-byte newline rescan in `LineBuffer::feed_byte_with_overflow` (the per-byte hot path) by replacing the whole-buffer `memchr` scan with an O(1) `push` + `byte == b'\n'` check, then measure the gain against the v0.8.1 e2e/micro-bench baseline. Behavior must stay byte-identical.

**Architecture:** `feed_byte_with_overflow` currently delegates to the general `feed_with_overflow(&[byte])`, which `extend_from_slice`s one byte and then `memchr`-scans the ENTIRE accumulated buffer from the start — O(L²) within a line. Invariant: a completed line always drains `inner`, and the multi-byte path (`feed_with_overflow`, used by SGR/sequence drains) also drains every `\n` before returning — so between calls `inner` never contains a `\n`. Therefore after appending one byte, the only possible newline is that byte itself. The fast path: `push(byte)`; on overflow flush; else if `byte == b'\n'` flush the line; else hold. The general `feed_with_overflow` is UNCHANGED (still used by sequence drains, the `feed()` wrapper, and tests).

**Tech Stack:** Rust 2021. Single file: `src/line_buffer.rs`. **Not DOKUNULMAZ** (`pipeline.rs`/`runtime.rs`/`pty.rs` untouched) → no security gate. No new deps.

**Reference:** spec `docs/superpowers/specs/2026-05-30-tayf-v0.8.1-profile-first-optimization.md` (Phase 2, hypothesis H1, narrowed by the Phase-1 clock spike: the per-byte `Instant::now()` was measured negligible (~1%), so this fix targets only the O(L²) rescan + per-byte delegation overhead, NOT the clock).

### Current code (for reference — the body to replace)

```rust
    pub(crate) fn feed_byte_with_overflow(&mut self, byte: u8) -> Option<Vec<u8>> {
        let (mut lines, overflow) = self.feed_with_overflow(&[byte]);
        if let Some(Error::BufferOverflow { cap }) = overflow {
            crate::log::warn_msg!("line buffer overflowed; cap={cap}");
        }
        let mut line = lines.pop()?;
        if line.last() == Some(&b'\n') {
            line.pop();
        }
        Some(line)
    }
```

```rust
    fn feed_byte_overflow_flushes_without_newline_strip() {
        // Per-byte path: feeding MAX_BUFFER_BYTES+1 non-newline bytes must
        // flush the accumulated buffer (no trailing newline to strip).
        let mut buf = LineBuffer::new();
        let mut flushed: Option<Vec<u8>> = None;
        for _ in 0..=MAX_BUFFER_BYTES {
            if let Some(line) = buf.feed_byte_with_overflow(b'x') {
                flushed = Some(line);
                break;
            }
        }
        let line = flushed.expect("overflow must flush a line via the per-byte path");
        assert_eq!(line.len(), MAX_BUFFER_BYTES + 1, "overflow flush returns all accumulated bytes");
        assert!(line.iter().all(|&b| b == b'x'), "no newline present, nothing stripped");
    }

    #[test]
    fn feed_byte_resumes_after_newline_flush() {
        // After a newline flush, the buffer must be empty and accept a fresh line.
        let mut buf = LineBuffer::new();
        for &b in b"first" {
            assert!(buf.feed_byte_with_overflow(b).is_none());
        }
        assert_eq!(buf.feed_byte_with_overflow(b'\n'), Some(b"first".to_vec()));
        for &b in b"second" {
            assert!(buf.feed_byte_with_overflow(b).is_none());
        }
        assert_eq!(buf.feed_byte_with_overflow(b'\n'), Some(b"second".to_vec()));
    }
```

- [ ] **Step 3: Replace `feed_byte_with_overflow` with the O(1) fast path**

```rust
    pub(crate) fn feed_byte_with_overflow(&mut self, byte: u8) -> Option<Vec<u8>> {
        // Per-byte hot path. The general `feed_with_overflow` rescans the whole
        // accumulated buffer for newlines on every call (O(L²) across a line);
        // here we exploit the invariant that `inner` never holds a `\n` between
        // calls (every completed line drains it, and the multi-byte path drains
        // all newlines before returning). So after pushing one byte, the only
        // possible newline is that byte. Push + a single comparison = O(1).
        self.last_write = Instant::now();
        self.inner.push(byte);

        let overflow = self.inner.len() > MAX_BUFFER_BYTES;
        if overflow {
            let cap = MAX_BUFFER_BYTES;
            crate::log::warn_msg!("line buffer overflowed; cap={cap}");
        } else if byte != b'\n' {
            return None;
        }

        // Either the cap was exceeded, or this byte completed a line: flush
        // `inner` as the line and reset. Strip a trailing `\n` so byte consumers
        // get a clean payload (matches the prior contract; overflow flushes that
        // do not end in `\n` are returned verbatim).
        let mut line = std::mem::take(&mut self.inner);
        self.inner = Vec::with_capacity(4096);
        if line.last() == Some(&b'\n') {
            line.pop();
        }
        Some(line)
    }
```
