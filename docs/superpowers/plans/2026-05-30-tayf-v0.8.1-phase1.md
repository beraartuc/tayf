# tayf v0.8.1 — Phase 1 (Attribution) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Attribute tayf's end-to-end streaming overhead across stages — split I/O-loop cost from pipeline cost (a free `tayf --bypass` differential on the e2e harness) and split the pipeline into AnsiSm / line-buffer / apply_rules via an in-process `Pipeline::feed` micro-bench — and record the numbers in `benches/BASELINE.md`. **No optimization in Phase 1.**

**Architecture:** Two measurements, both reusing existing infrastructure. (1) `benches/e2e_overhead.rs` gains a third subprocess column (`tayf --bypass`, which sets `apply_colors=false` so the I/O loop runs but the pipeline is never fed); the two derived percentages reuse the existing `overhead_pct` (no new math). (2) A new criterion micro-bench `benches/pipeline_feed.rs` drives `Pipeline::feed` in-process against the three existing corpus shapes, writing to a reused `Vec` sink so real I/O cost is excluded. To reach `Pipeline::feed` from the external bench crate **without touching the off-limits `src/pipeline.rs`**, a behavior-neutral `BenchPipeline` newtype is added to the existing `lib.rs::__bench__` module (same crate → can call `pub(crate)` methods), mirroring the existing `BenchScratch` shim.

**Tech Stack:** Rust 2021, criterion 0.8 (existing dev-dep), portable-pty 0.9 + tempfile 3.27 (existing). **No new dependencies.**

**Reference spec:** `docs/superpowers/specs/2026-05-30-tayf-v0.8.1-profile-first-optimization.md` (Phase 1 = §2; this plan covers §2 only — Phase 2 is planned separately after the §3 attribution checkpoint).

> **DOKUNULMAZ (Phase 1):** `src/runtime.rs`, `src/pty.rs`, `src/pipeline.rs` are NOT modified in Phase 1. The only `src/` change is a behavior-neutral re-export shim in `src/lib.rs::__bench__`. `git diff v0.8.0..HEAD -- src/pipeline.rs src/runtime.rs src/pty.rs` MUST be empty at the end of Phase 1.

## Task 1: e2e harness — add the `tayf --bypass` differential column

**Files:**
- Modify: `benches/e2e_overhead.rs` (the `main` function's per-shape measurement + report block)

`--bypass` makes `Tayf::run` take the bypass branch (`src/lib.rs:122`): `runtime::run(..., apply_colors = false)`, so the output thread does raw `stdout.write_all` and never feeds the pipeline. So `tayf --bypass` exercises the full I/O loop (double-PTY hop + read + blocking write) with zero pipeline processing. The two derived numbers:
- `bypass_overhead% = overhead_pct(bypass_med, cat_med)` → pure I/O-loop overhead.
- `pipeline_cost% = overhead_pct(full_med, bypass_med)` → total pipeline cost on top of the I/O loop.

Both reuse the existing `overhead_pct` — **do NOT add new math functions** (DRY).

    /// Bench-only wrapper exposing the `pub(crate)` `Pipeline::feed` hot path
    /// to external bench crates without widening `src/pipeline.rs` visibility
    /// (which is an off-limits hot-path module). Constructs a pipeline over the
    /// built-in rule set. Behavior-neutral: forwards verbatim to `Pipeline`.
    pub struct BenchPipeline(crate::pipeline::Pipeline);

    impl BenchPipeline {
        /// Build a pipeline over the default built-in rule set.
        ///
        /// # Panics
        /// Panics if the built-in rule set fails to compile — impossible in
        /// practice (the built-ins are compile-tested) and acceptable in a
        /// bench-only constructor.
        #[must_use]
        pub fn with_builtins() -> Self {
            let compiled =
                crate::rules::Compiled::load_builtins().expect("built-in rules must compile");
            let rules = std::sync::Arc::new(arc_swap::ArcSwap::from_pointee(compiled));
            BenchPipeline(crate::pipeline::Pipeline::new(rules))
        }

        /// Feed a chunk through the pipeline, writing styled output to `out`.
        ///
        /// # Errors
        /// Propagates any write error from `out`.
        pub fn feed<W: std::io::Write>(&mut self, chunk: &[u8], out: &mut W) -> std::io::Result<()> {
            self.0.feed(chunk, out)
        }
    }
```

//! In-process `Pipeline::feed` micro-bench (spec v0.8.1 §2.2).
//!
//! Drives the pipeline hot path over the three e2e corpus shapes, writing to
//! a reused in-memory `Vec` sink so real PTY/stdout cost is excluded — that
//! cost is attributed separately by the `e2e_overhead` bypass differential.
//! Comparing shapes splits the pipeline's internal cost: `prose` is the
//! AnsiSm + line-buffer + RegexSet-miss floor; `log` adds full apply_rules +
//! SGR emission; `ansi` exercises the pre-colored SGR-detection path.
//!
//! Reuses the corpus templates from `benches/inputs/` (DRY with e2e). A
//! single `BenchPipeline` + `Vec` sink are hoisted out of `b.iter` so the
//! measurement reflects steady-state `feed`, not per-iter allocation. Each
//! template is newline-terminated, so the line buffer fully drains every
//! iteration and pipeline state is deterministic across iterations.

use std::hint::black_box;

use criterion::{criterion_group, criterion_main, Criterion, Throughput};

use tayf::__bench__::BenchPipeline;

/// Repeat a template to ~the same ~1 MiB scale for all three shapes so the
/// per-iter work is comparable across bench rows.
fn scaled(template: &[u8]) -> Vec<u8> {
    let target = 1024 * 1024;
    let reps = (target / template.len().max(1)).max(1);
    template.repeat(reps)
}

fn bench_shape(c: &mut Criterion, name: &str, template: &[u8]) {
    let input = scaled(template);
    let mut group = c.benchmark_group("pipeline_feed");
    group.throughput(Throughput::Bytes(input.len() as u64));
    group.bench_function(name, |b| {
        let mut pipeline = BenchPipeline::with_builtins();
        let mut sink: Vec<u8> = Vec::with_capacity(input.len() * 2);
        b.iter(|| {
            sink.clear();
            pipeline.feed(black_box(input.as_slice()), &mut sink).expect("feed to Vec cannot fail");
            black_box(&sink);
        });
    });
    group.finish();
}

fn bench_prose(c: &mut Criterion) {
    bench_shape(c, "prose", include_bytes!("inputs/e2e_prose.txt"));
}

fn bench_log(c: &mut Criterion) {
    bench_shape(c, "log", include_bytes!("inputs/e2e_log.txt"));
}

fn bench_ansi(c: &mut Criterion) {
    bench_shape(c, "ansi", include_bytes!("inputs/e2e_ansi.txt"));
}

criterion_group!(benches, bench_prose, bench_log, bench_ansi);
criterion_main!(benches);
```
