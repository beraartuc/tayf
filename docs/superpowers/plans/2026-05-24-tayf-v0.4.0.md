# tayf v0.4.0 — RegexSet Fast-Path + Pipeline-Owned Scratch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.4.0 — wire `Compiled.set: RegexSet` (populated-but-unused since v0.1) as a per-line pre-filter into `apply_rules`, move the four per-call scratch `Vec`s plus a new set-match scratch into a Pipeline-owned `PipelineScratch` struct, switch `runs` from `&Style` borrows to `Style` by value, update the bench shim and harness to hoist scratch outside `b.iter`, and close the v0.3.7 carryover (`ZeroForbidden` UserConfig arm → `Display` delegation).

**Architecture:** `apply_rules` keeps its free-function shape but grows a `scratch: &mut PipelineScratch` parameter (disjoint field borrow lets `Pipeline::feed`/`tick`/`drain` call it without destructure boilerplate). The outer `for (i, re) in compiled.individuals.iter().enumerate()` loop is replaced with `scratch.set_match_scratch.extend(compiled.set.matches(line).iter())` followed by `for &i in scratch.set_match_scratch.iter()`; selective per-rule dispatch (`uses_capture_styling[i]` → `find_iter` vs `captures_iter` + `emit_capture_runs`) is preserved byte-identical. `Style` is `Copy + ~16 byte`, eliminating the `'r` lifetime in `emit_capture_runs` and letting `PipelineScratch::runs` be lifetime-free as `Vec<(usize, usize, Style)>`. Bench shim grows `BenchScratch` newtype; `benches/throughput.rs` allocates it once outside each `b.iter` loop.

**Tech Stack:** Rust 2021, no new dependencies (`regex::bytes::RegexSet` already imported), no dependency version bumps. Pre-commit gate: `cargo fmt --all -- --check && cargo clippy --all-targets -- -D warnings && cargo test --all-targets`.

**Spec reference:** `docs/superpowers/specs/2026-05-24-tayf-v0.4.0-regexset-fastpath.md` (rev2).

```rust
pub(crate) fn apply_rules<W: Write>(
    line: &[u8],
    compiled_handle: &ArcSwap<Compiled>,
    scratch: &mut PipelineScratch,
    out: &mut W,
) -> std::io::Result<()> {
    let snapshot: Arc<Compiled> = compiled_handle.load_full();
    let compiled: &Compiled = snapshot.as_ref();

    scratch.accepted_spans.clear();
    scratch.runs.clear();
    scratch.event_scratch.clear();
    scratch.active_scratch.clear();
    scratch.set_match_scratch.clear();

    for (i, re) in compiled.individuals.iter().enumerate() {
        if compiled.uses_capture_styling[i] {
            for caps in re.captures_iter(line) {
                let m = caps.get(0).expect("capture 0 is always the full match");
                let (start, end) = (m.start(), m.end());
                if overlaps_accepted(&scratch.accepted_spans, start, end) {
                    continue;
                }
                emit_capture_runs(
                    &caps,
                    start,
                    end,
                    compiled.styles[i],
                    &compiled.group_styles[i],
                    &mut scratch.event_scratch,
                    &mut scratch.active_scratch,
                    &mut scratch.runs,
                );
                insert_accepted(&mut scratch.accepted_spans, start, end);
            }
        } else {
            for m in re.find_iter(line) {
                let (start, end) = (m.start(), m.end());
                if overlaps_accepted(&scratch.accepted_spans, start, end) {
                    continue;
                }
                scratch.runs.push((start, end, compiled.styles[i]));
                insert_accepted(&mut scratch.accepted_spans, start, end);
            }
        }
    }

    scratch.runs.sort_by_key(|&(s, _, _)| s);

    let mut cursor = 0usize;
    for &(start, end, style) in scratch.runs.iter() {
        out.write_all(&line[cursor..start])?;
        let sgr = style.to_sgr();
        if !sgr.is_empty() {
            out.write_all(sgr.as_bytes())?;
        }
        out.write_all(&line[start..end])?;
        out.write_all(Style::reset_sgr().as_bytes())?;
        cursor = end;
    }
    out.write_all(&line[cursor..])?;
    Ok(())
}
```

- [ ] **Step 4: Update `emit_capture_runs` signature + body — Style by value, lifetime parameter removed**

```rust
#[allow(clippy::too_many_arguments)] // reason: scratch Vecs are caller-owned to avoid per-match allocation; bundling them into a struct would obscure the reuse pattern.
pub(crate) fn emit_capture_runs(
    caps: &regex::bytes::Captures<'_>,
    match_start: usize,
    match_end: usize,
    default_style: Style,
    group_styles: &[Option<Style>],
    event_scratch: &mut Vec<(usize, OpenClose, u32)>,
    active_scratch: &mut Vec<u32>,
    out: &mut Vec<(usize, usize, Style)>,
) {
    event_scratch.clear();
    active_scratch.clear();
    for (gi, slot) in group_styles.iter().enumerate() {
        if slot.is_none() {
            continue;
        }
        let Some(sub) = caps.get(gi + 1) else { continue };
        #[allow(clippy::cast_possible_truncation)]
        // reason: regex caps capture count well below u32::MAX; group_styles.len() bounded by pattern.
        let g = (gi + 1) as u32;
        event_scratch.push((sub.start(), OpenClose::Open, g));
        event_scratch.push((sub.end(), OpenClose::Close, g));
    }
    if event_scratch.is_empty() {
        out.push((match_start, match_end, default_style));
        return;
    }
    event_scratch.sort_unstable_by(|a, b| a.0.cmp(&b.0).then_with(|| a.1.cmp(&b.1)));

    let mut prev_pos = match_start;
    for &(pos, kind, g) in event_scratch.iter() {
        if pos > prev_pos {
            let active_g = active_scratch.last().copied().unwrap_or(0);
            let style: Style = if active_g == 0 {
                default_style
            } else {
                group_styles[(active_g - 1) as usize]
                    .expect("event pushed for Some-styled group; slot is Some")
            };
            out.push((prev_pos, pos, style));
            prev_pos = pos;
        }
        match kind {
            OpenClose::Open => {
                let ip = active_scratch.iter().position(|&x| x > g).unwrap_or(active_scratch.len());
                active_scratch.insert(ip, g);
            }
            OpenClose::Close => {
                if let Some(rp) = active_scratch.iter().position(|&x| x == g) {
                    active_scratch.remove(rp);
                }
            }
        }
    }
    if prev_pos < match_end {
        out.push((prev_pos, match_end, default_style));
    }
}
```
