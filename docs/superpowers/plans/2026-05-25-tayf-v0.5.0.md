# tayf v0.5.0 — GHA Bump + Capture-Group Naming Retrofit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.5.0 — the first sub-version of the v0.5 minor. Two orthogonal pieces: (1) bump `.github/workflows/ci.yml`'s `actions/upload-artifact@v4` → `@v7` (Node.js 20 deprecation, 2026-06-02 hard cutoff; spec-phase verified `@v5` is still Node 20, `@v6` is the Node 24 transition, `@v7.0.1` current); (2) named-capture-group retrofit on the three capture-styled built-ins (`permission`, `timestamp` ISO branch, `url` first branch), with TOML resolution that accepts both positional (`styles."1"`) and named (`styles.scheme`) keys via compile-time `regex.capture_names()` lookup. Two new `ThemeRuleErrorKind` variants (`CaptureGroupNameUnknown { name, available }`, `CaptureGroupDuplicateTarget { positional, named }`) plumb through both Theme and UserConfig diagnostic paths.

**Architecture:** Three orthogonal pieces, each atomic. (1) One-line YAML edit. (2) Three regex source string rewrites in `src/rules.rs` adding `(?P<name>...)` markers, preserving `Compiled.group_styles` index-based shape (compile-time name → index resolution, **zero runtime perf delta**). (3) Refactored `resolve_group_styles_for_rule` ([src/rules.rs:901-1011](src/rules.rs#L901)) with **explicit three-step dispatch** (no fall-through): `key == "0"` → `CaptureGroupIndexZeroForbidden` (existing); all-digit → `validate_styles_map_key` (existing positional path, `None` → `KeyMalformed`, **NOT** named fall-through); else → named resolution via `regex.capture_names()`, miss → `CaptureGroupNameUnknown`. Duplicate-target detection: track which capture-group indices have been assigned during the rule's key iteration; second hit emits `CaptureGroupDuplicateTarget`. Two new variants additive on `#[non_exhaustive]` enum; Display impls byte-pinned by tests. v0.3.7-era duplicate-formatter discipline (memory `feedback_duplicate_formatter_audit`) preserved: both Theme and UserConfig paths delegate to `ThemeRuleErrorKind::Display`, no inline string reconstruction.

**Tech Stack:** Rust 2021, regex 1.12 (existing `Cargo.lock` surface — `capture_names()` is stable since regex 1.0). No new Cargo deps. GHA workflow change is single-line; `actions/upload-artifact@v7` is drop-in (inputs `name`/`path`/`retention-days` unchanged across v4→v7, v7 defaults `archive: true`/`compression-level: 6` preserve legacy zip-on-upload).

```rust
    /// A `styles` map key references a regex group name that is not present
    /// in the rule's compiled regex. `name` is the user-supplied key
    /// (sanitized by the `Display` impl). `available` lists the regex's
    /// actual named groups in `capture_names()` positional order
    /// (left-to-right, `None` filtered out). An empty `available` means
    /// the regex has no named groups at all (the regex's capture groups
    /// are all positional, e.g., a user rule that uses `(...)` without
    /// `(?P<name>...)`). See spec §2.4 + reviewer I-2/I-4.
    CaptureGroupNameUnknown {
        /// The raw `styles` map key as written in the user's TOML
        /// (sanitized in the `Display` impl).
        name: String,
        /// Named groups in the regex, in `capture_names()` positional
        /// order (left-to-right). Empty when the regex has no named groups.
        available: Vec<String>,
    },
    /// A `styles` map defines two keys that resolve to the same capture-
    /// group index: one numeric (positional, e.g., `"1"`) and one named
    /// (e.g., `"scheme"`). Set exactly one. Within a single regex the
    /// `regex` crate forbids duplicate named groups, so this variant only
    /// arises from a positional/named clash. See spec §2.4 + reviewer I-3.
    CaptureGroupDuplicateTarget {
        /// The numeric (positional) form of the key (e.g., `"1"`).
        positional: String,
        /// The named form of the key (e.g., `"scheme"`).
        named: String,
    },
```

```rust
                    sanitize_for_display(positional),
                    sanitize_for_display(named),
```

```rust

    // named-resolution path. The rule's pattern is grammar-validated at
    // builtin construction time; if compilation fails here for a Builtin,
    // that's a constructor bug — surface via unreachable!.
    //
    // Note: this regex compile happens at config-resolve time (config-parse /
    // theme-load), NOT on the hot path. Caching is not required (cf. Rust
    // senior reviewer N-3); the hot path remains apply_rules' index-based
    // dispatch via Compiled.individuals.
    let regex = match regex::bytes::Regex::new(&rule.pattern) {
        Ok(r) => r,
        Err(_) => match source {
            RuleSource::UserConfig | RuleSource::Theme => {
                // Should not happen here — pattern compilation failures are
                // surfaced earlier in the load pipeline. Defensive return.
                return Ok(vec![None; captures_len.saturating_sub(1)]);
            }
            RuleSource::Builtin => unreachable!(
                "Builtin rules ship with grammar-valid regex patterns; \
                 compile failure here would be a constructor bug."
            ),
        },
    };

    // Pre-compute the available named-group list (positional order,
    // None filtered out). Used by both NameUnknown diagnostic construction
    // AND named-resolution lookup.
    let available_names: Vec<String> = regex
        .capture_names()
        .filter_map(|opt| opt.map(String::from))
        .collect();

    // Per-slot tracker for duplicate-target detection. Indexed by slot
    // (= group_index - 1). Records the raw key that filled the slot.
    let mut assigned_by: Vec<Option<String>> = vec![None; captures_len.saturating_sub(1)];

    for (key, user_style) in map {
        // -----------------------------------------------------------------
        // Step 1: literal "0" — group-zero forbidden (existing behavior).
        // -----------------------------------------------------------------
        if key == "0" {
            match source {
                RuleSource::Theme => {
                    // Already collected by themes::validate_theme_rules.
                    continue;
                }
                RuleSource::UserConfig => {
                    let kind = crate::error::ThemeRuleErrorKind::CaptureGroupIndexZeroForbidden;
                    return Err(Error::Config {
                        path: user_cfg_path_or_sentinel.to_owned(),
                        line: 0,
                        message: format!("rule '{}': {kind}", rule.name),
                    });
                }
                RuleSource::Builtin => unreachable!(
                    "Builtin rules ship with styles_override == None; reached the \
                     map iteration only for UserConfig/Theme. styles_override on \
                     a Builtin would be a constructor bug."
                ),
            }
        }

        // -----------------------------------------------------------------
        // Step 2: all-digit key → positional path (existing grammar gate).
        // CRITICAL: None branch MUST NOT fall through to Step 3.
        // Regression-guarded by `dispatch_malformed_digit_key_emits_key_
        // malformed_not_name_unknown`. (Rust senior reviewer I-1 absorb.)
        // -----------------------------------------------------------------
        let resolved_idx: usize = if key.bytes().all(|b| b.is_ascii_digit()) {
            let Some(parsed) = crate::config::validate_styles_map_key(key) else {
                match source {
                    RuleSource::Theme => continue,
                    RuleSource::UserConfig => {
                        let kind = crate::error::ThemeRuleErrorKind::CaptureGroupKeyMalformed {
                            key: key.to_owned(),
                        };
                        return Err(Error::Config {
                            path: user_cfg_path_or_sentinel.to_owned(),
                            line: 0,
                            message: format!("rule '{}': {kind}", rule.name),
                        });
                    }
                    RuleSource::Builtin => unreachable!(
                        "Builtin rules ship with grammar-valid styles keys (validated at \
                         constructor time via builtin_rules()); this arm is reachable only \
                         through UserConfig/Theme paths handled above."
                    ),
                }
            };

            // Range check.
            if parsed >= captures_len {
                match source {
                    RuleSource::Theme => {
                        theme_errors.push(crate::error::ThemeRuleError {
                            rule_name: rule.name.clone(),
                            kind: crate::error::ThemeRuleErrorKind::CaptureGroupIndexOutOfRange {
                                group: parsed,
                                captures_len,
                            },
                        });
                        continue;
                    }
                    RuleSource::UserConfig => {
                        let kind = crate::error::ThemeRuleErrorKind::CaptureGroupIndexOutOfRange {
                            group: parsed,
                            captures_len,
                        };
                        return Err(Error::Config {
                            path: user_cfg_path_or_sentinel.to_owned(),
                            line: 0,
                            message: format!("rule '{}': {kind}", rule.name),
                        });
                    }
                    RuleSource::Builtin => unreachable!(
                        "Builtin rules ship with capture-group indices < captures_len \
                         (validated at constructor time via builtin_rules()); this arm is \
                         reachable only through UserConfig/Theme paths handled above."
                    ),
                }
            }
            parsed
        } else {
            // -----------------------------------------------------------------
            // Step 3: non-digit key → named resolution.
            // -----------------------------------------------------------------
            // Find the 1-based group index whose capture_names() entry matches `key`.
            // Group 0 (the whole match) has None name, so iter index = group index.
            let lookup = regex
                .capture_names()
                .enumerate()
                .find_map(|(i, opt)| opt.filter(|n| *n == key.as_str()).map(|_| i));
            let Some(idx) = lookup else {
                match source {
                    RuleSource::Theme => {
                        theme_errors.push(crate::error::ThemeRuleError {
                            rule_name: rule.name.clone(),
                            kind: crate::error::ThemeRuleErrorKind::CaptureGroupNameUnknown {
                                name: key.to_owned(),
                                available: available_names.clone(),
                            },
                        });
                        continue;
                    }
                    RuleSource::UserConfig => {
                        let kind = crate::error::ThemeRuleErrorKind::CaptureGroupNameUnknown {
                            name: key.to_owned(),
                            available: available_names.clone(),
                        };
                        return Err(Error::Config {
                            path: user_cfg_path_or_sentinel.to_owned(),
                            line: 0,
                            message: format!("rule '{}': {kind}", rule.name),
                        });
                    }
                    RuleSource::Builtin => unreachable!(
                        "Builtin rules ship with styles_override == None; named-key \
                         resolution unreachable for Builtin source."
                    ),
                }
            };
            idx
        };

        // -----------------------------------------------------------------
        // Duplicate-target check. Both positional and named keys can reach
        // this point; clash arises when one of each resolve to the same slot.
        // -----------------------------------------------------------------
        let slot_idx = resolved_idx - 1;
        if let Some(prior_key) = &assigned_by[slot_idx] {
            // Determine which is positional and which is named.
            let prior_is_positional = prior_key.bytes().all(|b| b.is_ascii_digit());
            let current_is_positional = key.bytes().all(|b| b.is_ascii_digit());
            let (positional, named) = match (prior_is_positional, current_is_positional) {
                (true, false) => (prior_key.clone(), key.to_owned()),
                (false, true) => (key.to_owned(), prior_key.clone()),
                _ => unreachable!(
                    "two positional keys cannot collide (TOML rejects duplicate keys at \
                     parse time); two named keys cannot resolve to the same index (the \
                     regex crate forbids duplicate group names within a single Regex)."
                ),
            };
            match source {
                RuleSource::Theme => {
                    theme_errors.push(crate::error::ThemeRuleError {
                        rule_name: rule.name.clone(),
                        kind: crate::error::ThemeRuleErrorKind::CaptureGroupDuplicateTarget {
                            positional,
                            named,
                        },
                    });
                    continue;
                }
                RuleSource::UserConfig => {
                    let kind = crate::error::ThemeRuleErrorKind::CaptureGroupDuplicateTarget {
                        positional,
                        named,
                    };
                    return Err(Error::Config {
                        path: user_cfg_path_or_sentinel.to_owned(),
                        line: 0,
                        message: format!("rule '{}': {kind}", rule.name),
                    });
                }
                RuleSource::Builtin => unreachable!(
                    "Builtin rules ship with styles_override == None; duplicate-target \
                     unreachable for Builtin source."
                ),
            }
        }

        // Assignment.
        let style = user_style.to_style(user_cfg_path_or_sentinel, &rule.name)?;
        vec[slot_idx] = Some(style);
        assigned_by[slot_idx] = Some(key.to_owned());
    }
    Ok(vec)
}
```

```rust
fn duplicate_formatter_theme_and_user_paths_byte_identical_diagnostic() {
    // Regression guard per memory feedback_duplicate_formatter_audit: the
    // UserConfig path's format!("rule '{}': {kind}", ...) and the Theme path's
    // theme_errors.push(...).kind.to_string() MUST produce byte-identical
    // diagnostic strings (modulo the Error envelope).
    use std::collections::BTreeMap;
    let style1 = crate::config::UserStyle { fg: Some("red".to_owned()), ..Default::default() };
    let style2 = crate::config::UserStyle { fg: Some("cyan".to_owned()), ..Default::default() };
    let mut overrides: BTreeMap<String, crate::config::UserStyle> = BTreeMap::new();
    overrides.insert("1".to_owned(), style1);
    overrides.insert("scheme".to_owned(), style2);
    let regex = compile_test_regex("url");
    let captures_len = regex.captures_len();
    let rule = crate::rules::BuiltinRule {
        name: "url".to_owned(),
        pattern: find_rule("url"),
        style: crate::style::Style::DEFAULT,
        group_styles: vec![None; captures_len.saturating_sub(1)],
        is_user_supplied: false,
        styles_override: Some(overrides.clone()),
        styles_override_from_theme: false,
    };

    // Theme path: collect into theme_errors vector.
    let mut theme_errors_t: Vec<crate::error::ThemeRuleError> = Vec::new();
    let _ = resolve_group_styles_for_rule(
        &rule,
        crate::rules::RuleSource::Theme,
        captures_len,
        None,
        &mut theme_errors_t,
    );
    assert_eq!(theme_errors_t.len(), 1, "theme path should collect exactly one error");
    let theme_kind_display = theme_errors_t[0].kind.to_string();

    // UserConfig path: returns Err with format!("rule '{}': {kind}", ...).
    let mut theme_errors_u: Vec<crate::error::ThemeRuleError> = Vec::new();
    let err = resolve_group_styles_for_rule(
        &rule,
        crate::rules::RuleSource::UserConfig,
        captures_len,
        Some("<test-config>"),
        &mut theme_errors_u,
    )
    .unwrap_err();
    let crate::error::Error::Config { message, .. } = err else {
        panic!("expected Error::Config, got {:?}", err);
    };
    // The UserConfig message has the envelope `rule '{name}': {kind}`.
    // Strip the envelope to extract the kind portion.
    let envelope_prefix = "rule 'url': ";
    let user_kind_display = message
        .strip_prefix(envelope_prefix)
        .unwrap_or_else(|| panic!("UserConfig message missing envelope: {message}"));
    // Note: the Error::Config Display adds another prefix
    // "config error in <test-config>: ", so `message` here is actually the
    // raw `format!` output stored in Error::Config { message } — already
    // "rule 'url': styles.\"1\" and styles.scheme target ...". Strip the
    // "rule '...': " envelope to get the kind.

    assert_eq!(
        theme_kind_display, user_kind_display,
        "Theme and UserConfig paths produced divergent diagnostic strings — \
         duplicate-formatter discipline broken. \
         Theme: {theme_kind_display:?} ≠ User: {user_kind_display:?}"
    );

    assert_eq!(
        user_kind_display,
        "styles.\"1\" and styles.scheme target the same capture group (index 1); set exactly one"
    );
}
```
