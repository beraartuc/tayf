## Task 2: Pipeline `tick()` aktive — 50ms idle flush

v0.1'de `Pipeline::tick` impl edildi ama `runtime.rs` çağırmıyordu. Interactive prompt'lar `\n` olmadığı için 64 KB cap'e kadar bekliyordu.

**Files:** `src/runtime.rs` (modify)

- [ ] **Step 1:** Output thread'in read'ini timeout'lu yapmak için iki seçenek var:
  - **A:** `nix::poll::poll([fd], 50ms)` ile read'i nonblocking yap; timeout'ta `pipeline.tick()` çağır
  - **B:** Ayrı ticker thread kurma (timer'a göre `Pipeline::tick(&mut stdout)` çağırır)

  **A daha temiz** çünkü tek thread, race yok. Implementasyon:

```rust
fn spawn_output_thread(...) -> JoinHandle<io::Result<()>> {
    thread::Builder::new()
        .name("tayf-output".into())
        .spawn(move || {
            use nix::poll::{poll, PollFd, PollFlags};
            use std::os::fd::AsRawFd;
            // reader.inner is Box<dyn Read + Send>; we need its fd.
            // pty.rs ::Reader doesn't expose fd; expose via a method or
            // restructure to take the raw fd here.
            // ...
        })
}
```

**`pty::Reader::as_fd()`** ekle (v0.1'de yok). Public API'de değil; `pub(crate)`.

- [ ] **Step 2:** `Reader::as_fd()` ekle. portable-pty `MasterPty::try_clone_reader()` `Box<dyn Read + Send>` döner; bunun raw fd'sini almak için `portable_pty` API'sini incele. Eğer mümkün değilse, daha temiz yol: `MasterPty::as_raw_fd()` çağır ve fd'yi `Reader`'a parametre olarak geçir.

- [ ] **Step 3:** Output thread loop:

## Task 3: Input thread self-pipe wakeup

v0.1 spec §3.4 step 7: input thread `stdin.read()`'te bloke kalıyor, OS reaps process exit'te. v0.1.1'de temiz exit.

**Files:** `src/runtime.rs`, `src/pty.rs` (Writer için shutdown handle), `src/lib.rs` (facade)

- [ ] **Step 1:** Self-pipe oluştur (`nix::unistd::pipe`). Input thread `poll([stdin, self_pipe_read], timeout=None)` ile bekler. Ana thread shutdown sinyali için `self_pipe_write`'a 1 byte yazar.

- [ ] **Step 2:** `runtime::run` imzasını değiştir: shutdown handle dön veya `Tayf::run` facade'da self_pipe write end'ini tut.

- [ ] **Step 3:** Facade child wait'ten sonra write end'e yaz → input thread uyanır, exit eder, join edilebilir.

- [ ] **Step 4:** Spec §3.4 step 7'yi güncelle (v0.1 limit kaldırıldı).

- [ ] **Step 5:** Integration test: child quick-exit (`exit 0`), input thread join'in 1 saniye içinde geri döndüğünü assert et.

- [ ] **Step 6:** Pre-commit gates + commit.

```
git commit -m "feat(runtime): self-pipe input-thread wakeup; clean shutdown

Adds nix::pipe() pair so the input thread polls both stdin and the
```

## Task 4: CLI parse error exit code 64 (EX_USAGE)

Final review I3. Şu an clap default 2 dönüyor; spec EX_USAGE (64) diyor.

**Files:** `src/cli.rs`, `src/main.rs`

- [ ] **Step 1:** `cli.rs` `parse_from_env`'i `try_parse` versiyonu ile değiştir:

```rust
impl Args {
    pub fn parse_from_env_or_exit() -> Self {
        match Self::try_parse() {
            Ok(args) => args,
            Err(e) => {
                e.print().expect("write help/version to stdout");
                let code = match e.kind() {
                    clap::error::ErrorKind::DisplayHelp => 0,
                    clap::error::ErrorKind::DisplayVersion => 0,
                    _ => 64, // EX_USAGE
                };
                std::process::exit(code);
            }
        }
    }
}
```

(Bu `process::exit` ban'lı diye `clippy::disallowed_methods` ile çakışır. Çözüm: `clippy.toml`'da bu fonksiyonu allow-list'e ekle, VEYA `main.rs`'i değiştir, `Args::try_parse_from_env()` Result dönsün ve `main` exit kodu set etsin.)

İkinci yol daha temiz:

`cli.rs`:
```rust
pub fn try_parse_from_env() -> std::result::Result<Self, clap::Error> {
    Self::try_parse()
}
```

`main.rs`:
```rust
fn main() -> ExitCode {
    match Args::try_parse_from_env() {
        Ok(args) => match Tayf::run(args) {
            Ok(code) => code,
            Err(err) => {
                eprintln!("tayf: {err}");
                ExitCode::from(map_error_to_exit_code(&err))
            }
        },
        Err(e) => {
            let _ = e.print();
            match e.kind() {
                clap::error::ErrorKind::DisplayHelp | clap::error::ErrorKind::DisplayVersion => ExitCode::SUCCESS,
                _ => ExitCode::from(64),  // EX_USAGE
            }
        }
    }
}
```

- [ ] **Step 2:** Integration test ekle:

## Task 6: TIOCGWINSZ dedup

Final review M2. `pty.rs` ve `signals.rs` aynı ioctl'i duplicate ediyor.

**Files:** `src/terminfo.rs` (add helper), `src/pty.rs` (use helper), `src/signals.rs` (use helper)

- [ ] **Step 1:** `terminfo.rs`'e ekle:

```rust
/// Query the controlling terminal's window size via TIOCGWINSZ.
pub(crate) fn winsize() -> Option<(u16, u16)> {
    use nix::libc::{ioctl, winsize, STDOUT_FILENO, TIOCGWINSZ};
    let mut ws: winsize = unsafe { std::mem::zeroed() };
    // SAFETY: TIOCGWINSZ is read-only; kernel writes into our local winsize
    // from a file descriptor we own (stdout).
    #[allow(unsafe_code)]
    let rc = unsafe { ioctl(STDOUT_FILENO, TIOCGWINSZ as _, std::ptr::addr_of_mut!(ws)) };
    if rc != 0 { None } else { Some((ws.ws_row, ws.ws_col)) }
}
```

- [ ] **Step 2:** `pty.rs::current_term_size` ve `signals.rs::read_winsize` sil; her ikisi de `terminfo::winsize()` çağırsın.

## Task 8: Bare-unit duration matching — DEFER documented

v0.1'de bare `s`/`m`/`h` unit'leri SGR collision yüzünden kaldırılmıştı. v0.1.1'de geri gelmiyor — v0.3 VTE awareness gerekiyor. Sadece dokümantasyon güncelle.

**Files:** `README.md`, `docs/superpowers/specs/2026-05-21-tayf-v0.1-design.md`

- [ ] **Step 1:** README "Known v0.1 limits" bölümüne ekle:

```markdown
- **Bare-unit duration matching (`1m`, `1h`, `1s`) disabled in v0.1.**
  These would collide with SGR escape sequence final bytes (`\x1b[49m`,
  etc.) producing visible garbage in colorized prompts. Re-enabled in
  v0.3 once VTE awareness can answer "is this match inside an escape
  sequence?" Currently `ns`, `us`, `μs`, `ms` are supported and cover
  modern logging conventions.
```

- [ ] **Step 2:** Spec §6 (security) ve §8 (Done) — bare unit'lerin v0.3 ile geri geleceğini açıkça yaz (zaten v0.2 backlog'da var; cross-reference ekle).

- [ ] **Step 3:** Commit.

```
git commit -m "docs: document bare-unit duration deferral to v0.3"
```
