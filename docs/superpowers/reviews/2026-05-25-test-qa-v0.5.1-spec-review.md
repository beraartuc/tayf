## What the spec got right

1. **Display-impl byte-pin verification with newline-continuation accounting.** Both §5.3 and §5.4 nest `\<EOL>` Rust string continuations inside `stderr.contains(...)` — the spec author correctly accounted for the implicit whitespace collapse, so the asserted substrings genuinely match Display output. Subtle and easy to miss.
2. **Disposition table for v0.5.0 §N-5 (negative regression) explicitly extends, not just folds.** Every new diagnostic test pairs a positive `contains` with at least one negative `!contains` of a sibling-variant phrase. The pattern is now structural, not anecdotal.

Future maintainers reading test 12 and test 13 side-by-side will immediately see the dispatch-path coverage symmetry.
